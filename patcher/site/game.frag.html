◀ 패치 목록

웹 패치

가지고 계신 원본 .bin 을 고르면 맞는 덤프인지 확인한 뒤 한글판을 만들어 드립니다. 파일은 이 컴퓨터 안에서만 처리되고 어디에도 올라가지 않습니다.

CD 이미지가 커서(약 250MB) 컴퓨터 브라우저를 권합니다. 휴대폰에서는 메모리가 모자라 멈출 수 있습니다.

파일로 받기

  1. xdelta — Delta Patcher(윈도·맥) 에서 원본 .bin 과 받은 .xdelta 를 고르고 적용합니다. 명령줄이면 xdelta3 -d -s 원본.bin 패치.xdelta 한글판.bin
  2. BPS — Flips 나 Rom Patcher JS 로 적용합니다. 원본이 다르면 적용 전에 알려 줍니다.
  3. 만든 .bin 옆에 같은 이름의 .cue 를 두고 에뮬레이터에서 .cue 를 엽니다.
