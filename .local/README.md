# .local/

**이 머신에서만 쓰는 것들.** 전부 gitignore 다(이 README 만 추적한다 — `originals/` 와 같은
방식이다. 폴더가 레포에 보여야 「여기에 무엇을 두는지」를 알 수 있다).

`work/` 와 갈리는 기준은 두 낱말이다 — **`work` 는 게임 작업물, `.local` 은 머신 전용.**
숨김인 이유는 gitignore 라서가 아니라 사람이 거의 안 열기 때문이다.

## 🔴 칸이 둘이다 — **`cache/` 만 지워도 된다**

기본값이 **보존**이다. 지워도 되는 것은 `cache/` 하나뿐이고, 리셋은 그 한 줄이다:

```sh
rm -rf .local/cache      # ← 이것만. work/ 와 같은 성질이다
```

⚠ **「gitignore 니까 재생성되겠지」가 아니다.** `.local` 은 스크립트 산출물처럼 보이는데
그 안에 **사람이 모은 되살릴 수 없는 자료**가 섞여 있다. 실제로 소장 공략집을 날린 적이
있다(복구 불가 — 잡지 부록이라 다시 구할 수 없다). 그래서 **예외를 외우게 하는 대신 칸을
갈랐다** — 종전엔 「넷만 빼고 지워도 됨」이었고, 그 넷이 문서에 없었다.

| 🔴 보존 — 지우지 않는다 | 무엇                                                       |
| ----------------------- | ---------------------------------------------------------- |
| `guide/`                | **소장 공략집**(잡지 부록 스캔·txt·hwp). 다시 못 구한다    |
| `bios/`                 | 기종별 BIOS (소장자 제공)                                  |
| `secrets.env`           | 바깥 서비스 열쇠 (아래)                                    |
| `inbox/<게임>/`         | 인게임 QA 스크린샷 — **라운드가 닫히면 칸 안만** 정리한다  |
| `capture/<게임>/`       | 실행기 화면 캡처(F9 · ⌥C) — `emu.sh` 가 세 실행기 모두 여기로 모은다 |
| `inbox/` 바로 아래      | ⚠ 출처 불명물이 쌓이는 자리다. **남긴다**                  |

| ✅ `cache/` — 지워도 된다 | 무엇                                                             |
| ------------------------- | ---------------------------------------------------------------- |
| `cache/dosbox/<game>/`    | DOS 실행 사본 — 원본을 안 건드리고 세이브·패치를 덮어쓰며 검증한다 |
| `cache/mednafen/`         | 우리 패치를 얹어 빌드한 mednafen (`emu/mednafen-build.sh`)        |
| `cache/np2kai/` `cache/pc98/` | PC-98 에뮬 빌드와 실행 사본                                   |
| `cache/fonts/`            | 내려받은 글꼴 원본 (Google Fonts)                                 |
| `cache/ref/`              | 패치 템플릿 클론 (`check-updates.sh` 가 다시 받는다)              |
| `cache/patcher/` `cache/ed-patch/` | 웹 패처 빌드 산출물 · 배포 레포 클론                     |
| `cache/publish/`          | 배포용 압축 (`publish.sh`)                                        |

⚠ 지울 땐 **목록을 먼저 파일로 남긴다.** 되돌릴 수 없는 것을 지웠는지 사후에 확인할
유일한 길이다.

## 🔑 `secrets.env` — 바깥 서비스 열쇠는 여기 하나로

새 `.env` 규약을 만들지 않는다. **이 파일 하나**에 모으고 도구는 `common.secret(이름)` 으로
읽는다. ⚠ **환경변수가 이긴다** — 일회성으로 덮어쓸 때 쓴다.

```sh
cat > .local/secrets.env <<'EOF'
# 값은 따옴표 없이 = 뒤에 바로 쓴다.

# 역번역 대조 (games/<게임>/tools/backtrans.py)
#   https://www.deepl.com/pro-api 의 **DeepL API Free** — 월 50만 자, 카드 등록은 필요하나 과금 없음
DEEPL_API_KEY=

# 대사 초벌 (games/<게임>/tools/mt_draft.py)
#   있으면 REST + 구조화 출력, 없으면 gemini-cli 로 폴백한다
GEMINI_API_KEY=
EOF
chmod 600 .local/secrets.env
```

⚠ **워크트리에는 `.local/` 이 따라오지 않는다.** 도구는 워크트리 루트에서 시작해 **메인
트리까지 거슬러 올라가** 이 파일을 찾으므로, 열쇠는 **메인 트리에 한 번만** 두면 된다.

⚠ 열쇠가 없으면 도구가 **어디에 어떻게 두는지 알려주고 멈춘다**(`common.need_secret`).
값은 로그·오류 메시지에 찍지 않는다 — 있는지 없는지만 말한다.
