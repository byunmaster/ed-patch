# shared/assets — 두 판 이상이 쓰는 그림

⚠ **여기 오는 기준은 「지금 둘째 소비자가 있는가」다**(루트 `CLAUDE.md` — YAGNI).
한 게임만 쓰는 그림은 그 게임의 `assets/` 에 둔다.

| 파일 | 무엇 | 쓰는 곳 |
| --- | --- | --- |
| `title_logo.png` | 「영웅전설」 로고 **정본** (1724×402 RGBA) | PS1 · 새턴 타이틀 |

## 정본이 곧 소스다 — 원화는 안 둔다

유저가 만든 원화를 가공해 만든 결과물이다. 손본 데가 둘이었다.

- 🔴 **자간.** 원화는 간격이 24 / 3 / −8px 이다(마지막은 「전」과 「설」이 8px 겹친다).
  글자를 넷으로 갈라 다시 늘어놓는다. **확정값은 68 / 62 / 56**(`logo.GAPS`).
  ⚠ **계산으로 안 닫힌다.** 균등 62 로 놓으면 「영웅은 좁고 전설은 넓다」가 되고(마주보는
  거리 117 / 162 / 138), 여백 넓이를 맞춘 광학 해(79 / 48 / 59)는 이번엔 「영웅·전설이
  넓고 웅전이 좁다」가 된다. 둘 사이에서 **사람이 보고 골랐다**(유저 QA 2026-08-23).
- 🔴 **알파.** 원화는 배경이 검게 구워져 있어 알파가 없다. 그대로 얹으면 세계지도 위에
  **검은 상자**가 뜬다. 밝기로 알파를 뽑는다.
  ⚠ 밝기로만 뽑으면 **반투명한 검은 화소가 8천 개** 남아 배경에 옅은 음영이 얹힌다
  (실측: 평균 α 51 · 밝기 17/765. 유저 인게임 지적 2026-08-23 「배경에 미세하게 음영」).
  α<250 이면서 어두운 화소는 **완전 투명**으로 만든다 — 밝은 가장자리 안티에일리어스는 남는다.

⚠ **그 가공을 빌드 때 하지 않는다.** 글자 분할은 휴리스틱(연결 성분·밝기 임계)이라 빌드
경로에 두면 원화를 손댈 때 조용히 흔들린다. 이 레포 관용대로 **판단은 커밋되는 정본에
박는다**(`align_map.json`·`locked_lines.json` 과 같은 자리).

🔴 **그래서 원화도 레포에 안 둔다**(유저 확정 2026-08-23). 정본이 있으면 빌드에 필요 없다.
⚠ 대신 **자간을 다시 만지려면 원화가 다시 필요하다** — 절차와 값은 이 문서와 그때의 커밋
히스토리에 남겼다. 회귀 시험은 정본의 간격이 `logo.GAPS` 와 같은지 본다.

정본이 화면에 앉는 규격은 두 기종 공통이다 — **290×69 상자에 비율 유지로 담고**, 가로는 화면
한가운데, 세로 중심 y=106. 값은 각 게임의 `patch_gfx_title.py` (`LOGO_FIT` · `LOGO_CY`).

⚠ **두 판이 같은 로고를 쓴다** — PS1 과 새턴은 타이틀 그림이 사실상 같다. 한쪽만 고치면
그림이 갈린다(문안에서 이미 겪었다 — 「문안이 하나면 그림도 하나여야 한다」).

## 8bpp 팔레트로 양자화된다

두 기종 다 타이틀 화면이 **256색 팔레트**다. 새 색을 못 쓰고 가장 가까운 팔레트 색으로
갈린다. 지금 원화는 그 안에서 125색을 쓰고 평균 오차가 10.6/765 라 눈에 안 띈다.
원본이 쓰던 157색 목록은 `games/ps1-ed1+2/tools/patch_gfx_title.py` 로 뽑을 수 있다.
