# shared/fonts

한글화 공용 폰트 에셋. 모두 SIL OFL 1.1 — 패치 임베딩·재배포 허용 (라이선스 파일 동봉).

| 폰트                        | 격자   | 파일             | 출처                                | 용도                        |
| --------------------------- | ------ | ---------------- | ----------------------------------- | --------------------------- |
| Galmuri11 (+Bold)           | 11×11  | `Galmuri11*.bdf` | <https://github.com/quiple/galmuri> | PS1 영웅전설 1+2 (11×11 셀) · **PS1 ED3·ED4** (12×12 저장 · 잉크 11행) |
| Galmuri11-Condensed         | **8×11** | `Galmuri11-Condensed.bdf` | 〃                          | **SFC 8×16 반각 한글 칸** — 완성형 11,172자 전부 전진폭 8(잉크 ≤7px), 실측 2026-09-06 |
| Galmuri7 / 9 / 14 / Mono    | 7~14px | `Galmuri*.bdf`   | 〃                                  | 다른 셀 크기 예비           |
| Neo둥근모                   | 16×16  | `neodgm.ttf`     | <https://github.com/neodgm/neodgm>  | **새턴 16×16 셀 확정**      |

- 릴리스 크레딧에 폰트 저작자 표기 필수: Galmuri © quiple (OFL), Neo둥근모 © Eunbin Jeong (OFL).

## ⚠ 폰트는 「예쁜가」가 아니라 **셀에 맞게 설계됐는가**로 고른다

16px 설계를 11px 셀에 우겨넣으면 **받침이 있는 글자만** 무너진다(`오`·`스` 는 멀쩡한데
`영`·`웅`·`많`·`읽` 이 뭉갠다). 한글은 초·중·종성을 세로로 쌓는데 16px 설계는 그 셋을
**13행에 배분**해 놨기 때문이고, 0.69배는 정수배가 아니라 획이 서로 먹는다.
2026-08-21 에 실물로 확인했다 — Neo둥근모와 [둥근모꼴+Fixedsys](https://cactus.tistory.com/193)
(퍼블릭 도메인) 둘 다 같은 증상이고, 육안으로 서로 구분이 안 된다(같은 뿌리의 복각).

| 셀    | 쓸 것         | 왜                               |
| ----- | ------------- | -------------------------------- |
| 11×11 | **Galmuri11** | 11px 에 초·중·종성을 배분한 설계 |
| 12×12 | **Galmuri11** | 잉크가 11행이면 12칸에 그대로 앉는다 (PS1 ED3·ED4, `dy=-3`) |
| 16×16 | **Neo둥근모** | 네이티브 — 축소가 없다           |

⚠ **셀이 12여도 원본의 잉크 행 수를 먼저 잰다.** PS1 ED3 는 저장 격자가 12×12 인데 원본
글리프의 잉크는 **0~10행**이라, Galmuri11 을 `dy=-3` 으로 얹어야 베이스라인이 맞는다.
`dy` 를 한 칸 잘못 주면 **한글만 1픽셀 아래로 밀리고**, 같은 줄에 일본어가 섞일 때만
드러난다(2026-09-03 실측). 미리보기는 **한 줄에 섞어서** 그린다.

⚠ **압축이 있는 자리는 셀 말고 「잉크 행 수」도 본다.** PS1 오프닝은 폰트를 압축해 EXE 에
넣는데(행-마스크, 예산 4,064B) 그 예산이 곧 **평균 잉크 8.5행**이라, 셀(16×15)에 수납되는
폰트도 예산에서 떨어진다. 자세히는 `games/ps1-ed1+2/tools/patch_opening_font.py`.
