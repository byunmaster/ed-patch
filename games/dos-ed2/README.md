# 영웅전설 II 만트라 DOS판 복원 프로젝트

팔콤 『영웅전설 II』(Dragon Slayer: The Legend of Heroes II)의 국내 정발판인
**만트라 DOS 이식판**에서, 이식 과정에 생긴 버그와 누락된 연출을 리버싱으로
복구하는 프로젝트입니다. 원본(PC98 일판)을 동작 레퍼런스로 삼습니다.

번역이 목적인 [영웅전설 시리즈 한글패치 프로젝트](../eiyuu-densetsu-kr)와는
스코프가 다릅니다 — 이쪽은 **만트라 포트 자체의 결함 복원(리마스터/버그픽스)**입니다.

패치 파일에는 원본 게임 데이터가 포함되지 않습니다. 적용하려면 직접 소장한
만트라 DOS 정발판 원본이 필요합니다.

## 복원 대상

| #   | 증상                                                                        | 위치               | 원본(PC98) | 상태         |
| --- | --------------------------------------------------------------------------- | ------------------ | ---------- | ------------ |
| 1   | 스엘 마을 "세계 3대명소 유람여행"(10000G) 이벤트 — 승선 후 월드맵에서 크래시 | `SCENA/F_501.DLL`·`F_502.DLL`의 `ALGO_00` export 누락 | 정상 동작  | ✅ 수정·검증 완료 |
| 2   | 그로스토스성 성문 파괴 시 효과음(SE) 누락                                   | 미확정 (성 맵 DLL) | SE 재생됨  | 🔍 조사 예정 |

- 두 결함 모두 **만트라 DOS판에서만** 발생하며 타 기종·PC98 원본은 정상.
- 이벤트 로직은 EXE 하드코딩이 아니라 맵별 **16비트 DPMI DLL**(`SCENA/*.DLL`)로
  분리돼 있어, 결함이 있는 맵 DLL 하나만 특정·패치하면 된다.
- #1은 유람선 NPC가 있는 `T_246`이 트리거지만 **버그는 `T_246`이 아니다**.
  엔진의 필드 메인 루프(`FIELD_MAIN`)가 필드 씬 DLL에서 `ALGO_00`을 이름으로
  찾는데, 필드 씬 12개 중 `F_501`/`F_502`만 그 export가 빠진 채로 빌드됐다.
  `GetProcAddress`가 NULL을 돌려주고, 그 실패 처리 경로에서 GP fault가 난다.
  `F_500`의 6바이트 스텁을 이식해 해결했다 — `ED2MAIN.EXE`는 수정하지 않는다.
  → [docs/02-suel-boat-tour-crash.md](docs/02-suel-boat-tour-crash.md)

## 기술 개요

- `ED2MAIN.EXE`가 `Scenario_Load` / `Scenario_GetFuncPtr`로 `SCENA/C_*.DLL`,
  `T_*.DLL` 등을 **이름 기반 동적 링킹**해 호출한다.
- 각 시나리오 DLL export: `C_xxx`(엔트리), `ALGO_xx`, `SINAL`, `SINAL_INIT`,
  `GETDLLDATASEG`. 대사 텍스트는 DLL 데이터 세그먼트에 EUC-KR로 내장.
- 접두어 규약: `C_`=메인 스토리 이벤트, `T_`=마을 NPC 대화, `M_`=맵, 그 외
  `D_/V_/H_/F_`=컷신류.

## 저장소 구조

```
tools/      파이썬 도구 — NE 파서·디스어셈블·스캐너, 패치 생성/적용, 패처 빌드
scripts/    직접 실행하는 셸 스크립트 (게임 구동, 패처 미리보기·배포)
dosbox/     DOSBox-X 설정 템플릿 (@ROOT@ 는 실행 시 치환)
web/        웹 패처 HTML 템플릿 — 빌드 시 패치 스펙이 인라인된다
docs/       디스어셈블 분석 노트, 크래시 재현 로그
patches/    패치 스펙(JSON) — 바뀐 바이트만. 원본 미포함
originals/  원본 게임 데이터 (전부 gitignore — 직접 소장본으로 채움)
work/       빌드·실행 중간물 (전부 gitignore)
```

주요 진입점:

```bash
scripts/dosbox.sh --app          # 게임 실행 (macOS는 --app 이라야 키보드가 산다)
scripts/patcher.sh serve         # 웹 패처를 로컬에서 띄워 확인
scripts/patcher.sh deploy        # 공개 리포로 빌드·배포
```

## 패치 적용

완성된 패치는 [Releases](../../releases)에 배포됩니다(예정). 소장 중인 만트라
DOS 정발판에 xdelta/IPS로 적용합니다. 자세한 절차는 릴리스 노트를 참조하세요.

## 법적 고지

이 저장소는 원본 게임 파일을 포함하지 않습니다. 배포물은 사용자가 합법적으로
소유한 원본에 적용하는 **차분 패치**뿐입니다.
