# pc98-ed1 도구 지도 — 무엇이 게이트를 지키고, 무엇이 조사도구인가

`docs/patcher-checklist.md` 「검사기 자신의 커버리지」가 요구하는 지도다. **만든 날에만 맞는
검사기**를 막으려고 둔다 — 자료 꼴이 바뀌거나 축이 늘면 아무도 안 고쳤는데 눈이 먼다.

## 게이트가 부르는 것 (`../check.sh`)

| 도구                | 무엇을 지키나                                        |
| ------------------- | ---------------------------------------------------- |
| `common.py`         | 원본 지문 + 섹터 모델 — 소장본이나 d88 리더가 바뀌면 죽는다 |
| `probe_font.py`     | 「게임이 CGROM 을 직접 읽는다」 판정의 재현(CG 루틴 9곳)   |
| `scn.py`            | 시나리오 디렉터리 — 224건이 553섹터를 정확히 채우나       |
| `dump_scn.py`       | 대본 덤프 **라운드트립 무손실** — 깨지면 저본을 못 믿는다  |
| `dump_sys.py`       | event·program 문자열 덤프의 라운드트립                   |
| `font.py --check`   | 글리프 표의 결정성 + 얼린 지문                           |
| `memmap.py`         | 폰트를 올릴 자리(세그먼트 0x4000) 전제의 재현            |
| `translate.py stat` | 정본 커버리지 + **재삽입 경로 없는 정본 수**             |
| `build.py`          | 🔴 쓰기 사전조건 다섯(무변경 대조·섹터 ID·빈자리·겹침·실패 무효화) |
| `patch_scn.py --verify` | 🔴 **왕복** — 구운 이미지를 되읽어 정본과 글자로 대조     |

## 조사도구 (게이트가 안 부른다 — 부를 것도 아니다)

`census_sjis.py`(문자 분포) · `free_map.py`(빈 섹터 지도) · `tables.py`(이름 표) ·
`units.py`(재삽입 성립 조건 계측) · `probe_font.py` 의 탐색 모드.
⚠ **`units.py` 의 수치가 status 14절에 인용돼 있다** — 조판·덤퍼·공용이 바뀌면 다시 돌린다.
(성립 조건 자체는 `patch_scn.plan()` 이 빌드마다 다시 계산하므로 게이트가 실질을 덮는다.)

## 라이브러리 (도구가 임포트한다)

`walk_scn.py`(옵코드 워커) · `reuse.py`(열쇠 정규화) · `patch_font_hook.py`(후킹 사이트 표) ·
`scn.py`·`common.py`.

## 🔴 주기 점검 — **언제 도나**

「생각날 때」가 아니라 **⑴ QA 라운드가 닫힐 때 ⑵ 자료 꼴을 바꿨을 때 ⑶ 공용이 갱신됐을 때**.
볼 것 넷(`patcher-checklist.md`):

1. **안 불리는 검사기** — 위 표에 없는데 검사기인 것이 생겼나
   `grep -oE '\$T/[a-z_]+\.py' ../check.sh | sort -u` 와 `ls *.py` 를 대조한다.
2. **로더가 못 읽는 자료** — 검사기가 자료의 일부만 보고 있나.
   지금 아는 구멍: **재삽입은 시나리오 영역뿐**이라 전투·event·program 에만 있는 정본은
   번역해도 화면에 안 나온다 → `translate.py stat` 이 그 수를 찍는다.
3. **같은 규칙의 사본** — 마커 표(`0x01=\n · 0x03=<WAIT> · 0x05=<PAGE>`)가 `dump_scn.py` ·
   `patch_scn.encode` · `patch_scn.decode_back` · `translate._markers` 넷에 흩어져 있다.
   하나를 고치면 넷을 맞춘다(왕복 대조가 어긋남을 잡아 주긴 한다).
4. **이미 판정이 끝난 ⚠** — `docs/status.md` 의 ⚠ 중 해결된 것을 내린다.
