**⭐ 원인 확정 + 훅 2 구현(2026-07-28, capstone 정적 RE — 라이브 불필요):**

개행은 우리가 짚었던 `0x800AD3A8`(그리기 단계)이 아니라 **그보다 앞선 `0x800ACE18`**에서
결정된다. 전체 파이프라인(호출 순서 = 데이터 흐름):

```
0x800B1D50 strcpy(fp+0x18, msg)      호출자 스택 128B 사본
0x800B1D60 jal 0x800ACE18            ★자동 개행 삽입기(글자단위·29열) — 0x0A를 끼워 제자리 재작성
0x800B1D7C jal 0x800B1E58            0x0A로만 분할 → 워크슬롯(0x801190B0+k*66)  ↳ 훅 1이 여기 끝
0x800B1DF0 jal 0x800B2410 → 0x800AD3A8   줄마다 그리며 남은 초과분만 재차 개행
```

- 훅 1(`0x800B2054`)은 **개행이 이미 정해진 뒤**라 폭 계산이 미해결 병기로 이뤄졌다:
  `세리오스은(는) 횃불을(를) 사용했다` = **34열 > 29** → "…사/용했다"(유저 재현과 일치).
  해결 후 `세리오스는 횃불을 사용했다` = **28열 ≤ 29** → 무개행.
- **훅 2 = `0x800B1D60`의 `jal` 타깃 1워드 교체** → 스텁이 `josa_fix(a0, 128, zero-guard)` 후
  `j 0x800ACE18` 꼬리호출(ra 유지). 원명령 재현·지연 슬롯 처리 불필요(지연 슬롯이 원래 nop).
  대상이 호출자 전용 스택 사본이고 결과는 **항상 짧아지며**, prewrap·assemble 모두 `strlen`을
  다시 재므로 오버플로·길이 불일치가 없다. 훅 1과 멱등 중복(둘 다 같은 `josa_fix` 호출).
- ⚠ **이전 RE 오류 정정**: `0x800B245C`는 `0x800B1E58` 내부가 아니라 별개 함수 `0x800B2410`.
  `0x800AD3A8`의 `a2`는 원문이 아니라 **워크슬롯 줄** — "a2 소스 라이브 확인" 항목은 잘못된
  질문이었다(그래서 삭제). `0x800ACE18`의 호출자는 전수 스캔 결과 `0x800B1D60` 하나뿐.
- ⚠ **"capstone 미설치"는 스테일** — 5.0.7 설치돼 있다.
- 검증: `--selftest`에 **MIPS 미니 인터프리터** 신설(어셈블된 바이트를 실제 실행해 파이썬 시뮬과
  바이트 비교 — 인코딩 오류를 잡는다) 7케이스 + 빌드 후 **디스크에서 다시 꺼낸 바이트**로 재실행.
  실패 시 `JOSA_NOPREWRAP=1`(훅 2만 제외) / `JOSA_NOOP=1`(훅 1 무력화)로 계층 이분.

## 핵심 지식 (영구 참조)

- **ED.EXE**: LBA 257. RAM = file − 0x800 + 0x80010000. mednafen 'ram' 오프셋 = & 0x1FFFFF.
- **`%c`의 정체**: 창 구분자가 아니라 **제어 인자 escape**(색상 등). 데미지 조립부
  `sprintf(buf, "%c%s%c…", 2, 이름, 1)`로 확증 — `%c`에 색코드(2=ON,1=OFF)가 인자로 들어간다.
  블록 조판 시 제어 토큰 위치를 옮기면 색이 문장 중간에서 바뀐다 → **템플릿 채우기**로 골격 보존.
- **구조 계약(소프트락 방지)**: 엔진은 블록당 **`%c` 세그먼트 수·`%s`/`%d` 수**를 원본대로 읽는다.
  부족하면 과잉읽기로 소프트락(1장 탈출 먹통의 원인). 재조립본이 부족하면 번역 제외.
- **%s 이름 주입 소스**: ED.EXE 0x800이 아니라 **SCN 오버레이의 널종단 이름 사본**(전투 HUD의
  몬스터명 사본과 같은 계열). patch_sys_ui.CHAR_NAMES가 처리.
- **공간(오버레이 확장)**: SCN 파일을 DUMMY.;1 영역으로 재배치 + ISO 디렉토리 레코드 패치
  (엔진이 SCN을 ISO 경로로 로드). out/scn_layout.json 매니페스트로 새 LBA 전달. 도너 풀
  `reinsert.DONOR_RUNS`는 조사 훅 배치용 2런(0xBF5DC/0xC105C)을 **주석 예약 제외** 유지 필수.
- **HUD 지명 소스**: SCN 오버레이 맵 세그먼트 헤더([포인터테이블]+[지명 널종단]+[%c 대사]).
- **값 메뉴 정렬**: 값 X = 라벨 렌더폭 + 갭. KR 라벨을 JP 원본 렌더폭에 패딩(patch_sys_ui VALUE_PAD).
- **MIPS 손인코딩 함정**: andi rs 필드, load-delay 슬롯 — 디스어셈블+시뮬로 검증.
- **정발 우선**: 정발에 있는 건 다 이식(이스터에그 포함), 없는 것만 정발 문법으로 신규 번역.
  문안 변경은 사전 보고. 재사용 기법은 `docs/reference/our-findings.md`에 축적.
