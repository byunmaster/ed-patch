# 우리가 그린 그림 (커밋된다)

여기 두는 PNG 는 **우리 작업물**이라 커밋한다 — 원본 그림(`work/review/tim/`)과 다르다.

이름은 `graphics_<disc>.json` 의 `file` 값과 같아야 한다. 규칙은 둘뿐이다:

1. **가로×세로를 원본 그대로.** 픽셀 하나도 다르면 안 된다.
2. **색 수가 bpp 안에.** 4bpp = 16색, 8bpp = 256색. 투명은 알파 0.

⚠ 4bpp 마스크(오프닝·엔딩·크레딧)는 원본이 **흰색 + 투명 둘뿐**이다. 회색조를 넣으면
   색이 늘어 팔레트를 다시 쓰게 되는데, 게임이 그 팔레트를 어떻게 쓰는지 아직 확인 안 했다.
   **1비트로 가는 게 안전하다.**

사양서와 원본 미리보기는 `work/review/tim/<disc>/_spec/` 에 있다(커밋 안 된다).
