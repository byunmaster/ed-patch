# sfc-ed1 플레이 매뉴얼 — 켜기 전에 읽는다

QA 회차의 준비물이다(규약 [`docs/ingame-qa.md`](../../../docs/ingame-qa.md)).
**지금 아는 것만** 적는다 — 모르는 자리는 「미탐색」이라고 쓰지, 그럴듯하게 채우지 않는다.
`sfc-ed1` 은 아직 **P0** 이라 완주 회차 전이다. 아래는 세션이 실제로 밟아 본 데까지다.

## 🔑 리셋 부팅으로 본다 — 세이브스테이트는 안 된다

글꼴은 **부팅 때 한 번만** VRAM 에 올라간다($00:9156). 옛 빌드의 스테이트를 새 롬에 얹으면
**타일맵은 새것 · 글리프는 옛것**이라 엉뚱한 글자가 뜬다. 회차는 늘 리셋에서 시작한다.

## 조작 (2026-09-07 실기 확인)

| 버튼 | 무엇 |
| --- | --- |
| **A** | 확인 · 대사 넘기기 · 말 걸기 |
| **B** | 취소 / **필드에서 가만히 선 채 누르면 커맨드 창** |
| **X** | 주문 창 바로 열기 |
| **Y** | 도구(사용) 창 바로 열기 |
| **START** | 저장 창 |
| **SELECT** | 로드 창 |

🔴 **커맨드 창이 안 열리면 「이동 입력이 남았나」를 먼저 의심한다.** 2026-09-07 첫 회차에서
세션이 <kbd>B</kbd> 로 못 열어 「여는 법을 모른다」로 보고했는데, **방향키를 누른 직후라
캐릭터가 걸었을 뿐**이었다. 몇 프레임 쉬고 누르면 열린다(`press_frames=3` 으로 확인).
유저는 09-06 에 같은 방법으로 열었다 — **여는 법은 처음부터 맞았고 조작 순서가 문제였다.**

커맨드 창 차례: `주문 · 사용 · 장비 · 버린다 · 상태 · 그외 · 리더`.
`그외` → 시스템 창(`로드 저장 시스템 설정`) → 설정·전투 설정.

## 시작 순서

1. 타이틀(로고) — **START**
2. `はじめから` / `ぼうけんのつづき` / `データをけす` → 첫 줄에서 **A**
   ⚠ 이 창은 아직 일본어이고 **깨져 보인다**(E2 — 창 배치 표 밖이라 타일을 못 지켰다)
3. 메시지 속도 창(`サクサク` / `ドキドキ`) → **A**
4. 1장 시작 — 왼쪽 위 띠에 **`제1장 왕자의 여행`**
5. 침실에서 시녀·라이아스 대사 몇 개(**A** 로 넘긴다) → 자유 이동

## 원판(일본어)으로 같은 자리 밟기 — 대조용

우리 빌드와 **조작이 같다**(2026-09-07 확인). 저장 화면까지:
1. 타이틀 → **START** → 세 줄 메뉴(커서는 **↑↓ 로 움직인다** — 움직이는지 먼저 보면 입력이 닿는지 알 수 있다)
2. 첫 줄에서 **A** → 메시지 속도 창에서 **A** → 1장
3. 대사를 **A** 로 여덟 번쯤 넘기면 자유 이동
4. **START** → 저장 창 → **A**(1번 슬롯) → 「◯ばん にセーブしますか?」 → **A** → **오른쪽 위에 `はい/いいえ` 창**
⚠ 3에서 **`B` 를 누르지 마라** — 커맨드 창이 열려 그 뒤 조작이 어긋난다(회차 하나를 그렇게 버렸다).

## 캡처 규약

`.local/inbox/sfc-ed1/` 에 **칸 ID 를 앞에 둔 ASCII 이름**으로(`A1-command-window.png`).
⚠ 한글 파일명은 쓰지 않는다 — 맥에서 온 이름의 자모가 분리돼 **관리자가 못 여는 일이 있었다**.
⚠ **256×224 캡처로 글자를 판정하지 않는다** — 여덟 기종 중 제일 낮아 `ㅏ`/`ㅣ` 가 안 갈린다.
확대해서 보거나 **롬 바이트를 되읽어** 댄다(`build.py` 의 되읽기 게이트가 그 일을 한다).
