## 번역 삽입 구조 (`tools/`)

- `segs.py` — **글자 구간**(번역 단위): 대사 단위를 구조 토큰(조건 `$11~$14`·점프 `$0F`·네이티브 `$15`·`$F0~`·끝 `$00`…)에서 갈라 글자·줄바꿈·색·사전 참조만 든 연속 토큰으로.
  점프 목적지·`$A6` 즉치 포인터에서 끊는다(공유 꼬리). 코드 곁 잡음(`(k` 등)은 `_clean` 이 걷는다. `EXCLUDE` 는 다른 종류가 맡는 자리.
- `build.py` + `patches.py` — 번역 삽입 규칙: 짧으면 제자리(`$16` 빈 토큰으로 채움), 길면 트램펄린(`17 lo hi bank` → 확장 뱅크, 끝에 되돌아오는 `17`), 3바이트는 같은 뱅크 `$0F` 점프(뱅크 빈 자리),
  `$D7` 은 문자열 이전 + 3바이트 포인터 수정. UI 창 블록(`ui.json`)·고정 칸(`cells`)·문자열(`spans`)·레코드 표(`records` — 정본에서)·16비트 포인터 표(`ptrs16` — 정본 지역명)·사전(`$E0` 정본).
  코드 패치: 글꼴 이전 · 트램펄린(`$17`) · 창 블록 로더 24비트 복사 · 조사 훅(`$9F56`·`$90E8`) · 반각 `,` `.` 글리프.
- `kr.py` — 표기(`⏎` 개행 · `<hh>` 제어 · `<E0:n>` 사전 · `<pad:N>` · `{은/는}` 정적 조사 · `{*은/는}` 런타임 조사) → 바이트, 글리프 배정(결정적, 갈무리 11px 12×12).
- `typeset.py` — 대사창 규격 조판(줄 50단위 = 전각 3·반각 2 · 쪽당 본문 3줄 · 어절 단위). 화자 머리 `<1e>이름<04>` 줄은 안 센다.
- `tm.py` — `dump`(구간 덤프, PS1 문장 제안) · `draft`(PS1 일치 초안) · `put`(번역 병합 — 원문 해시 계산) · `stats`.
- `ui.py` · `relocate.py` · `script.py` · `glyphmap.py` · `hangul_font.py` — 창 블록·문자열 이전·대사 문법·글리프표.

## 알아 둘 규격 (에뮬 실측)

- 대사창: 줄 200px(전각 16자 + 반각 1칸) · 쪽당 본문 3줄 + 화자 줄. `<05>` = 키 대기 + 쪽 지움.
- 반각 글꼴은 ASCII 순서가 아니다 — `!`=$21 · `?`=$22(인코딩이 처리) · `,` `.` 는 우리가 그렸다 · `% & ' ( )`($25~$29)는 HUD 조각이라 안 쓴다(`kr.HALF_OK`).
- 아이템 이름 레코드 14B(7전각 칸) — 한국어 이름이 15B 인 셋이 칸보다 길다(아래 「관리자에게」).
- 1바이트 글자 `$88~$DF` = 반각 가타카나(JIS X0201 배치, `$E1C9` 기준).
- 세이브스테이트로 에뮬 시간 단축: `.local/keep/saves/sfc-ed2/field-start.mss`(필드 시작 직후) — 다른 빌드 롬에서도 `load_state` 가 된다. 에뮬 조작 요령은 devlog.

## 관리자에게 (판정·후보 — 정본에 없는 것)

- 정본에 없는 이름 후보: 지역 `エメ`($CB:30E9[26]) · 주문 자리표시 `MG14·MG15·MG22`(원판 미사용) · 아이템 `？？？？？71~75`(미사용).
- 아이템 이름 셋(`성스러운 지팡이` · `마리스카의 친서` · `길모아의 무지개`)은 새 표(16B 칸) + 소비자 스텁으로 글자를 전부 넣었다. 정본 표기(15B) 그대로이고, 출력기가 줄 끝 불완전 타일을 버리던 결함·장비 창의 `$120F` 덮기를 고쳐 사용·장비 창에 끝 글자까지 나온다(devlog 10-13). 전투 「무기」 창·상점은 미확인.
- 타이틀 메뉴 `データを削除する` → 「데이터를 삭제한다」(정본에 같은 원문 없음, ED1 정본 「データをけす→데이터를 지운다」 참고) · `はじめから冒険する` → 「처음부터 모험한다」(ED1 정본).
- 저장·로드 안내가 칸(25B) 때문에 해요체(「…할까요?」) — 합쇼체 「…하시겠습니까?」가 칸에 안 든다(인덱스로 읽는 26B 레코드 — 코드 패치로 넓히면 가능).

**디버그 명령 계통 — 실제로 살아 있다.** 입력 루프(`$C1:E271`)의 `$C1:E2A5~E2BA` 가 `$0131` 비트7 **그리고** `$137A` 비트7 이면 `C0:0995` 가 `$1377~$1380` 7바이트를 16진 글자 13개(`$136A~$1376`)로 펴고 `$137A` 를 지운 뒤 `$C1:E43F` 로 간다.

**③ 쓰이지 않는 것** — 【코드 읽기】 롬 안 원본 파일명이 자원 머리에 남아 있다: `ED1~ED6.BIN`(6) · `OP1~OP9.BIN`(5 없음, 6 두 곳) · `EPOMARK.BIN`(두 곳) · `F1MAP/F2MAP` · `BBG00~12.CGT`(8) · `BBG_01~16.SCT`(16) · `TIJOU/TIKA.MD7`(모드7 지상·지하) · `MAPnnn.BIN` 171개(1~186 중 107·108·113·114·132·134~142·144 이름 없음). **어느 것이 실제로 안 쓰이는지는 안 따라갔다**(맵 이동 표·엔딩 장면 호출을 추적해야 한다 — 다음 라운드). 이미 알려진 미사용 이름 후보는 위 「관리자에게」 절(지역 `エメ` · 주문 `MG14·MG15·MG22` · 아이템 `？？？？？71~75`).

**④ 오마케류 — 못 찾았다.** 롬 전체에서 영문 4글자 이상 덩이를 뽑아 보고, `DEBUG·TEST·SOUND·MODE·WARP·CHEAT·MENU·FALCOM·Copyright·(C)·OMAKE·STAFF·SPECIAL·ENDING` 을 대소문자로 찾았다. 걸리는 건 타이틀 로고 문자열(`$D7:0EB1`) · 헤더 내부 이름 · 대사 속 레버 라벨 `LOCAL`(`$C4:C655`)과 위 자원 파일명뿐이다. 가나·SJIS 쪽은 대사 구간 전수(번역 정본)에 이미 들어 있고, 개발자 방·제작진 메시지로 보이는 구간은 없었다(스태프롤은 번역 완료).

## 시험 수단 — 강제 조우 (빌드에 안 넣음)

필드 모드 진입(`$C1:9FDC`)을 시험 ROM 에서 스텁으로 갈아 `JSL $C1:2663`(전투 시작, A=조우 번호)을 한 번 부른다. 스크립트: `.local/work/inbox/sfc-ed2/mkbattle-test.py <번호>`
(빌드 ROM → `/tmp/w/battle.sfc`). 1번 = 슬라임 둘(약함), 3번 = 강함. 새 게임 → 필드 진입 직후 전투 화면. 조우 번호는 `$12B0`, 게임 모드 변수는 `$0106`(4 = 전투).
조사 훅 에뮬 확인: `{*은/는}`·`{*을/를}` 이 「요크슬라임B는」「아트라스를」「아트라스는」 로 바르게 나왔다(받침 있는 이름 끝은 아직 못 봄).

## 시험 수단 — 엔딩 강제 호출 (빌드에 안 넣음)

필드 진입 스텁이 `$C1:C2FF`(엔딩 8장면 + 스태프롤)를 부른다. 스크립트 `.local/work/inbox/sfc-ed2/mkend-test.py C1C2FF`(→ `/tmp/w/end.sfc`), 구운 칸 `work/build/sfc-ed2-endtest/`. 새 게임 → 사운드 확인 → 엔딩 자동 재생(약 4만 프레임). 보스 앞 세이브(맵·진행 플래그 변수 미확인)는 마스터 10-13 판단으로 중단 — 알아낸 것은 devlog.
