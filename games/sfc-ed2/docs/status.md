## 알아 둘 규격 (에뮬 실측)

- 대사창: 줄 200px(전각 16자 + 반각 1칸) · 쪽당 본문 3줄 + 화자 줄. `<05>` = 키 대기 + 쪽 지움.
- 반각 글꼴은 ASCII 순서가 아니다 — `!`=$21 · `?`=$22(인코딩이 처리) · `,` `.` 는 우리가 그렸다 · `% & ' ( )`($25~$29)는 HUD 조각이라 안 쓴다(`kr.HALF_OK`).
- 아이템 이름 레코드 14B(7전각 칸) — 한국어 이름이 15B 인 셋이 칸보다 길다(아래 「관리자에게」).
- 1바이트 글자 `$88~$DF` = 반각 가타카나(JIS X0201 배치, `$E1C9` 기준).
- 세이브스테이트로 에뮬 시간 단축: `.local/keep/saves/sfc-ed2/field-start.mss`(필드 시작 직후) — 다른 빌드 롬에서도 `load_state` 가 된다. 에뮬 조작 요령은 devlog.

| 타이틀·필드 | → | 맵 전체 공개(오토맵) | 그 판 |
| 타이틀 | **Y** | 느닷없이 엔딩(안내 뒤 A → 엔딩 → 스태프롤 자동 재생, 약 4만 프레임) | 안전 |
| 타이틀 | **Start** | 사운드 모드 — 사운드(BGM 1~32)·효과음(1~94)을 ↑↓·←→ 로 고르고 A 로 재생, 「사운드 모드 종료」로 닫기 | 안전 |
| 타이틀 | **B** | 몬스터 일람 — ↑↓ 로 넘기며 전투 배경 위 몬스터를 본다(B 종료). 마지막 칸은 고드윈 2세의 농담 | 안전 |
| **필드 주메뉴**(B 로 연 뒤) | **Y** | **전투 스킵 토글** — 켜면 필드의 랜덤 조우가 판정 단계에서 지워진다(한 번 더 누르면 해제). 이벤트·보스 전투와 필드 몬스터 접촉은 그대로 | 안 남음(WRAM `$0B59`, 세이브 밖) |
| **필드 주메뉴** | **Start** | **워프 등록 49칸만 켠다**(전역 플래그 `$0441~$0471` — 시작 직후 첫 칸만 켜져 있는 걸로 보아 워프 등록표. 아이템은 안 줌) | ⚠ 세이브에 남는다 |
| **필드 주메뉴**(B 로 연 뒤) | **X** | **매직 코드** — 모든 아이템 지급 + 「워프로 전 지역에 갈 수 있다」(워프 해방) | ⚠⚠ **아이템이 세이브에 저장된다 — 진행·밸런스를 망가뜨린다. 시험 세이브에서만** |

- ⚠ 표시: 「그 판 전체」 플래그가 세이브에 저장되는지는 **확인 못 했다** — 저장하지 말고 시험한 뒤 버리는 편이 안전하다. 쓴 판의 세이브는 제품 세이브와 섞이지 않게 (DEBUG) 롬으로만 이어 간다.
- 타이틀·필드에서 쓰는 ↑↓←→ 는 메뉴 커서도 같이 움직이니(해롭지 않다) 눌러서 숫자·상태가 안 보여도 적용된 것이다 — 값은 효과(전투 보상 · 새 게임 능력치 · 맵)로 확인한다.
- 일본어가 남아 있는 곳(디버그 안내 메시지 · 몬스터 일람 이름)은 아직 번역하지 않았다(사용자용 진입로와 함께 다음 라운드).
- **구현**(참고): `tools/debug_patch.py` — 입력 루프 `$C1:E306`(버튼이 눌린 갈래 6바이트)을 `JSL` 로 돌려 롬 꼬리(`$DF:FE00~`, 338B)의 스텁이 조합을 읽고 원판 디버그 변수(`$137A`·`$137B~$1380`·`$0B57`)를 채운다. 끝에 원래 두 명령을 실행하고 `RTL`. 확인 캡처: `.local/work/inbox/sfc-ed2/debug/10·11`. 전투 스킵은 둘째 훅 — 랜덤 조우 판정(`$C1:9CE4` 의 `lda $11BF / and #$02`)을 `JSL` 로 돌려 `$DF:FFC0` 의 15B 스텁이 `$0B59`=`$A5` 일 때 조우 비트를 지운다(헤드리스에서 켬=전투 시작 · 끔=조우 없음 확인). 워프 등록은 스텁이 일곱 바이트(`$01EF~$01F5`)에 마스크를 OR 한다(스텁 호출로 값 확인).

## 디버그·일괄 검수 (헤드리스 실행기 — 10-18, 마스터 「기능만 만들어두고 번역이 끝나면 돌리자」)

**기능만 만들어 뒀다 — 전수는 씬·전투 번역이 끝난 뒤 다시 지시받아 돈다**(번역 전 기종 일본어가 섞여 나온다). 롬은 **제품 롬 그대로**(패치 없음), 에뮬 호출(emucap) 0번 — Mesen2 `--testRunner` + Lua(sfc-ed1 과 같은 방식).

```
python3 games/sfc-ed2/tools/headless/sweep.py setup                 # emucap 의 Mesen 빌드를 work/derived/headless/ 로 복사
python3 games/sfc-ed2/tools/headless/sweep.py mkstate battle|dialog  # 부팅해서 시작 상태 파일 — 롬이 바뀌면 다시
python3 games/sfc-ed2/tools/headless/sweep.py battle --groups 0-98 --seeds 1 --frames 4000 --jpp 3 --procs 4
python3 games/sfc-ed2/tools/headless/sweep.py dialog [--limit N]     # 대사 단위(메시지 3,364개) 직접 호출
.venv/bin/python games/sfc-ed2/tools/headless/sweep.py report work/review/headless/<battle|dialog>/<tag>   # 접촉 시트 + 표(PIL 은 .venv 에만)
```

- **전투**(`battle_sweep.lua`): 필드 진입 직전 상태를 불러 `$C1:2663`(전투 시작, A=조우 번호)으로 보낸다 — 군 번호 0~98(조우 번호는 `0x00~0x1D · 0x20~0x3E · 0x40~0x53 · 0x60~0x71`). 파티 HP 999(메시지 입구마다 복원)·자동전투 켜기(`$0536` 비트0), 적 HP 9999(1000프레임마다 2500 으로 내려 HP 임계 행동 유도), **난수 루틴(`$C1:1E3A`)의 반환을 몬스터 코드(`$D4·$D5`)에서 호출 자리별 순번으로 덮어** 분기를 강제한다. 난수 씨는 `$1C24`. 메시지 입구(`$C0:A6E8`)에서 캡처 + 40·90프레임 뒤 캡처(타이핑이 끝난 화면은 90프레임 쪽). 산출 `raw/<군>_s<씨>/*.png` + `log.txt`(`M` = 메시지 호출 포인터, `END` 있는 작업만 완주).
- **대사**(`dialog_sweep.lua`): 필드 첫 메시지 호출 입구 상태를 열고, 단위마다 `$A6~$A8` 포인터만 바꿔 같은 메시지 루틴으로 찍는다(A 를 45프레임마다 눌러 쪽을 넘김). 호출자 복귀 지점(`$C1:8F14`)에 닿으면 그 단위 끝. 문맥(플래그·NPC)은 재현 안 한다 — 줄바꿈·고아 부호·첫 칸 공백·빈 줄·글리프·조사 훅 검수용이고 화자 관계는 눈으로 본다.
- ⚠ **함정(실측)**: ① `--testRunner` 는 기본 **벽시계 100초**에서 말없이 죽는다(작업이 `END` 줄 없이 사라진다) — `--timeout=<초>`(sfc-ed1 이 찾음, `sweep.py` 가 1800 을 준다)로 푼다. 그래도 작업을 많이 몰지 않고(`--jpp`·`--procs`) 상태 파일로 부팅 3,000프레임을 건너뛴다. ⑥ `emu.loadSavestate` 는 CPU 실행 콜백(NMI `$C0:0FC0` 등) 안에서만 된다(endFrame 에서 부르면 오류). ⑦ 사이트·읽기 콜백을 넓게 달면 속도가 반토막이다 — 기본 끔. ② 같은 로그 번호(`job`)는 프로세스마다 다시 1부터라 표에서 군 번호로 풀어야 한다(`report.py` 가 한다). ③ 메시지 포인터 로그만으로는 「그 문구가 화면에 나갔나」를 못 센다 — 문구가 조각(이름 버퍼 `$053B`~·조사 조각)으로 나뉘어 `$A6` 로 안 보이는 조각이 있다(군 1 의 「…차가운 시선…」이 포인터엔 없는데 화면엔 나왔다). 커버리지는 **화면 캡처**가 정본이다. ④ 보스·이벤트 전투(군 81·82 등)는 대사·연출이 얽혀 4,000프레임으로 못 끝난다 — 분리 목록. ⑤ 파티 HP 999 는 후반 군에서 모자란다(군 98 에서 1,308 피해로 전멸) — 필요하면 9999.
- **표본 검증(16군, 10-18)**으로 찾아 고친 것: 「그러나 운 좋게/나쁘게」 뒤 이름 앞 띄어쓰기 없음(`$C17F93`·`$C17F9F` 앞에 공백) · 「자고 있다」 앞 첫 칸 공백(`$C180AB`) · 긴 이름 몬스터의 「빛의 고리를 날렸다.」에서 마침표가 다음 줄로 넘어가는 고아 부호(`$D5D40C` 에 줄바꿈). 같은 **고아 부호 꼴**은 이름 길이에 따라 다른 문구에도 날 수 있다 — 전수에서 시트로 잡는다(정적으로는 이름 폭×문구 폭 조합 검사 후보).

## 시험 수단 — 강제 조우 (빌드에 안 넣음)

필드 모드 진입(`$C1:9FDC`)을 시험 ROM 에서 스텁으로 갈아 `JSL $C1:2663`(전투 시작, A=조우 번호)을 한 번 부른다. 스크립트: `.local/work/inbox/sfc-ed2/mkbattle-test.py <번호>`
(빌드 ROM → `/tmp/w/battle.sfc`). 1번 = 슬라임 둘(약함), 3번 = 강함. 새 게임 → 필드 진입 직후 전투 화면. 조우 번호는 `$12B0`, 게임 모드 변수는 `$0106`(4 = 전투).
조사 훅 에뮬 확인: `{*은/는}`·`{*을/를}` 이 「요크슬라임B는」「아트라스를」「아트라스는」 로 바르게 나왔다(받침 있는 이름 끝은 아직 못 봄).

## 시험 수단 — 엔딩 강제 호출 (빌드에 안 넣음)

필드 진입 스텁이 `$C1:C2FF`(엔딩 8장면 + 스태프롤)를 부른다. 스크립트 `.local/work/inbox/sfc-ed2/mkend-test.py C1C2FF`(→ `/tmp/w/end.sfc`), 구운 칸 `work/build/sfc-ed2-endtest/`. 새 게임 → 사운드 확인 → 엔딩 자동 재생(약 4만 프레임). 보스 앞 세이브(맵·진행 플래그 변수 미확인)는 마스터 10-13 판단으로 중단 — 알아낸 것은 devlog.
