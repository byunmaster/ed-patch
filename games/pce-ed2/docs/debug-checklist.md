# 디버그 메뉴 확인표 (마스터 인게임 확인용 — 10-22 Q8)

마스터 10-22 「디버그메뉴 여는법은 일단 보류, 디버그메뉴가 잘 동작하는게 확인되면 그때 넣자」. 아래를 제품 롬(`work/build/pce-ed2/ed2.iso`)에서 차례로 확인하고
칸에 ✅ / ❌ / 메모를 적는다. 열쇠는 사이트·배포 문서에 안 올린다(`debug-notice.md` 는 보류).

**여는 법**: 필드(걸어 다니는 화면)에서 **RUN 을 쥔 채 I 와 II 를 함께** 누른다. 닫기는 II. 전투 설정 창은 아래 ⑭.
⚠ 저장을 바꾸는 항목(WARP · LVL · GOLD · ITEM · MAGIC)은 **쓰기 전에 세이브를 따로 두고** 시험한다(라벨 뒤 `!`).

| --- | --- | --- | --- | --- |
| 1 | 메뉴 열기 | 필드에서 RUN+I+II | 창이 열려 14줄(WARP! … VISUAL)과 맨 아래 좌표 두 줄이 보인다. 글자 안 꺾임(MAGIC! 의 `C!` 포함) | |

## 알려진 한계 (10-22)
- 14·15 는 **하네스로 화면을 못 얻었다** — 자동 전투 루프(`$68D6`, 캐릭터 상태 `$E8B6` 의 비트 0·1 이 서야 `$68E3` 의 패드 검사로 간다)에 도달하는 조건을 맞추지 못했다. 분기 코드(`$6902` → `$7F3A`: RUN 쥠이면 `$690D`, 아니면 `$6905`)는 바이트와 논리로 확인했다. **마스터 인게임 확인이 제일 빠르다.**
- 4~13 의 효과는 코드 읽기 위주다(`debug-mode.md`) — 이 표가 그 실측이다.
- 1282 멈춤이 이 창을 되살린 대가로 줄었다(102 → 52/102) — 판정 Q5 「2」.
