## 전투 로그 런타임 어절 줄바꿈 훅(10-18 마스터 「로그성 메시지는 개행 없이 엔진이 어절 단위로」) — 코드 `tools/wrap.py` · 시험 `tools/tests/test_wrap.py`
- **상태**: ✅ 훅 둘 구현·실엔진 확인(헤드리스). 화면: 긴 문장이 어절 경계에서 넘어가고(「슬라임이 아트라스의 공격을 / 받아 해치웠다 …」) 이름이 어절 첫머리일 때 통째로 다음 줄로 간다(「공격을 / 슬라임A…」 — 훅 없이는 「슬 / 라임A」로 쪼개졌다). 제품 롬에 들어갔다(아래 sha).
- **엔진 사실(실측)**: 글자 단위 줄넘김만 있다(`$67CC`: 글리프 직전 `x+폭 > 2*$79-1` 이면 줄 넘김). 어절 개념·앞보기 없음. 폭 단위 4px: 글리프 3 · ASCII 한 바이트 2(반각 8px) · 공백 `60` 1. 줄 한계 = `2*$79-1`(=43). 줄 넘김 = `JSR $4812; BIT $6806`(`0D` 와 같다 — 줄 머리면 아무것도 안 함). 메시지는 작업 버퍼 `$30E5` 로 복사돼 찍히고, 이름 `13 nn` 은 런타임에 `$E78E` 로 펼쳐진다(그때 `$7C` 는 이미 이름 쪽 — 이어질 글 포인터는 소프트웨어 스택 `$EA04,X`(`$8C`=깊이)의 맨 위 넷 `$7D $7C $2C0B $2C07`).
- **훅**: ① 공백 `$675C` — 공백 뒤 다음 어절 폭을 읽어 `x+폭 ≥ 한계`면 공백 대신 줄 넘김 ② 이름 펼침 끝 `$6948` — 이름 폭 + 바로 붙은 글자(조사)가 줄에 안 들어가면 이름 앞에서 줄 넘김. 코드 241B 는 뱅크 0x71 `+0x13FB`(0xFF 패딩 머리, 글리프 풀 용량 −15자 안팎).
- **켜는 조건**: 스트림이 작업 버퍼(`$30xx~$31xx`)이고 창이 전투 로그 창(`$77~$7A` = 2·0x11·0x16·9)일 때만 — 메뉴·대사의 공백 정렬은 그대로.
