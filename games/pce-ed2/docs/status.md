## P0 확정 구조 (10-12 — 코드: `tools/{package,repack,hook,font,build,asm,sim6280}.py`)
- ✅ **씬 패키지** = 128섹터 간격(rel 258 · 386 · 514 …, 거울 +36,864), 보통 78섹터를 뱅크 0x73~ 에 올린다. 앞 8KB `$8000` 에 `4c..` JMP 셋 + **3바이트 머리표**(`[상대 뱅크][lo][hi]`, 항목 n 은 3n 위치 — 엔진 `$4743`).
  포인터 부호화(`$46EF`): hi 윗 3비트 = 뱅크 가산, 아래 5비트 = 뱅크 안 주소 → 패키지 바이트 오프셋 = `뱅크*8192 + ((hi&0x1F)<<8|lo)`.
  **항목 4 = 메시지 포인터 표**(2B씩, `$AF` = 메시지 번호 → LZ 덩이 시작). 덩이는 이어 붙어 있고 **각자 링을 새로 시작**하며, **전 덩이가 다음 덩이 시작에 정확히 닿는다**(rel 386: 26덩이 · 마을·성 계열 12패키지를 `package.py --check` 게이트로). 표 뒤 첫 덩이 ~ 마지막 덩이 뒤 **0xFF 채움**(rel 386: 5,668B)까지가 대본 영역.
  게임은 덩이 안에서 앞부터 `00` 을 세어 줄을 고른다(`$7DA2` → `$7D84` → `$5796`, 건너뛰기 `$7DC0`). 항목 3 = 이벤트 코드(`$8100`), 항목 5 = 다른 표(rel 414~).

- ✅ **글리프 이음매** `$60D2`(뱅크 0x6C): `JSR $60EA`(4칸 표 조회, 맞으면 24B→`$309B`·C=0) → 미스면 BIOS. 인터프리터(뱅크 0x71 `$672F`): `<$20` 제어 · `$60` 공백 · `$80~$9F`·`$E0~` = **2바이트(리드)** · `$A0~$DF` = 단일 바이트 가나. → 리드 `F0~F8` 을 우리 코드 공간으로(ED1 과 같다). 트레일은 **0 금지**(줄 건너뛰기가 00 을 센다), 0x24~ 사용.
- ✅ **후킹** `hook.py`: 피연산자 2바이트만 바꿔 우리 루틴(뱅크 0x6C `+0x1966`, 0xFF 패딩)을 부른다. **글리프 풀 = 본 프로그램(rel 130, 뱅크 0x68~0x71) 안의 0xFF 패딩**(디스크·런타임 모두 불변, 합 ~13.4KB = 18B 묶음 745자). 칸마다 (글리프 수·뱅크·주소) 표, 루틴이 뱅크를 MPR4 에 잠깐 걸어(SEI) 읽는다. 논리는 `sim6280.py` 시뮬레이터 테스트로 검증, 실제 화면으로 확인(캡처 `.local/work/inbox/pce-ed2/002-…`).
