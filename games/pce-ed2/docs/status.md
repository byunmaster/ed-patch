## P0 확정 구조 (10-12 — 코드: `tools/{package,repack,hook,font,build,asm,sim6280}.py`)
- ✅ **씬 패키지** = 128섹터 간격(rel 258 · 386 · 514 …, 거울 +36,864), 보통 78섹터를 뱅크 0x73~ 에 올린다. 앞 8KB `$8000` 에 `4c..` JMP 셋 + **3바이트 머리표**(`[상대 뱅크][lo][hi]`, 항목 n 은 3n 위치 — 엔진 `$4743`).
