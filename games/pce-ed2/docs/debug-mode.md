# pce-ed2 — 디버그 모드(숨은 개발 기능) 분석 (10-16 착수, 진행 중)

> 규칙: 롬은 고치지 않는다(시험 빌드 `test-*`, 쓰고 지움). 실측 = 에뮬 확인, 코드 읽기 = 디스어셈블만. 캡처 `.local/work/inbox/pce-ed2/debug/`.
> 좌표: 「본 프로그램」 = rel 130(뱅크 0x68~0x71, 뱅크 0x68+k = 파일 k번째 8KB). 필드 때 MPR3($6000)=0x6A · 메뉴 코드/글=0x69·0x6A.

## 확정(실측)
- **입구**: 필드(MPR3=뱅크 0x6A) 입력 처리 `$6057~`가 RUN(`$332A` bit3) → `JMP $6099`. `$6099` 루틴(코드 읽기 + BP 실측)은 `JSR $571E`(입력 갱신) 뒤
  `TST #$04,$26E5`(SELECT) 이고 `BBR7 $86`(개발기 게이트)이 서 있으면 디버그 메뉴(`JSR $4800; BIT $73E5` → 뱅크 0x69 `$73E5`)를 띄운다.
  게이트가 없거나 SELECT 가 없으면 RUN 을 떼는 동안 대기(`$80`bit4)하다 필드로 돌아간다.
- **게이트 `$86` bit7**: 부팅 때 `$41DF`(뱅크 0x68)가 `$86=$3B`, `$87=0` 으로 두고 **`$20` bit7(IPL 이 개발기 RAM 을 확인해 세움)이 서 있으면** `SMB7 $86`. 일반 PC엔진/에뮬에서는 `$86=$3B`(bit7 없음, 실측 0x3B).
- **메뉴를 띄운 방법(실측, 롬 무수정)**: 필드에서 RAM `$2086 = 0xBB`(bit7 세움) → RUN 을 눌러 `$609E` 에서 멈춤 → `$26E5 = 0x04` → 재개. 화면: 캡처 `001-menu-open.png`.
- ⚠ **RUN+SELECT 를 30프레임 이상 같이 누르면 게임이 스스로 소프트 리셋**(`$4159~`: `$2228==$0C` 가 30프레임 → `JMP $E000`). 짧게(<0.5초) 누르면 안 걸린다.
- **메뉴 항목(14)**: `WARP · LVL · GOLD · ITEM · MAGIC · PATH · ENTRY · MASK · ENCNT · SPOT · A · B · C(라벨 ATRB) · VISUAL` + 맨 아래 두 줄 좌표(`X0308 ,V0158` / `X0298 ,V0148` — 플레이어·화면 좌표).
  토글 상태는 `$86` bit0 PATH · bit1 ENTRY · bit2 MASK · bit3 ENCNT · bit4 SPOT · bit5 VISUAL, `$87` bit3/2/1 = A/B/C (초기 `$86=$3B` = PATH·ENTRY·ENCNT·SPOT·VISUAL ON, MASK OFF — 화면과 일치).
- **WARP**(`002-warp-list.png`): 목록 「デバッグ村(디버그 마을)·엘아스타·루디아·크루즈·베르가·네리아·론도」. 첫 항목 선택 시 영어 배너 「ETC. TEST」의 시험 맵(엘아스타 마을 풍 타일 + 파란 갑옷 NPC 줄, `003-etc-test-map.png`)으로 들어간다.
- **LVL**: 레벨 +1(L01→L02, 필드 레벨업 문구 「…はレベルアップした / 最大HPが 6ポイント あがった」 — 일본어 그대로. 이 문구는 전투 쪽 레벨업과 같은 계열이면 정규 플레이에서도 나올 수 있다 — 미확인). `004-lvl-levelup.png`.
- **ITEM / MAGIC**: 아이템 목록(나이프·소형검·청동검·철검·…)·마법서 목록(`005`, `006`) — 선택하면 소지품에 추가(코드 읽기, 인벤토리 확인은 아직).
- **GOLD**: 코드는 `$E9A0~` 의 3바이트를 읽어 시프트(3번)하는 계산 — 실측으로 골드 변화는 못 봤다(필드 하단 Gold 0 그대로).
- 토글 PATH → OFF 표시 확인(`007`은 SPOT OFF). 효과(통과·표시)는 아직 항목별로 못 갈랐다.

- 필드 입력 처리의 또 다른 개발자 게이트: `$6086 BBR7 $86` — 게이트가 서 있으면 **I 를 누른 채 이동 시 `$31EA=$40`(고속 이동)** (코드 읽기).
- 화면 문구: 항목 이름은 전부 반각 ASCII(`WARP LVL GOLD ITEM MAGIC PATH ENTRY MASK ENCNT SPOT ATRB VISUAL`, `ON `/`OFF`, 좌표 `X`·`V`+4자리 16진). 일본어(원판 글) = WARP 목적지 이름(`デバッグ村` + 마을명은 정본 한글로 보임) · 아이템/마법서 목록(정본 한글 + 「の書」) · LVL 레벨업 문구(일본어 그대로, 미번역). 칸: 메뉴 창은 좌측 상단 약 11열×14줄(스프라이트 창, 반각 한 글자 8px).

## 들어가는 조건 · 막는 것
- 원판(일반 PC엔진/에뮬)에서는 **안 열린다** — 막는 것은 `$86` bit7 하나(부팅 때 `$20` bit7 이 서야 세움; IPL 이 개발기 RAM 을 확인해 세운다). 다른 조건: 필드에서 RUN 을 누르는 중 SELECT(`$26E5` bit2) 한 번 더.
- **함정**: RUN+SELECT 를 30프레임(0.5초) 이상 같이 누르면 `$4159~` 가 소프트 리셋(`JMP $E000`) — 진입 때 짧게 눌러야 한다.

## 진입로 안(마스터 선택 전 — 구현 없음)
1. **A: 게이트만 연다** — `$41E4 BBR7 $20,$41E9`(1~3바이트)를 무조건 통과(또는 `$86` 초기값을 `$BB` 로)로. 그러면 **필드에서 RUN 짧게 + SELECT** 로 열린다. 위험: 일반 유저가 RUN+SELECT 를 길게 누르면(30프레임↑) 리셋(원판 동작) · `$6086` 고속 이동(I)이 같이 켜진다.
2. **B: 게이트 + 키 조합 교체** — A 에 더해 `$609E TST #$04,$26E5` 의 비교 값을 다른 버튼(예 II=`$02`)으로 바꿔 SELECT 리셋 함정을 피한다(+1바이트). 원판 일시정지(RUN 누른 채 기다림)는 그대로.
3. **C: 타이틀/부팅 숨김 명령** — 부팅 패드 지름길(I/II 표 `$4075`)처럼 시작 때 특정 조합(예: I+II+SELECT)에서만 `$86` bit7 을 세운다. 평소 플레이에는 영향이 전혀 없다. 구현량은 가장 크다(IPL 쪽 분기 + 빈 공간).
- **위험 표시**(세이브·진행 플래그를 바꾸는 항목 ⚠): ⚠ **WARP**(진행 상태와 무관한 맵으로 이동 — 시험 맵은 되돌아오는 출구가 있는지 미확인, 이벤트 플래그를 건너뜀) · ⚠ **LVL · GOLD · ITEM · MAGIC**(저장 데이터를 바로 바꾼다 — 이후 세이브하면 영구). 토글류(PATH·ENTRY·MASK·ENCNT·SPOT·A·B·C·VISUAL)는 `$86`/`$87`(영 페이지 RAM)만 바꾼다 — 세이브에 들어가는지는 미확인.
