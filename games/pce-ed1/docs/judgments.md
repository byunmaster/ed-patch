   ### 09-15 (3) — ① 디스크 원좌표: VRAM 쓰기 BP 부정 결과, 여기서 멈춘다

   패턴 주소 공식을 정정했다 — `$380` 의 실제 VRAM 바이트는 `0xE000` 이 아니라 **`0xE020`**
   (32B 어긋남, 상수 소스 미상). 그 자리에 **쓰기 BP 를 걸고 리셋→부팅→타이틀→새 게임→침실**을
   스킵 없이 돌렸는데 **한 번도 안 걸렸다** — 그런데 그림은 화면에 정상으로 뜬다. ⇒ **자료는
   맞는 자리에 있는데, 거기 쓰는 순간을 이 BP 가 못 잡는다.** 추정 원인: PCE VRAM 쓰기는
   VDC 데이터 포트($0002/$0003, MAWR 오토인크리먼트) 경유라 **`vram0` 메모리공간 쓰기 BP 가
   보는 경로가 아닐 수 있다**(전투·씬 텍스트 RAM 스테이징 때와 다른 부류).
   대안으로 `$EA9C`(CD 전송 루프) 실행 BP 는 걸렸지만 **부팅 중 수십 번 불려** 목표(HUD
   스프라이트 전송)를 가리는 조건을 아직 못 세웠고, 한 번 멈출 때마다 클리어→스텝→재무장
   세 콜이 들어 몇 회 만에 예산을 넘긴다.
   ⇒ **여기서 멈춘다** — ③(이번 회차 핵심)은 값으로 닫혔고, ①은 **"VRAM 쓰기 BP 로는 안
   된다"는 부정 결과**만 확실하다. 다음 수: VDC 포트 쓰기 BP + 목표창 좁히는 조건, 또는

- 🔴 **`$726E` 트레이스 완료 — 관리자 지시대로 여기서 멈춘다.** 완전히 디스어셈블했다:

  ```

         LDA $38BE / CMP #$07 / BNE ...     ; 상위 바이트가 7이 되면(±저위 바이트 조건까지 봐서)
         (아니면) LDA $38BD / SBC #$A0 / ... ; 저위에서 0xA0 을 빼는 랩어라운드(타일 풀 크기로 보인다)
  ```
