# pce-ed1 플레이 매뉴얼

QA 를 돌리기 전에 읽는다. 규약은 루트 [`docs/ingame-qa.md`](../../../docs/ingame-qa.md).
여기엔 **이 게임을 실제로 굴려 본 것만** 적는다 — 추측은 「미확인」이라고 쓴다.

🔴 **이 문서가 없어서 2026-09-07 회차를 접었다.** 조우율이 100% 인 자리에서 메뉴를 못 열었고,
마을까지 걸어가느라 전투 여덟 판에 HP 가 20 → 15 로 깎였다. 아래 「전투가 나는 자리」 세 줄만
있었으면 그 회차가 닫혔다.

## 조작

| 무엇 | 버튼 | emucap 이름 |
| --- | --- | --- |
| 확인·말걸기·결정 | Ⅰ | `i` |
| 취소 | Ⅱ | `ii` |
| 메뉴·시작·진행 | RUN | `run` |
| 커서 | 십자 | `up` `down` `left` `right` |

⚠ **필드(오버월드)에서 `run`·`ii` 로 커맨드 창을 못 열었다**(2026-09-07). 버튼이 다른 것인지
**조우가 먼저 떠서**인지 **아직 못 갈랐다** — 마을 안에서 다시 해 봐야 한다.

### emucap 으로 굴릴 때

- 🔴 **`tap` 은 안 먹는다.** `input_control` → `pulse_while_running` 을 쓴다.
  - 버튼 한 번 = **10~12프레임** · 이동 한 칸 = **40~70프레임**(짧으면 안 움직인다)
- **어트랙트(로고·별밤)는 `step` 으로 넘긴다** — 그 구간엔 입력이 튕긴다.
- 전투 한 판 ≈ **1,300~1,400프레임**. 승리창까지 그 정도 `step` 하면 된다.
- ⚠ **행동 메시지 창(「◯의공격」)은 한두 프레임대로 지나간다.** 캡처를 노리지 말고
  **스트림 동일성**(그 조각이 마지막 캡처 이후 바뀌었나, `git log -L`)으로 대는 게 싸다.
- ⚠ **캡처로 글자를 판정하지 않는다** — 341×232 라 `ㅏ`/`ㅣ` 가 안 갈린다. 확대하거나 바이트를 댄다.
- ⚠ 빌드를 갈면 **프로세스를 죽이고 다시 띄운다**(mednafen 디스크 캐시).
- ⚠ 실행 중 `write_memory` 는 **첫 바이트를 놓치는 경합**이 있다 — 쓴 직후 되읽어 확인한다.

## 부팅 순서 (콜드부트 → 세이브 로드)

1. `step` ~2,500프레임 → 시스템 카드 화면, **PUSH RUN** 이 뜬다 → `run`
2. `step` ~1,900 → 별밤 오프닝 → `run` 으로 건너뛴다
3. `step` ~1,000 → **타이틀**(Dragon Slayer, 영문 그림). `Beginning` / `Continue`
4. 이어하기: `right` → `i`
5. 🔴 **파일 선택 목록은 곧바로 안 뜬다** — `step` **~400프레임**을 더 준 뒤에 슬롯이 보인다.
   바로 `i` 를 누르면 빈 목록을 보고 「세이브가 없다」로 오진한다(실제로 그랬다).
6. 슬롯 1 에 커서가 있다 → `i` → `step` ~1,300 → 게임 시작

## 세이브 — 어디에서 시작하나

- 유저 세이브: `/root/save/pce-ed1/ed1.<이미지해시>.sav` → emucap 홈의 `sav/` 로 복사한다
  (`scripts/emu.sh` 가 이미지 해시에 맞춰 이름을 대신 맞춘다).
  🔴 **`mcp__emucap-control__launch` 를 직접 부르면 이 동기화를 건너뛴다**(09-15 실측) —
  `/root/save/`의 파일명은 `ed1.<해시>` 인데 emucap sav 폴더는 `ed1-kr.<해시>` 라 **체계부터
  다르다.** 직접 launch 했을 땐 파일 선택 화면이 **셋 다 비어 보인다**(`ファイルがありません`)
  — 세이브가 없는 게 아니라 안 실린 것이다. `scripts/emu.sh` 경로로 띄우거나, 안 되면
  받은 `.sav` 를 emucap sav 폴더에 **`ed1-kr.<지금 빌드 해시>.sav`** 이름으로 손수 복사한다.
- **위치: 엘아스타 바로 남쪽 필드.** 1장, LV1, HP 30.
- 🔴 **2026-09-06(커밋 `ee4aa469`) 이전에 뜬 세이브는 파티 이름이 깨진다** — 글리프 배정을
  그때 정본으로 못 박았다. 그 전 세이브는 「서린온을」처럼 나온다. **새 세이브로 본다.**
- ⚠ **문안 검증에 세이브스테이트를 쓰지 않는다**(루트 CLAUDE.md) — 텍스트가 RAM 오버레이라
  스테이트가 곧 옛 빌드다. 리셋 + BRAM 정식 로드.

## 전투가 나는 자리 / 안 나는 자리

| 자리 | 조우 | 무엇을 보나 |
| --- | --- | --- |
| **유저 세이브 지점(엘아스타 남쪽 필드)** | 🔴 **사실상 100%** — 한 입력마다 뜬다 | **전투 QA 에 최적**(C1~C6). **메뉴 QA 는 불가능** |
| 오버월드 전반 | 높다 | 전투 |
| **엘아스타 안(마을)** | **없다** | **메뉴 QA(A·B 묶음)는 여기서** |

⇒ **메뉴를 보려면 마을 안으로 들어간다.** 세이브 지점에서 **위(`up`)로** 계속 가면 엘아스타다 —
2026-09-07 실측으로 **전투 여덟 판** 정도 붙는다(한 판마다 `i` → `step` 1,400 → `i`).
💡 **마을 안 세이브를 하나 떠 두면** A1·A3·A4·A5·B1·B2·B3·B5 여덟 칸이 한 번에 닫힌다.

## 진행 순서 (1장, 실측 구간까지)

1. **새 게임** — 침실에서 시녀가 깨운다. 아래로 내려가며 이벤트가 이어진다.
2. 성 밖으로 나가려 하면 **병사가 막는다**(「라이아스 님께서 왕자님을 밖에 내보내지 말라고…」).
   계속 아래로 가면 대화가 이어지고 **퍼거슨**이 개구멍을 알려 준다.
3. 개구멍으로 마을 밖 → 필드. **여기가 유저 세이브 지점**이다.
4. 필드에서 **위로** 돌아가면 엘아스타 재입장 — **「라이아스」 씬**이 뜬다.
   🔴 예전 빌드는 여기서 굳었다(후킹 페이로드 자리 문제, 2026-09-07 수정). **지금은 정상이다** —
   굳으면 그건 새 결함이니 보고한다.
5. 그 뒤(2장 진입 · 상점 · 도감)는 **아직 안 가 봤다 — 미확인.**

## 막히는 자리 (알려진 것)

- **성문 병사** — 대화를 끝까지 봐야 개구멍이 열린다(2번).
- **필드 조우율** — 위 표. 메뉴를 열려면 마을로.
- **도망** — 전투 커맨드에서 `down`·`down`·`right`·`i` 로 「도망」인데, 실측에서 커서가
  공격으로 되돌아가 실패했다. **한 번 더 확인 필요(미확인).**
- 2장 이후 요구 레벨·열쇠 따위는 **미탐색**.
