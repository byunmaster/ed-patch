# md-ed1 플레이 매뉴얼 — 어디로 가면 되나

`docs/ingame-qa.md`(레포 공용)가 시키는 매뉴얼이다. **QA 회차를 열기 전에 이걸 먼저 본다.**
⚠ 표시가 **실측**인 것과 **문안 근거**(대본에서 읽었을 뿐 아직 화면으로 못 본 것)를 갈라 적는다 —
안 가르면 다음 회차가 없는 길을 찾는다.

## 1. 조작 (실측)

| 무엇 | 버튼 |
| --- | --- |
| 확인 · 말 걸기 · 대사 넘기기 | **c** |
| 취소 · 창 닫기 | **b** |
| **메뉴 열기** | **b** (필드·실내) |
| 일시정지 | **start** — 화면이 회색으로 죽는다. **메뉴가 아니다**(한 번 오진했다) |
| 이동 | 십자키. emucap 은 `press_frames` 30~200 이 한 칸~여러 칸 |

🔴 **새로 시작한 직후에는 메뉴가 안 열린다**(실측 2026-09-07). 첫 대사부터 라이아스의 훈계까지는
b·a 어느 것도 안 먹는다. **세이브를 로드하면 열린다.** ⇒ **메뉴 계열(A1~A6·B1~B3) QA 는 반드시
「이어하기」로 들어간다.** 새 게임으로 열려다 회차를 한 번 태웠다.

## 2. 켜는 순서 (실측)

```
launch → start(600프레임) → 타이틀 로고 → start(300) → 「처음부터 / 이어하기」
  이어하기: down(4프레임) → c → 슬롯 목록 → c   ← 슬롯 1 「L 1 엘아스타」
  처음부터: c → 오프닝 약 15,000~16,000프레임 → 첫 대사(시녀) → 침실
```

🔴 **슬롯 목록의 마지막 줄이 「처음부터」다.** 커서 자리를 안 보고 c 를 누르면 **오프닝이 시작된다**
(두 번 밟았다). 슬롯 목록에서는 **반드시 화면을 한 번 찍고** 누른다.

⚠ **세이브 이름은 롬 md5** — 빌드를 새로 구우면 안 읽힌다(빈 슬롯 셋으로 보인다).
`python3 tools/import_save.py` 를 **빌드마다 한 번**. 에뮬레이터는 **띄울 때** 읽으므로 다시 launch.

## 3. 제1장 길 (실측 + 문안 근거)

| 자리 | 가는 법 | 근거 |
| --- | --- | --- |
| 침실 | 새 게임 시작 지점. 시녀가 깨운다 | 실측 |
| 복도 | 침실에서 **왼쪽** | 실측 |
| 왕좌의 방 | 복도에서 **왼쪽 → 아래** | 실측 |
| ↳ 라이아스의 훈계 | 왕좌 아래에서 **위를 보고 c** — 5창 | 실측 |
| 성 밖 | 왕좌의 방에서 **아래** ×2 | 실측 |
| 성문 병사 | 성 밖에서 **위**, 문 왼쪽 병사에게 c — 「외출하시옵니까」 | 실측 |
| 저잣거리 | 성 밖 갈림길에서 **왼쪽 → 아래** (카운터·노점) | 실측 |
| **마을 문(남쪽)** | 갈림길에서 **아래** ×2 — 병사 둘이 **막는다** | 실측 |
| **퍼거슨의 밭** | **남쪽 마을 문에서 오른쪽**(담을 따라). 뙈기 둘, 오른쪽 뙈기에 퍼거슨 | **실측 2026-09-07** |
| **개구멍(抜け道)** | 퍼거슨에게 부탁해 둔 길 — 여기로 **마을 밖**에 나간다 | 문안 근거 |

## 4. 🔴 막히는 자리

- **남쪽 마을 문은 못 지나간다.** 「기다려 주시옵소서, 왕자님. 라이아스 어르신께서 왕자님을
  밖에 내보내지 말라 하셨사옵니다.」 → 왕자 「그런가, 그럼 하는 수 없군.」 (실측)
- 🔑 **퍼거슨과 말이 트였다**(2026-09-07, `inbox/qa_scene_ferguson.png`).
  **맞닿는 자리가 까다롭다 — 왕자가 퍼거슨의 오른쪽 칸에 서서 왼쪽을 보고 `c`.**
  위·아래로는 여러 번 시도해도 안 열렸다(한 칸씩 어긋나 있었다). 대사는
  「퍼거슨 / 오, 왕자님!! / 지 소중한 밭을 망가뜨리지 말아 주십쇼요.」
- 🔑 **개구멍은 깃발 하나로 갈린다 — `$FF1B5C`.** 화면에서 찾지 말고 이 표를 쓴다
  (블록 104 모듈 코드를 디스어셈블해서 얻었다, 2026-09-07).

  | 비트 | 뜻 | 서는 자리 |
  | --- | --- | --- |
  | 3 | **성문에서 막히는 장면을 봤다** | 스트림 `0af6`(병사의 만류)을 그린 직후 `bset #3` |
  | 4 | 개구멍 대화(`0eee`)를 봤다 | 그 대화를 그린 직후 |
  | 5 | 「여기 있습니다요」(`0fe2`)를 봤다 | 그 대화를 그린 직후 |

  퍼거슨의 분기(`0x326`~): **비트 3 이 0 이면 밭 대사**(`0ea0`) · 1 이고 4 가 0 이면 **개구멍 대화**
  · 4 도 1 이면 `0fe2` → 그다음 → … **말을 걸 때마다 한 칸씩 나아간다.**
  ⇒ **순서는 「성문에서 한 번 막힌 다음 퍼거슨에게 간다」**이고, **부탁하는 장면은 게임 안에 없다**
  (대사의 「지난번에 부탁해 둔」은 게임 시작 전 이야기다 — 대본 전량을 훑어 확인했다).
- ⚠ **유저 세이브는 이미 비트 0·3·4 가 서 있다**(실측 `$FF1B5C = 0x19`). 즉 개구멍 대화는 이미
  지나갔고, **다음 대화는 `0fe2`「왕자님, 여기 있습니다요」부터**다. 계속 말을 걸어 끝까지 간다.
  💡 막히면 `read_memory cpu $FF1B5C` 한 번이 화면 스무 장보다 싸다.
- ⇒ **마을 밖으로 나가려면 퍼거슨의 개구멍**을 쓴다. 대본(블록 104)에 그 대화가 있다 —
  「야아, 퍼거슨. 지난번에 부탁해 둔 개구멍은 다 됐어?」 → 「왕자님, 자 어서 가십쇼.
  이건 라이아스 어르신께는 비밀입니다요.」 (문안 근거, **다음 회차의 첫 목표**)
- 🔑 **엘아스타의 상점은 도구점·무기점 **둘 다** 닫혀 있다**(대본 근거, 2026-09-07 확인).
  블록 107: 도구점 주인이 **오늘은 쉬는 날**이라며 아크담의 즉위를 이유로 든다 — **아크담의 즉위 때문에 쉬는 날**이다. 영업하는 도구점 문안은 **블록 108**
  에 따로 있다. ⇒ **B4(사다/팔다)는 개구멍을 지나 다음 마을에서 본다.** 엘아스타를 아무리 돌아도
  안 열린다(한 회차를 그렇게 태웠다).
- **엘아스타의 무기점은 닫혀 있다.** 대본: 무기점 주인이 빵집을 하고 있고(「그 아크담이 갑자기
  가게를 접으라고 하지 뭡니까」), 다른 이는 「론드로 가는 뱃길이 되살아났으니 무기는 론드에서」라고
  한다. ⇒ **B4(사다/팔다)는 이 시점에 안 열릴 수 있다** — 도구점을 먼저 보고, 안 되면 마을 밖.

## 5. 전투가 나는 자리 / 안 나는 자리

| | 자리 |
| --- | --- |
| **안 난다** | 성 안 · 마을 안(엘아스타 전역). **메뉴 계열 QA 는 여기서** |
| **난다** | **개구멍을 지나 나온 들판** — 몇 걸음이면 바로 만난다. 첫 몬스터는 **슬러그**(15HP, EP 1) |

**밖으로 나가는 전 과정(실측 2026-09-07)** — 세이브 로드 → **아래로 성 밖** → **계속 아래로 마을 문**
(병사가 막는 장면이 뜬다 = `$FF1B5C` 비트 3) → **오른쪽으로 담을 따라 밭** → 퍼거슨에게 **말을 세 번**
(개구멍 → 여기 있습니다요 → 고마워/별말씀을) → **위로 나가면 세계 지도**. 거기서 오른쪽 몇 걸음이면 전투.
💡 대사 사이가 길어 `after_frames` 를 짧게 잡으면 지나친다 — **비트를 읽어 진도를 확인**하는 게 확실하다.

🔴 **전투를 강제로 띄우지 않는다.** RAM 개입으로 전투를 여는 길이 `docs/status.md` 6절에 적혀
있지만, 객체 포인터를 잘못 주면 **DIV/0 로 게임이 죽는다**(실측). **게임을 불안정하게 만드는
개입은 그 자체가 오진의 원인**이다(레포 규약 `docs/ingame-qa.md`).
