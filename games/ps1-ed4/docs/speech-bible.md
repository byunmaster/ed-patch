# ED4 말투 정본 — 번역 에이전트 공용 한 장

씬 번역을 여럿이 나눠 해도 **한 인물의 말투가 갈리지 않게** 하는 표다(관리자 지시 10-24). 표기는 `shared/canon/nouns/ed4.json` 이 이긴다. 정본에 없는 이름은 `policy.md` 의 후보 표기를 쓴다.
예시 줄은 **우리가 이미 번역한 문안**(서장·1장·2장)이다 — 같은 인물의 새 대사는 이 결에 맞춘다. 인물 설정의 사실은 `story-bible.md`·`shared/lore/ed4.json`.

## 0. 원칙

- **원문 어미가 1차 자료다.** 아래 표는 요약이다. 표와 원문 어미(です·ます / だ·だよ / じゃ·おる / ございます …)가 갈리면 **원문을 따른다**(시점·상대에 따라 갈리는 데엔 이유가 있다).
- 등급: 합쇼체(~ㅂ니다) · 해요체(~요) · 하오체(~오·~소) · 해체(반말 ~어·~야) · 해라체(~다·~라). 같은 인물이 **같은 상대에게** 등급을 오르내리지 않는다.
- 1인칭·호칭은 인물마다 고정한다(표). 주어·호칭은 한국어에서 대개 생략한다.
- 나이 든 남자(じゃ·わし) = 하오체·「~일세/~라네/~는가」, 늙은 여자 = 「~다오/~구먼」, 도적·악당 = 해라체「네놈/~다/~냐」.
- 아이 → 어른: 해요체 이상(부모는 예외). 어른 → 아이: 「~렴/~거라/~니?」 가능.
- 대화 끝 마침표는 붙인다(`…` 뒤엔 안 붙임). 물음은 `?`(원문이 `？` 를 생략해도 상대의 답을 요구하면 `?`). 자세한 부호는 `docs/translation-rules.md`.

## 1. 주인공 일행 (화자 표에서 `アヴィン` 등 이름으로 나온다)

| 인물(표기) | 1인칭 | 상대별 말투 | 성격·결 |
| --- | --- | --- | --- |
| 어빈 (アヴィン) | 나 | 일행·또래에게 **해체(반말)**, 독백은 **해라체(~했다)**. 낯선 어른·노인에게는 원문이 です·ます 면 해요체/합쇼 | 과묵, 짧게 답한다. 여동생 아이멜에겐 더 짧고 다정 |
| 마일 (マイル) | 나 (어른 앞 「저」) | 어빈에게 반말, 어른·낯선 이에게 해요체/합쇼 | 활발·붙임성, 감탄이 많다(「~야!」「~잖아」) |
| 루티스 (ルティス) | 나 | 기본 해체(쿨), 낯선 어른·높은 이에게만 해요체 | 오크툼 승병단 출신 소녀 전사. 단호·간결, 어미를 흐리지 않는다 |
| 뮤즈 (ミューズ) | 저 / 나 | **해요체 + 도도한 어조**(「~거예요」「~이에요」「~않겠어요」). 왕녀답게 아랫사람에겐 명령형도 해요체 | 엘 필딘 왕녀. 기가 세고 품위, 가끔 새침 |
| 마티 (マーティ) | 나 | 해체, 혼잣말투(「~인가…」「~군」), 학자 어휘 | 책벌레. 말끝을 끊어 사색 |
| 라엘 (ラエル) | 나 / 내 | **반말, 건방진 소년**(「~라고」「~뿐이야」「헤헤」) | 어린 천재. 어른에게도 반말(원문이 です 일 때만 존댓말) |
| 알쳄 (アルチェム) | 저 | **해요체**, 부드럽고 천진 | 자연을 사랑하는 소녀 |
| 엘레노아 (エレノア) | 저 | **해요체**, 차분하고 상냥 | 연장자 느낌의 여성 |
| 콘로드 (コンロッド) | 저 | **합쇼체**(「~십시오」「~올시다」 가능), 격조 있는 관용구 | 귀족 출신 철학자 |
| 더글라스 (ダグラス) | 나 | 해체, 호탕 | 무사 수행 중인 기사 지망생 |
| 루키어스 (ルキアス) | 나 | 해체, 건조하고 쿨(「~지」「~야」) | 유랑 여검사 |
| 미첼 (ミッシェル) | 저 | **해요체**, 지적 | 마법사 |

## 2. 현자·성직자

| 인물 | 말투 |
| --- | --- |
| 가웨인 | **하오체**(「~시오」「~소」「~오」), 어빈 일행에겐 평어 섞은 하오체 |
| 레뮤라스 | 하오체 + 어린 어빈·마일·아이멜에게는 「~거라/~렴/~니」 |
| 에스페리우스(최고 도사) | 하오체, 위엄. 올레시아(오레시아)에게는 「~님」 |
| 베리어스 | 오만한 해라체·문어(「~하라」「~노라」) |
| 디너켄·크로웰 등 현자 | 하오체(원문 じゃ·おる 이면) |

## 3. 기타 자주 나오는 인물

| 인물 | 말투 |
| --- | --- |
| 닥터 반들 | 해요체(「~죠」「~군요」), 느긋한 의사 |
| 케이트 | 어린 여자아이, 해요체, 자기를 「케이트」라 부르기도 한다 |
| 앤디 | 소년 모험가, 반말, 허세와 푸념 |
| 도적·악당·승병 | 도적: 해라체(「네놈」「~다」), 승병: 합쇼체(「~하고 있습니다」) |
| 상점 주인 | 손님에겐 해요체(원문 です·ます) 또는 합쇼, 늙은 주인은 하오체 |
| 마을 사람(NPC) | 원문 어미대로. 아이 = 반말/해요체, 노인 = 하오체, 주부 = 해요체/해체 |

## 4. 일행이 모르는 사이에서 아는 사이로 — 시점

처음 만난 사이엔 낯선 이 등급(해요체·합쇼), 사귄 뒤엔 반말로 풀린다. **원문이 풀린 자리부터** 푼다. 한 장면 안에서는 우세한 층으로 고른다.

## 5. 예시 대응 (이미 번역한 결)

- **어빈**: 네놈들… 사교도냐. / 자, 이야기는 이쯤 하도록 할게. / 배가 안 보여서 찾았어. / 알선소에서 일을 의뢰받았어.
- **마일**: 자, 아이멜을 찾는 여행을 떠나자. / 다른 광부 아저씨들한테 찍힐 거야. / 일단 니레 씨 댁으로 데려가자. / 나는 마일, 이쪽은 소꿉친구 어빈이야.
- **루티스**: 쿠에르포가 먼저야! / 이 근처에는 마수의 기척이 느껴지지 않아. / 놓치지 않아. / 가르시아 씨한테서 짐을 맡아 왔어요.
- **뮤즈**: 흥, 거절한다는 거예요! / 서민 따위, 두려울 것 없어요. / 잠시 쉬었다 갈까요. / 되다 만 돌이네.
- **마티**: 세 곳의… 지점을… 잇는… / 공부할 생각이니까 / 번역서를 찾기가 귀찮아서
- **라엘**: 쪼잔하게 굴지 마! / 머리는 맑게, 몸은 개운하게 하는 거지. / 한동안 분수나 보고 있을까. / 뭐, 별로 괜찮지만.
- **알쳄**: 빅토리아, 착하지. / 한동안은 여기 머물고 있으니 / 아, 나는 동물이라면 / 지금까지 고마웠어요.
- **엘레노아**: 또 초대해 주세요. / 적당한 휴식을 잊지 마세요.
- **콘로드**: 기회가 있으면 다시 불러 주십시오. / 이별은 달콤한 슬픔. / 이별은 새로운 만남의 서곡.
- **더글라스**: 위험하면 망설이지 말고 도망쳐. / 내 차례는 아니라는 거야? / 머지않아 내 힘이 필요해질 거야. / 내가 없다고 무리하지 마.
- **루키어스**: 싸움은 항상 냉정한 쪽이 승자가 돼. / 싸움은 신중하게. / 뭐, 그런 셈이지. / 마음이 바뀌면 와.
- **미첼**: 가져오면 해결이죠? / 정말 무서운 기술이에요, 이건. / 당신은 이런 동굴에서 / 마수를 부리는 지팡이는
- **가웨인**: 어빈과 아이멜을 데리고 곧 떠나겠소. / 내 힘이 필요할 때는 찾아오시오. / 시간이 없다.
- **레뮤라스**: 사교도의 눈을 돌리려고 / 금세 눈에 띄고 말 테니 말이오. / 아주 슬픈 얼굴을 하고 있었지. / 어빈, 놀다 오너라.

- **닥터 반들**: 당신들, 위험할 뻔했어요. / 샴실단에 독침 쓰는 사람이 있다고 / 저는 닥터 반들이에요. / 어쨌든 한시라도 빨리 진찰하죠.
- **케이트**: 아이참, 삼촌도. / 집에 가고 싶어～ / 폐 끼치면 안 돼. / 아, 어빈 오빠!
- **앤디**: 갑자기 머리를 쾅 맞아서… / 생활비를 찾고 있었는데 / 그 편지 내용 기억하나? / 이야, 그게 부끄럽지만.
- **도적**: 누님이 넘버 투가 되는 날도 머지않았어요… / 우리는 무섭다고…? / 뭐, 뭐야, 네놈들은! / 또 불청객이 왔군.
