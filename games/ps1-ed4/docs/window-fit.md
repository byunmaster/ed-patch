# EXE 창 폭 맞춤 표 (마스터 11-06 「가장 긴 항목에 맞춰서 가로길이 조절」)

창 폭 = 창 여는 함수 `0x80015B20(번호, x, y, 열, 줄)` 의 열(`a2`) 상수. 엔진은 항목을 재지 않는다(왼쪽 위 앵커 고정).
필요 열 = 올림((최장 항목 px + 6) / 12) — 반각 6px · 전각 12px, 엔진 자르기 6px(`choice.need_cols_for_px`, 11-06 실측).
대본 선택창 28곳은 `choice.py`(`ED_CHOICE_FIT`)가 맡고, 여기는 **실행파일 안 창**이다. 호출 91곳 전수는 `.local/work/inbox/ps1-ed4/window-open-sites-1106.tsv`.
항목 px 는 제품 문안(`uitext.plan`)에서 쟀다(`tools/` 밖 일회용 스크립트).

## 91곳 전수(`window-sites-1107.tsv`)
호출 91곳을 묶음(상점·알선소·전투·필드 메뉴…)으로 가르고 판정을 단 표. 상점 목록 8곳(열 11 + 가격 칸) · 게시판 6(`ED_BOARD_*` 로 따로) · 도구 목록 1(`ED_WIN_FIT`) · 열이 런타임 값인 9 · **미판독 67**.
미판독 사유: 항목 문자열을 창 호출 근처 코드에서 정적으로 이을 수 없다(표 기준 상수를 여러 창이 돌려 쓰고, 목록 그리기 함수가 창 번호로 항목을 고른다) — 호출마다 런타임으로 어느 문자열을 그리는지 덫을 거는 일이 남았다.

## 못 한 것
- 상점 구매 확정·여관·장비·세이브 창의 오른쪽 칸: 구매 확정 화면을 못 띄웠다(「Rose」 주소 미상).
