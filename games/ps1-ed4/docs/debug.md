# ED4 디버그·숨은 기능 — 정적 조사 (10-24, 굽지 않음)

범위: 맵 이름 표 · 하드코딩 맵 이름 · 이벤트 스크립트의 맵 이동 연산 · 패드 조합. 주소는 RAM(`SLPS_015.40`, 파일 오프셋 = RAM − `0x80010000` + `0x800`).

## 결론

- **화면용 디버그 메뉴·로그는 없다** — ED3 처럼 영문 로그 문자열(부팅 로그·BIOS 라이브러리)만 있고, 개발 모드 문구는 코드표 키워드 스캔 0건(`status.md`).
- **맵 구경은 만들 수 있다 — 진입로가 7바이트다**: 새 게임이 읽는 맵 이름 리터럴 `OP00000`.
- 표에 **숨은(어떤 스크립트도 안 가리키는) 맵은 없다** — 372항목 중 이름이 스크립트에 하나도 안 나오는 건 `DR08000`(디스크에 멤버도 없다 — 죽은 항목)과 `OP00000`(리터럴로만 로드) 둘뿐이다.
- 패드 조합(개발자 숨김키)은 **정적으론 못 찾았다**: 실행파일 전체에서 `andi imm` 뒤에 같은 값과 비교하는 다비트 마스크를 찾았으나 0.x 비트 플래그 외엔 없었다(한계: 마스크 비교가 아닌 상태값 직접 비교는 못 잡는다).

## 맵 로더 — 이름 하나가 폴더·아카이브·맵을 정한다

| 자리 | 하는 일 |
| --- | --- |
| `0x8001252c(종류, 번호, 이름*)` | 자원 로더. 종류 0 + 이름이면 맵, 종류 1 이면 번호가 그림 `C_<번호>.TIZ`(0x358=C_856 …). 호출처 32곳 |
| `0x80012068(이름*)` | 맵 이름 표(`0x80087808`, 8B 항목 = 이름 7자 + 1바이트)에서 이름 7자를 비교해 **영역 번호(`byte & 0x7F`)** 를 돌려준다. 끝은 `Z`(0x5A) |
| `0x800132a0(이름*)` | 같은 표 조회 — 플래그(`byte & 0x80`)를 본다 |
| `0x80011efc(영역, 글자)` | **아카이브 선택**: 글자(= **이름 첫 글자**, `A`~`K`·`O`)를 경로 `C:\ED4\CD_DATA\<글자>\SC<nnn>.DAT` 의 +0xF 에 써 넣고 `nnn = 영역 + 100 × (글자 − 'A')`. 현재 영역은 `0x800B3010`(u16), 현재 폴더 글자는 `0x80095D60` |
| `0x8001252c` 안 `0x800126a0~b4` | `jal 0x80012068(이름)` → `lbu a1,(이름)`(첫 글자) → `jal 0x80011efc` |

⇒ **챕터 폴더 전역을 따로 만질 필요가 없다**(ED3 는 폴더 변수를 바꿔야 했다) — 이름 첫 글자가 폴더다. 표의 영역 번호는 0~16(0~7 이 대부분, 13 은 `B` 폴더 18개).

## 이벤트 스크립트의 맵 이동

스크립트에 이름이 **인라인 ASCII 7자**로 박혀 있고 앞이 `14 <방향> 07`(연산 0x14, 방향 `00 01 02 03 08 88`, 인자 종류 `07`)다 — 1,417곳(전부 표의 이름). ED3 의 `14 <방향> 06 <이름>` 과 같은 꼴이다. 인자 디코더는 `0x80042a28`(타입 바이트 `<0x60` 즉치 · `0xE0` u16 · `0xC0`/`0x80` 변수 등)이고, 연산 핸들러는 `0x80042000~0x80047000` 대에 흩어져 있다(**VM 연산표 전체는 못 읽었다** — 아래 한계).

## 하드코딩 이름

| 이름 | 주소 | 쓰임 |
| --- | --- | --- |
| `OP00000` | 리터럴 `0x80088890`(파일 `0x79090`) · 쓰는 곳 `0x8005a338` | **새 게임** — 부팅 함수(`0x8005a2bc`)가 타이틀(`0x8005885c`) 반환이 1 이면 `0x8001252c(0, 0, "OP00000")` |
| `GT07000` | 리터럴 `0x80088604` · 비교 `0x80046fa0`·`0x80048bc4` | **현재 맵 이름(`0x801EFCA0`)과 비교** — 그 맵일 때만 도는 특수 처리(적재가 아니라 판정) |
| `GT40000` | 리터럴 `0x80088888` · 비교 `0x80056ce0`·`0x80056cf4` | 같은 종류(그 맵일 때 `0x8005805c(0x2d)` 등) |

## 진입로 설계 — 맵 구경 (굽지 않음)

- **바이트**: 파일 `0x79090` 의 `OP00000\0` 7바이트를 표의 아무 이름으로 바꾼다(길이 7 고정 — NUL 은 그대로). 새 게임을 고르면 그 맵이 로드된다(첫 글자가 폴더·표가 영역).
  - 근거: 위 로더 — 이름만으로 폴더·영역이 정해진다. 오프닝(`O` 폴더 `SC400`)의 이벤트가 건너뛰어져 시작 이벤트·파티가 비므로 ED3 와 같은 「맵 구경 모드」(플레이어·파티 없음 가능)다 — **실제로 구워 보진 않았다**.
  - `ED_DEBUG_MAP` 식 시험 스위치는 ED3 `debugpatch.py` 꼴(이름 검증 후 리터럴 교체)로 쉽게 만들어진다.
- **여러 맵을 도는 길**: 한 빌드는 한 맵이다. 연속 순회는 에뮬 RAM 에 `0x801EFCA0`(현재 맵 이름)을 쓰고 맵 변경 연산을 태우는 식(ED3 의 「워프」) — 이 주소 쌍은 동적 확인 전.
- **디버그 메뉴를 새로 만들려면**: 코드를 얹을 자리가 필요하다. 실행파일 꼬리의 0 런(32,744B)은 **런타임 버퍼라 안 된다**(「빈 공간의 VAB 함정」) — 폰트 칸 중 안 쓰는 자리나 오버레이가 아닌 상수 구간은 별도 조사. 문구는 새로 정해야 한다(원판에 없다).

## 한계 (다음 조사 거리)

- 이벤트 VM 연산표(op → 핸들러)를 못 읽었다: `0x14` 외의 연산(워프 변종·플래그 세팅·이벤트 호출)은 미해독. 연산표 후보는 `0x800105b8`(107)·`0x80010adc`(121) 등 주소 테이블 런이나 어느 것이 스크립트 VM 인지 확정 안 됨.
- 패드 조합·타이틀 숨김 입력은 정적으론 미확인(타이틀 함수 `0x8005885c` 본문 미해독).
- 표 항목의 상위 비트(플래그 114개)의 뜻은 미확인(`0x800132a0` 이 읽는다).

## 맵 워프 · 대사 주입 (10-26, 실측 — 롬을 안 굽는다)

- **맵 워프(RAM 한 번 쓰기)**: 타이틀에서 「처음부터」를 누르기 **전에** 새 게임 맵 이름 리터럴(`OP00000`, RAM `0x80088890`, 7자 + NUL)을 표의 다른 맵 이름으로 덮는다 → 그 맵이 바로 로드된다(`BT01000` 바로아 마을로 실측, 어빈이 걸어 다니는 필드). 맵 372개를 이 방식으로 순회할 수 있다. (앞 절의 「굽는 방식」과 같은 바이트를 RAM 에서 바꾼 것 — 빌드 불필요.)
- **이벤트 VM 의 PC 는 전역 `0x800C65E8`**(읽기 중단점 + `0x80045a54` 등 403곳 참조) — 스크립트 기준 포인터 `0x800C6E14`, VM 호출 스택 `0x801F33B0`(깊이 `0x800A8BCA`). 대사(`0F`) 연산 핸들러가 `0x8003C98C(ctx, 스트림 포인터)` 를 부르고, 이 **대사 함수가 입력 대기까지 제 지역 변수(스택 `sp+0x64`)로 스트림을 읽는다.** 문자열 표 주소는 전역 `0x800B3014`(표 시작, 항목 = 표 시작 기준 u16 오프셋).
- ⚠ **PC 전역을 꽂는 ED3 식 주입은 필드에서 안 먹는다** — VM 이 이벤트 중에만 돈다(필드 대기 중엔 PC 를 읽는 프레임 루프가 없다).
- **대사 주입 — 실측으로 되는 방식**: 새 게임 첫 대사(오레시아 「자, 어빈, 아이멜.」)가 ○ 를 기다리는 순간의 상태를 만들고(`dialog_harness.make_state`), 그 상태에서 ① 멤버 바이트를 빈 RAM(`0x801B0000`, 536KB 0 런 안)에 올리고 ② `0x800B3014 = 그 주소 + 멤버 머리 u16` ③ **스택 `0x801FFF44` 의 스트림 포인터를 그 멤버의 스트림 시작(`p0`)으로** 바꾼 뒤 ○ 를 누르면 대사 함수가 우리 스트림을 그린다(레뮤라스 대사가 떴다). 쪽마다 ○ 를 눌러 찍고, 같은 화면이 두 번 나오면 스트림이 끝난 것(`dialog_sweep.py`).
  - 🔴 libretro 코어는 **`pcsx_rearmed_drc=disabled`(인터프리터)** 로 돌려야 한다 — 동적 재컴파일러는 불러온 상태·RAM 쓰기와 어긋나 `Segmentation fault in recompiled code` 로 죽는다.
  - ⚠ 이름창(`12 NN`)은 VM 연산이라 대사 함수가 안 읽는다 — 주입한 스트림의 이름칸은 직전 화자(오레시아) 것이 남는다. 줄·쪽 조판 확인용이다. 선택지(`3B`)·변수 삽입 값도 VM 몫이라 흉내가 안 된다.
