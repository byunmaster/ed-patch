# 플레이 매뉴얼 — PS1 ED3·ED4 (QA 회차용)

⚠ **디스크가 둘이라 두 벌이다.** 칸에는 이미지 하나만 두므로(루트 `CLAUDE.md`) 한 번에
한 디스크만 굴린다 — 굽는 순서를 바꿔 가며 본다.

🔴 **여기 적힌 프레임 수는 실측이다**(2026-09-07, emucap mednafen, 시험 빌드). 헤드리스라
빨리감기가 없어 `tap(after_frames=…)`·`step` 으로만 시간을 민다.

## 조작 (둘 다 같다 — PS1)

| | |
| --- | --- |
| 확인 · 대사 넘김 | `circle` |
| 취소 | `cross` |
| 메뉴 | `triangle` (⚠ **미검증** — 오프닝을 못 벗어나 아직 못 열어 봤다) |
| 타이틀·선택지 | 🔴 **`press_frames=10`** — 2프레임 탭은 **안 먹는다**(09-07 실측, 세 번 헛돌았다) |
| 대사 넘김 | `press_frames=4` 면 충분 |

## ED3 — 부팅에서 첫 대사창까지 (실측, 다섯 번 재현)

```
launch(psx, "…/Eiyuu Densetsu III (KR) (TEST).cue")   # ⚠ .cue 는 launch_plan 승인 먼저
tap start  press 10  after 3200    # SCEI 로고 → 별밤 내레이션(D1, 한글)
tap start  press 10  after 4500    # 오프닝 무비
tap start  press 10  after 4500    # 타이틀 화면(E1·E2, 한글)
tap circle press 12  after 2900    # 장 카드(D2, 일본어) → NOW LOADING → 첫 대사창
```

- 타이틀 커서는 **이미 「모험을 처음부터 한다」에 있다** — `down` 을 누르면 메모리카드 로드로
  빠진다. 빠졌으면 `cross` 로 나온다.
- 🔴 **D2(장 카드)만 보려면** 위 `circle` 탭을 `after 100`으로 잘라서 본다(09-15 실측) — 100프레임
  안에 뜨고 900프레임쯤엔 이미 맵으로 넘어가 있다. `after 2900`은 카드를 지나쳐 첫 대사창까지
  가는 값이라, 카드 자체를 스크린샷하려면 짧게 끊어야 한다.
- 첫 대사창 = 크리스 집, 화자 **크리스엄마**. 여기까지가 `SC000!FT0000`(정본 165줄).

## ED3 — 그 뒤 (여기가 이번 회차의 병목이다)

🔴 **오프닝 씬이 길다 — `circle` 을 25회 넘게 눌러도 조작 자유에 못 갔다**(09-07 실측).
크리스 집 대화 → 오르골 → 쥬리오 집으로 **장면이 이어진다**. 그래서 **메뉴 칸
(A1~A6·B1~B3)을 아직 한 번도 못 열었다.**

| 지나온 자리 | 프레임 감각 |
| --- | --- |
| 크리스엄마 첫 대화 | `circle` press4 after 120~240 씩 10여 회 |
| 「크리스는 戸棚의 오르골을 열었다」 | 여기서 창이 **화면 위**로 올라간다 |
| 쥬리오 집 (쥬리오아빠·쥬리오엄마) | after 400~600 으로 늘려야 넘어간다 |

⇒ **세이브가 있으면 이 구간을 통째로 건너뛴다.** 유저 세이브를 `/root/save/ps1-ed3/` 에
받으면 `scripts/emu/sync-saves.sh` 가 이미지 해시 이름으로 맞춰 넣는다.

⚠ **세이브스테이트는 「자리로 가는 데」만 쓴다.** 문안 검증에 쓰면 안 된다 — 텍스트가
오버레이로 RAM 에 올라와 **스테이트가 곧 옛 빌드**다(루트 `CLAUDE.md`). 새 빌드를 재면
**리셋 + 메모리카드에서 정식 로드**.

## ED3 — 어트랙트로 로고·두루마리를 보려면

타이틀에서 **입력 없이** 약 5,100프레임 → 3D 데모(~6,800f, 로고 없음)와 **그림 몽타주**가
번갈아 돈다. 로고는 몽타주 **끝**(시작 후 ~13,000f).
🔴 **어트랙트 중엔 어떤 입력이든 타이틀로 튕긴다** — `tap(press_frames=0)` 도 입력이다.
**`step(count, unit="frames")`** 로만 민다(한 번에 최대 5,000).

## ED4 — 아직 안 돌아 봤다

- 타이틀 메뉴는 09-03 PoC 로 한 번 봤다(「처음부터 시작」·「이어서 시작」). **그 뒤 문안이
  바뀌었으니 다시 봐야 한다.**
- 첫 씬은 `/A/SC001.DAT!AT01000.BIN`(현자 레뮤라스의 유언 → 노토스 사당) — 정본 120줄이
  들어 있다. **부팅 순서·프레임 수는 미측정.**
- ⚠ **ED4 엔 공백 8px 엔진 패치가 없다**(렌더러가 `0x800164F0` 으로 따로다) — 공백이 한 칸으로
  보이는 건 정상이다.
- 굽기: `python3 games/ps1-ed3+4/tools/build.py --disc ed4 --test`

## 근거 캡처

`.local/inbox/ps1-ed3+4/` 에 **칸 ID 를 앞에, 이름은 ASCII 로** — `A1-window-top.png`.
🔴 한글 이름은 맥에서 자모가 분리돼 관리자가 못 연다(09-07 실측). 괄호도 셸에서 걸린다.
⚠ **저해상도 캡처로 글자를 판정하지 않는다** — 320×240 에서 `ㅏ`/`ㅣ` 가 안 갈린다.
확대본을 같이 남기거나 바이트를 댄다.

## 🔑 거기까지 가는 데도 emucap 을 쓴다 (유저 방침 2026-09-07)

**우리는 emucap 을 「왜 그런가」를 캐는 데만 썼다.** 막힌 눈금 대부분은 **도달 문제**인데
도구를 그 방향으로 안 돌렸다 — 이 매뉴얼의 「오프닝 탭 25회」가 바로 그 부류다.

- 레벨·소지금·플래그·상태이상·챕터 변수를 **`write_memory` 로 써 넣으면** 그 화면이 그 자리에서
  열린다. 세이브를 기다릴 필요가 없다.
- ⚠ 그건 **「화면 확인」이지 「정상 경로 확인」이 아니다.** 눈금 표의 **도달** 칸에 「메모리」로
  적고, **나중에 플레이로 한 번 더 밟는다.**
- 🔵 **유저에게 청하기 전에 「이거 내가 계측으로 못 하나」를 한 번 되묻는다.** 화면 판정만 유저 몫이다.
- ⚠ 아직 우리는 ED3 의 챕터·플래그 변수 자리를 모른다(**선행 프로젝트에도 없다** —
  `docs/reference/prior-art.md`) — 다음 라운드에 찾는다(이벤트 VM 정찰이
  `0x800DD734` 커서까지 와 있다).

## 아직 모르는 것 (다음 회차에 채운다)

- 조작 자유가 되는 **첫 지점**과 거기까지의 프레임 수 (ED3·ED4 둘 다)
- **메뉴 버튼**이 정말 `triangle` 인가
- **전투가 나는 자리** — 메뉴 QA 는 안 나는 자리에서, 전투 QA 는 나는 자리에서 해야 한다
- 상점이 있는 마을 (B4 는 문안 자리조차 못 찾았다)
