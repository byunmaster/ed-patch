## 다음에 할 일 (순서대로)

1. **폰트** — 여기가 유일한 관문이다. 아래는 **이미 닫힌 길**이라 다시 파지 않는다:
   평문 비트맵(디스크 전량·RAM·SPU·VRAM, 1bpp 임의 정렬·4bpp·행 간격 24종) · 압축 해제 후
   자산 628개 · BIOS 폰트(런타임 ROM 읽기 안 걸림) · 메인 RAM 에서의 글리프 조립(장면 간
   RAM 차이가 828바이트뿐).
   ⇒ 남은 가설은 **글리프별 가변 길이 인코딩 + 오프셋 표**다. 착수점:
   (a) `PSX2.EXE` 0x3A144 의 오름차순 u16 930개(평균 간격 4.4B)를 풀어 본다 — 그게 타이틀
       화면 폰트라면 **같은 인코딩**을 ED3.EXE 에서 찾으면 된다.
   (b) `ED3.EXE` 를 디스어셈블해 코드 → 글리프 주소 계산을 따라간다(ED1+2 가 쓴 방법).
2. **글리프 예산** — 한글 2,350자가 들어갈 자리가 있나. 표에 안 쓰는 코드가 얼마나 되나
   (지금 대본이 쓰는 고유 코드는 ED3 1,804). ⚠ 이게 **PoC 보다 먼저** 답해야 할 물음이다
   (체크리스트 10-C).
3. **ED4 카나 블록 유도** — 로제타가 없으니 빈도 정렬(단조 DP)로.
4. 재삽입 구조 — 런 길이를 바꿀 수 있나(포인터가 있나, 있으면 어디).

## 열려 있는 물음

- `0xEEEE` 가 267번 나온다 — 블록 구분(`0xFFFF`)과 다른 무엇인가.
- 코드 `0x0010~0x003E` 기호·숫자 대역이 아직 반쯤 비었다(로제타에 잘 안 걸린다).
- ED3 미해독 581 코드는 전부 저빈도 한자로 보인다 — 번역엔 안 걸리지만 **「일본어 안 남았나」
  검사에는 걸린다.**
