# 도구 지도 — 역할별

⚠ **「아무도 안 부른다」와 「쓸모없다」는 다르다**(유저 확정 2026-08-18).
1회성 탐색 도구는 그 산출물의 **출처**다 — `SJIS→글리프주소 0x8001BE24` 가 어디서
나왔냐는 물음의 답이고, 원본이 바뀌면 다시 돌려야 한다. **호출 여부로 지우지 않는다.**
지울 자격이 있는 건 **산출물조차 안 남은** 도구뿐이다.

2026-08-12 에 「배정 시대 검출기 28개」를, 08-18 에 「탐색 끝난 19개」를 지웠다가
**둘 다 되살렸다**(113개). 이유는 같다 — `textmap/*.json` 은 `gen_textmap` 이 만들었고,
`ed1-scene-map.md` 는 `segment_copy --map` 이 뽑았고, `work/derived/scn_maps/` 는
`scn_maps` 가 만든다. 체크리스트 절 6은 지금도 `proposal.py verify|apply` 를 인용한다.
**도구를 지우면 그 도구가 만들던 것의 출처가 끊긴다.**

⚠ 이 표는 `tools/README.md` 생성기가 아니라 **손으로 갱신**한다 — 도구를 더하거나
성격이 바뀌면 여기도 고친다(회귀 테스트 `test_tool_index_covers_all_tools` 가 누락을 잡는다).
