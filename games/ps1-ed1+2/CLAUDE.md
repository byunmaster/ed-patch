# CLAUDE.md — PS1 영웅전설 1+2 한글패치 (트랙: kr)

일본 원판 PS1 『영웅전설 1+2』(SLPS-01323)를 한국어화한다. 번역 저본은 국내 정발판
(만트라 DOS). 레포 공용 규칙은 루트 `CLAUDE.md`.

- 타깃 원본: `originals/jp/ps1-ed1+2`
- 번역 저본: `originals/kr/dos-ed1` (ED1 = `SINDLL/*.DLL`) · `originals/kr/dos-ed2` (ED2 = `SCENA/*.DLL`)
- ED.EXE = LBA 257. RAM 주소 = file오프셋 − 0x800 + 0x80010000.

  ⚠ **지시가 없어도 매 작업마다 갱신한다**(유저 확정 2026-08-04) — 막다른 길·버린 안·
  오진했다가 바로잡은 것·함정. 성공한 변경의 "무엇을 왜"는 커밋 메시지 관할이니 옮기지 않는다.

## ⚠ 빌드는 결정적이어야 한다 — 배정 정본 (align_map.json)

> 레포 **제1 원칙**의 이 게임 몫이다(루트 `CLAUDE.md` 첫 절).
> 검증: `python3 tools/check_determinism.py`

**같은 입력이면 어디서 빌드하든 같은 이미지가 나와야 한다.** 원래는 아니었다 — 빌드 경로
한복판에 `align_semantic`(LaBSE 임베딩 + 헝가리안)이 있었고, 원작에 **글자까지 똑같은 JP
블록**이 있어(같은 대사를 하는 병사 여럿) 배정이 **정확한 동점**이 됐다. 승자는 부동소수
잡음이 정하니 **회사 빌드와 집 빌드가 달랐다**(2026-08-03(3), 좌표 117건·문안 24건).

그래서 **비결정적 제안 생성과 결정적 빌드를 갈랐다**:

- **`align_map.json`(커밋) 이 배정 정본**이다. `{씬: {jp_eid: {table, entry_id, speaker}}}` —
  좌표는 포인터, speaker 는 단어 라벨이라 **문장은 한 글자도 안 담긴다**(textmap 과 같은 관용).
- **정본이 있으면 빌드는 `work/derived/align` 을 안 읽는다.** 새 머신에 torch·LaBSE 가 없어도
  빌드가 돌고, 정렬 파일 유무와 무관하게 **바이트 동일한 이미지**가 나온다(실측 검증).
- `align_semantic.py` 는 이제 **제안 생성기**다. 의도적으로 돌린 뒤 `--diff` 로 검토하고
  받아들일 때만 `--update` 로 정본에 반영한다.

```bash
python3 tools/align_map.py --status          # 현황
python3 tools/align_map.py --diff ED1SCN2    # 정본 vs 지금 정렬 (제안 검토)
python3 tools/align_map.py --update ED1SCN2  # 검토 끝난 것만 정본으로
```

⚠ **머신을 옮긴 직후 `--update` 를 돌리지 말 것** — 그 머신의 동점 결과를 정본으로 승격시킨다
(`lock_lines.py --freeze` 와 같은 함정: 검증기를 갱신기로 쓰는 셈).

## ⚠ 확정 대사 락 (locked_lines.json)

배정 정본이 "어느 정발 엔트리를 쓸지"를 고정한다면, 락은 **그 결과 문안이 안 바뀌었는지**를
지킨다(정발 교정·파서 변경 같은 상류 변화를 잡는다). 둘은 층이 다르니 같이 쓴다.

- **씬 QA 가 끝나면 즉시 못 박는다** — `python3 tools/lock_lines.py --freeze ED1SCN1`.
  문안 해시가 달라지면 **빌드가 실패**한다. `locked_lines.json` 은 커밋되므로 머신을 따라간다
  (정렬 산출물은 `work/` 라 안 따라간다 — 그게 사고의 뿌리였다).
- 의도적으로 문안을 고칠 때만 `--unlock <씬> <eid …>` 후 재빌드.
- ⚠ `align_jp_kr.py` 를 **인자 없이 돌리지 말 것** — 의미정렬 정본을 구조 초안으로 덮어쓴다.
  이제 가드가 막지만(`generator` 표식), 정렬 재생성은 `align_semantic.py` 로 한다.

## 번역 정책

- **정발판(만트라 DOS)에 있는 건 다 이식**(이스터에그 포함), 없는 것만 정발 문법으로 신규 번역.
- 정발 표기 그대로가 원칙. 기술 제약(슬롯·렌더폭)이나 정발 내부 불일치로 바꾼 것만
  **편차 대장(jeongbal-deviations.md)에 기록**. ED1↔ED2 표기 충돌 시 일본어 원음으로 판정.
- **문안(특히 정발 원문) 변경은 사전 보고** — 공간 부족 시 어색한 한국어·중복부터 줄여
  공간 확보, 조용히 바꾸지 않는다. 그래픽 로고류는 볼드 근사/유저 에셋 합성 OK.
- **문장급 문안은 코드에 임베드 금지**(저작권 — 팔콤 일문·만트라 문안이 리포에 남으면 안 됨).
  문장 테이블은 `textmap/*.json`(정발 원본 포인터 + 우리 번역) → `tools/derive_text.py`가
  빌드 시 소장 원본(originals/)에서 파생. 문장 추가·수정은 textmap에서, JP 키는 sha1 해시.
  단어 수준 명칭·라벨(아이템·몬스터·지명·메뉴)은 저작권 대상이 아니라 코드 유지 OK.

## 재삽입 주의 — 구조 계약 (소프트락의 근원)

**엔진은 블록의 텍스트가 아니라 "구조"를 계약으로 읽는다.** 번역문만 맞추고 구조를 바꾸면
증상이 오타가 아니라 **소프트락·이벤트 정지**로 나온다(음악은 계속 나옴 = 프리징 아님).

- **세그먼트(창) 수 부족 = 소프트락(치명)**, 초과 = 꼬리 잘림(표시 손실). 재조립본의 `%c` 수가
  원본보다 적으면 엔진이 종단을 못 만나 뒤 데이터까지 읽는다 → 깨진 글자 + 무한 대기.
- 원본의 **`%s`·`%d`·인라인 제어코드**는 장식이 아니라 흐름 제어 — 임의로 빼거나 공백 치환 금지.
- **갱신 가능한 포인터(lui+addiu/ori)로 참조되지도, 번역되지도 않는 블록은 이동 금지.**
  텍스트 영역엔 값 테이블·이름·스크립트 조각이 "블록"으로 섞여 있고, 무참조 = 절대주소로 읽힌다.
- **구조가 다 맞는데 깨지면 "위치"를 의심한다.** `%c`·`%s`·`%d` 가 전부 일치해도 블록이 줄어
  뒤가 당겨지는 것만으로 이벤트가 깨지는 구간이 있다(크루즈 아침 자동이동 실측). 증상이
  **축소량에 단조 반응**하면 그 자유 구간을 통째로 원본 길이 고정 — `reinsert.FIXED_RUNS`.
- 인게임 먹통을 만나면 코드 추적보다 **differential 빌드로 원인 계층을 이분**하는 게 훨씬 빠르다
  (`PILOT_TEXT_IDENTITY`·`PILOT_FIXED`·`PILOT_NOSPLICE`·`PILOT_IDENTITY`).

상세 규칙·체크리스트·소프트락 디버깅 절차: 레포 루트의
**`docs/reference/our-findings.md`** (⚠ 구조 계약 절).
