# ED1+2 진행 현황

**이 문서 하나만 읽으면 이어서 작업할 수 있게 쓴다.** 누가(어떤 세션·어떤 도구가) 오든
"지금 어디까지 됐고 · 다음에 뭘 하고 · 어떻게 시작하는지"를 여기서 얻는다.

- **방침·규칙**은 여기 쓰지 않는다 → [policy.md](policy.md)
- **완료된 작업의 경위**도 여기 쓰지 않는다 → 커밋 히스토리 · [devlog.md](devlog.md) ·
  [reference/our-findings.md](../../../docs/reference/our-findings.md)
- 여기엔 **현재 상태 + 남은 일**만 둔다. 다 하면 지운다.

마지막 갱신: 2026-08-04.

## 시작하기 — 첫 명령은 빌드다

```bash
cd games/ps1-ed1+2
python3 tools/build.py        # → work/build/Eiyuu Densetsu (KR).bin/.cue
```

**통과하면 그대로 작업을 시작하면 된다.** 머신이 바뀌었든 파생물이 낡았든 상관없다 —
배정 정본(`align_map.json`)이 커밋되어 있어 **어디서 빌드하든 바이트 동일한 이미지**가 나온다.
LaBSE·torch 도 필요 없다(정렬 파일을 전부 지우고 빌드해 sha1 일치를 확인했다).

`work/derived` 가 통째로 없으면 덤프 둘만 만들면 된다(결정적, 빠르다):

```bash
python3 tools/extract_scn.py      # JP 대사 덤프
python3 tools/extract_dos_kr.py   # 정발 대사 덤프
```

빌드가 **확정 락 위반**으로 멈췄다면 문안이 바뀐 것이다. 절차는 [policy.md](policy.md).

## 남은 일 (우선순위)

### 1. 🔴 SCN2~6 커버리지 — 최대 과제

번역 자체가 남은 구간이다(QA 가 아니다). 제외가 가장 많은 곳은 **SCN2 27건**
(`size` 20 · `fmt_excess` 5 · `ctrl_seq` 2)으로, `size` 가 압도적이라 **정발 문장이 창 용량을
넘는 쪽**부터 손보면 회수가 크다. 씬 QA 를 끝낼 때마다 **반드시 freeze**([policy.md](policy.md)).

### 2. 🔴 오버라이드 조용한 실패 4건

`ED1SCN2 jp933 · jp942 · jp952` · `ED1SCN3 jp694` — 전부 "화자 없음"으로 적용 실패한다.
매 빌드 경고로 뜬다. SCN2 에 들어가기 전에 치우는 게 낫다(화면에 안 나오는 대사를 QA 에서
다시 발견하는 건 낭비다).

### 3. 🔴 `anchor_overlap` 잔여 3건 (SCN3 ×1 · SCN5 ×2)

포인터 테이블과 대사가 한 블록이라 통째로 핀 고정되고 번역이 버려진다. **손댈 길이 있다** —
앵커는 블록 **앞부분**만 덮으므로 뒤 텍스트를 **제자리·같은 길이**로 덮어쓰면 절대참조가
유효하다. 구현 자리는 `rebuild()` 의 `if b["pinned"] and b["eid"] in translations` 분기.
SCN1 분은 회수 완료(`2a13bd5`). 사유 확인은 `work/derived/excluded_*.json`.

### 4. 창 계약으로 막힌 잔여

`size` 23 · `fmt_excess` 9 · `fmt_drop` 8 · `ctrl_seq` 6. 1번과 같은 뿌리라 함께 다뤄진다.

### 5. 🔴 HUD 세 건 — 1장 QA 중 발견, 끝나고 하기로 미뤄둔 것들

**(a) 로우 이름칸 오른쪽 테두리가 지워졌다.** 파티 HUD 에서 `로우` 칸만 우측 border 가
사라진다. 이름이 2글자라 다른 캐릭터와 렌더 폭이 달라진 것과 관련이 있어 보인다 —
`patch_hud_names.py`(이름판 5명: 세리오스·류난·로우·게일·소니아) 쪽부터 볼 것.

**(b) HUD 마을표시 폰트를 줄인다.** (c)의 선행 조건이기도 하다.

**(c) HUD 접미 폭** — `[지명]+[접미]` 합계가 14B 한계다(`베르가 광산`+`입구`=15B). 공백을
넣으면 잘리고, 반각 공백은 전각 경계를 깨 `++` 가 뜬다. **(b) 폰트 폭 축소 뒤에나 띄어쓰기가
가능**하다. 상세는 [our-findings.md](../../../docs/reference/our-findings.md).

> ⚠ 「クルスの村」 미치환 인스턴스가 남았는지는 **바이트 카운트로 판정하면 안 된다.**
> 지명 치환은 새 위치에 쓰고 참조를 바꾸는 방식이라 **원본 JP 바이트가 그대로 남는다**
> (빌드본에 29곳 남아 있지만 화면과 무관할 수 있다). 인게임으로 확인할 것.

### 6. 화자 미해결 3건

`アグニージャ` · `ギュリゲス` · `フラート`. `ロー`→`로우` 와 같은 증상(음차가 화자창에
그대로 나감)이 날 수 있다. 1장 밖이라 미뤘다.

> 빌드는 "ED1 미해결 9건"이라고 찍는데 **그중 6건은 화자가 아니다** — `眠り草`·`竜の笛`·
> `船`·`銀の笛`·`黄金のかぎ`·`黄金のカード` 는 `%s` 로 주입되는 **아이템·탈것 이름**이다.
> 숫자만 보고 화자 문제로 오해하지 말 것.

### 7. 타이틀 버튼 — 인게임 검증 잔여

절차적 드로잉으로 전환한 뒤 유저 DuckStation 확인이 안 끝났다(옛 devlog 에서 옮김).

- 영웅전설Ⅰ/Ⅱ 셀 글자 겹침(이전 이미지 방식의 반려 사유) 재발 여부.
- 알약 선택/비선택 위치·크기 안정성(엔진 크기차 외 추가 흔들림 없는지).
- 타이틀 로고(`英雄伝説`·`はじめから`/`つづきから`) 재작성은 [ROADMAP](../../../ROADMAP.md) 미완.

### 8. B급 교정 2,352건 수동 검토

`work/review/corpus/ED*_spell_report.md`. 공백만 바꾸는 A급은 자동 적용됐고, 글자를 바꾸는
B급이 남았다. 정발판 교정 패치([ROADMAP](../../../ROADMAP.md))로 넓힐 때 선행 조건이 된다.

### 9. ED2 전체 미착수

배정 정본에 ED2 9씬이 들어와 있지만 재삽입·QA 는 시작하지 않았다.
⚠ ED2 씬10~13 은 대응 KR 테이블이 0건으로 잡힌다(씬 규칙 미대응 또는 덤프 누락) — 착수 시 먼저 볼 것.
