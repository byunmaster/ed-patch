# ED1+2 진행 현황

**이 문서 하나만 읽으면 이어서 작업할 수 있게 쓴다.** 누가(어떤 세션·어떤 도구가) 오든
"지금 어디까지 됐고 · 다음에 뭘 하고 · 어떻게 시작하는지"를 여기서 얻는다.

- **방침·규칙**은 여기 쓰지 않는다 → [policy.md](policy.md)
- **완료된 작업의 경위**도 여기 쓰지 않는다 → 커밋 히스토리 · [devlog.md](devlog.md) ·
  [reference/our-findings.md](../../../docs/reference/our-findings.md)
- 여기엔 **현재 상태 + 남은 일**만 둔다. 다 하면 지운다.

마지막 갱신: 2026-08-13 (**저작권 정리 완료** · `main`, 정리된 히스토리 push 완료).

## ✅ 초안 → 정본 이관 완주 — 다음은 폴백 제거와 QA

**방침이 바뀌었다**(2026-08-12, [policy.md](policy.md) 「번역 방침」). 정발 배정을 검증하는
일이 아니라 **좋은 한국어판을 쓰는 일**이 됐다. 구조도 배정(`chain` 3,779건)에서
**평탄한 문안 테이블**로 갔다.

|      |                                                                                      |
| ---- | ------------------------------------------------------------------------------------ |
| 정본 | `script/ED1SCN*.json` — `{"1100": {"t": "…", "s": "병사"}}`. **커밋된다**(우리 문안) |
| 초안 | `work/review/draft_ED1SCN*.json` — 옮기기 전 화면 문안. **커밋 금지**(정발)          |
| 검증 | `script_draft.py --verify` — 초안을 그대로 넣었을 때 같은 바이트가 나오는가          |

**여섯 씬 전부 초안을 소진했다**(2026-08-12). 남은 1,001블록은 **초안이 없는 자리**다 —
정형 블록(보물상자·상점 가격 — 빌더 관할)과 화면에 안 나가는 것(포인터·이진 잔재).

⚠ **2026-08-13 이후 「정본 블록 수」는 이관의 척도가 아니다.** 저작권 방침이 서면서
문안이 정발과 같아도 **관용·상투 표현이면 `script/` 에 그대로 두고**, 번역자의 노력이 든
문장만 포인터로 뺐다([policy.md](policy.md) 「저작권」). 지금은 **정본 4,787 · 포인터 392**
이고, 포인터 쪽은 미완이 아니라 **그렇게 두기로 한 자리**다.

이관 자체는 여섯 씬 전부 끝났다(초안 소진 2026-08-12).

**전 씬에서 오역 100종 이상.** 유형은
[mistranslation-patterns.md](../../../docs/reference/mistranslation-patterns.md) 에 모았다
(게임 무관 — 다음 프로젝트에서 볼 자리를 좁힌다).

### 이관에서 굳은 두 가지

- **원문이 같으면 문안도 같아야 한다.** 원작은 상점·숙소·신부 응대를 마을마다 복제해 두고,
  블록 단위로 옮기면 같은 원문에 다른 문안이 붙는다(SCN3 도구점 한 벌에서만 31곳).
  검출기: `python3 tools/check_dup_jp.py [씬]` — 판정용이라 게이트가 아니다.
  ⚠ **인자(`%s`·`%d`)가 든 블록은 통일에서 뺀다** — 보이지 않는 센티널이 날아간다.
- **화자는 원문 헤더가 정답이다.** 이관 중 예순 곳 남짓을 되돌렸다(`check_speakers`).

### 커밋 전에는 `sh scripts/check.sh`

빌드만으로는 절반이다 — 조판·이름창·표기는 빌드가 안 본다. 28초.
⚠ 게이트는 **지금 고칠 수 있는 것**만 실패로 친다(안 옮긴 씬의 후보는 「할 일」이다).

⚠ **판정 규율** — 문안을 쓸 때 **반드시 JP 원문과 뜻이 맞는지 본다**(유저 지시 2026-08-12
"항상 원문과 의미가 맞는지 검토하는 과정도 꼭 지켜줘"). 오역 판정은 우리가 하는 것이라
틀리면 정발보다 나빠진다 — 고친 자리는 `note` 에 원문 근거를 남긴다.
⚠ 이 문서는 **현재 상태 + 남은 일만** 둔다 — 닫은 절은 지우고, 그 안의 함정은 그때
[text-pipeline.md](text-pipeline.md)(도구·절차) 또는
[our-findings.md](../../../docs/reference/our-findings.md)(재사용 기법)로 **옮긴다**.

## 시작하기 — 첫 명령은 빌드다

```bash
cd games/ps1-ed1+2
python3 tools/build.py        # → work/build/Eiyuu Densetsu (KR).bin/.cue
```

**통과하면 그대로 작업을 시작하면 된다.** 머신이 바뀌었든 파생물이 낡았든 상관없다 —
배정 정본(`align_map.json`)이 커밋되어 있어 **어디서 빌드하든 바이트 동일한 이미지**가 나온다.
LaBSE·torch 도 필요 없다(정렬 파일을 전부 지우고 빌드해 sha1 일치를 확인했다).

**`work/` 는 통째로 지워도 된다** — 원본 덤프(`extract_scn.py` · `extract_dos_kr.py`)는
`build.py` 가 매번 새로 뜬다(둘 합쳐 1.3초). `rm -rf work/` 후 재빌드로 sha1 동일 확인
(2026-08-09). 낡은 덤프를 안고 오는 사고를 막으려고 그렇게 바꿨다 — 경위는
[devlog.md](devlog.md).

빌드가 **확정 락 위반**으로 멈췄다면 문안이 바뀐 것이다. 절차는 [policy.md](policy.md).

## 남은 일 (우선순위)

1. **인게임 QA — 1장부터 다시 훑는다**(진행 중 2026-08-13). 지적은 `script/ED1SCN*.json` 의
   `t` 를 고쳐 반영한다. ⚠ 정발과 같은 문안이 **포인터로 빠진 블록**(392개)은 파일에 `t` 가
   없다 — 고칠 때는 `t` 를 새로 적으면 그쪽이 이긴다(포인터를 안 지워도 된다).
2. **전투 문안 개선** — 새 방침을 전투에도 적용한다(유저 지시 2026-08-12
   "전투는 개선할 부분 있으면 개선하자"). 오프닝·시스템 메뉴·HUD 는 **기존대로 둔다.**
3. **맞춤법** — `spellcheck_render` 가 주력 관문이다. ⚠ **제안을 그대로 믿지 말 것** —
   A급조차 `네놈`·`시집가다`·`틈나다`·`익살맞다`(전부 한 단어)를 띄우라고 한다. 게다가
   검사기는 **렌더 결과**를 보므로 조판 줄바꿈이 공백으로 보여 `미안 해` 같은 유령 오타가
   뜬다 — 정본 원문으로 되짚어 판정한다(2026-08-12: 규칙 3,028개 중 실제 반영 8곳).
4. **줄 갈림 50건** — `check_line_breaks --report`. 조판 미세 품질이라 게이트는 아니다.

⛔ **하지 말 것 — `align_map.json`·`align_overrides.json`·`textmap/` 을 지우는 일.**
「폴백 제거」로 남아 있던 항목인데 **방향이 정반대가 됐다**(2026-08-13). 저작권 방침 ⓐ 이후
그것들은 폴백이 아니라 **정발 문안을 리포에 안 남기는 체계 그 자체**다. 지우면 정발 문안
전량을 다시 `script/` 에 적어야 한다.

⛔ **하지 말 것 — SCN1 오프닝 11블록을 정본으로 옮기는 일**(jp19·20·23·27~30·293 등).
정발 문안 그대로면 **포인터가 정상**이다. 정본에 적는 건 **우리 표현으로 다시 쓸 때**뿐이고,
그건 저작권 정리가 아니라 번역 품질 과제다.

## 인게임 QA 하는 법

⚠ **정발을 나란히 켜지 않는다**(2026-08-12 전환). 이제 대조할 저본이 없고, 볼 것은
「이 문장이 원문의 뜻이고 읽기 좋은가」다. 유저는 PS1 한 대만 켜고 텍스트를 훑는다.

```bash
python3 tools/script_dump.py ED1SCN1        # 대본(JP 원문 ↔ 우리 문안) → work/review/
python3 tools/check_tail_cut.py             # 창 수·줄 수 초과
python3 tools/check_line_breaks.py          # 줄 갈림
python3 tools/check_forbidden.py            # 마크업 유출·조사 병기 노출
python3 tools/spellcheck_render.py --report # 화면 문안 맞춤법
python3 tools/scn_callgraph.py              # 코드가 부르는 맵을 벗어난 배정(폴백 구간용)
python3 tools/check_scn_jp_left.py          # 일본어 잔존(ED1 은 0 이어야 한다)
```

## 유저 손이 필요한 것

- 🔴 **`kr/ed1-ch2` 는 `main` 위로 리베이스돼 있다**(2026-08-10, 두 번). `origin/kr/ed1-ch2` 에
  올리려면 **force-push 가 필요하다** — 푸시는 유저 몫이라 손대지 않았다.
  되돌릴 백업 브랜치 둘: `kr/ed1-ch2-prerebase` · `kr/ed1-ch2-prerebase2`. 확인 끝나면 지운다.
  ⚠ 히스토리에 **문서만 남은 쌍둥이 커밋**이 있다(제목이 `main` 의 `…덤프를 빌드가 만들게` 와
  같다) — `main` 이 코드 몫을 갖고 이쪽은 문서 몫만 남았다. 제목 정리는 미결.
- **커밋은 순서대로 쌓는다**(유저 확정 2026-08-10) — 장별로 한 커밋씩, QA 반영은 그 장의
  **다음 커밋**으로. 과거 커밋에 끼워 넣지 않는다(같은 JSON 을 뒤 커밋들이 계속 고쳐 충돌하고,
  "무엇을 언제 알았는지"가 무너진다).
- 외부 의존물은 **2026-08-09 기준 전부 최신**이다 — emucap 0.14.1 · create-kr-patch 1.2.1 ·
  patch-template. ⚠ **emucap 을 올린 세션에는 Claude Code 재시작이 필요하다**(MCP 서버가
  메모리에 물려 있어 구 바이너리로 붙어 있다).
- ⚠ **이 머신엔 emucap 어댑터(에뮬레이터 바이너리)가 없다.** 인게임 확인은 맥
  (DuckStation)에서 한다. 여기서 돌리려면
  `sh vendor/emucap/adapters/mednafen/build.sh` + BIOS 배치 —
  [machine-setup.md](../../../docs/machine-setup.md) ③.
- `vendor/emucap` 의 "수정된 파일 3개"(`adapters/desmume-nds/patches/*.patch`)는 **해소됐다**
  — 우리가 고친 게 아니라 CRLF 변환 탓이었고, 그 경로만 변환을 끄면 끝난다(2026-08-09).
  절차는 [machine-setup.md](../../../docs/machine-setup.md) ②.
