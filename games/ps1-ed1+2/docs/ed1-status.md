## 문안이 어디서 오는가 — **정본이 전부다** (2026-08-19)

08-18 자체 번역 전환의 종착점이다. 화면에 나가는 블록은 하나도 빠짐없이 `script/` 의 `t`
에서 온다 — `align_map`·`align_overrides` 는 이제 **문안을 안 나른다.** 다만 그 표를
지우면 안 된다: **구조 지시**(`inject_pairs`·`nl_after`·`fold_name`·`trail_nl`·`blank`)가
아직 거기 있고, `t` 를 적어도 그 필드들은 살아남는 설계다(`_load_overrides` 의 `_ALIGN_KEYS`
가 걷는 건 배정 필드뿐).

|      |                                                                                      |
| ---- | ------------------------------------------------------------------------------------ |
| 정본 | `script/ED1SCN*.json` — `{"1100": {"t": "…", "s": "병사"}}`. **커밋된다**(우리 문안) |
| 초안 | `work/review/draft_ED1SCN*.json` — 옮기기 전 화면 문안. **커밋 금지**(정발)          |
| 검증 | `script_draft.py --verify` — 초안을 그대로 넣었을 때 같은 바이트가 나오는가          |

**여섯 씬 전부 자체 번역으로 끝냈다**(2026-08-19). 화면에 나가는 블록의 문안은 하나도
빠짐없이 `script/` 에서 온다 — 정발 포인터 0. 남은 블록은 **전용 빌더 관할**(보물상자·
상점 가격)과 화면에 안 나가는 것(포인터 표·이진 잔재)뿐이다.

**전 씬에서 오역 100종 이상.** 유형은
[mistranslation-patterns.md](../../../docs/reference/mistranslation-patterns.md) 에 모았다
(게임 무관 — 다음 프로젝트에서 볼 자리를 좁힌다).

### 이관에서 굳은 두 가지

- **원문이 같으면 문안도 같아야 한다.** 원작은 상점·숙소·신부 응대를 마을마다 복제해 두고,
  블록 단위로 옮기면 같은 원문에 다른 문안이 붙는다(SCN3 도구점 한 벌에서만 31곳).
  검출기: `python3 tools/check_dup_jp.py [씬]` — 판정용이라 게이트가 아니다.
  ⚠ **인자(`%s`·`%d`)가 든 블록은 통일에서 뺀다** — 보이지 않는 센티널이 날아간다.
- **화자는 원문 헤더가 정답이다.** 이관 중 예순 곳 남짓을 되돌렸다(`check_speakers`).

### 커밋 전에는 `sh scripts/check.sh`

빌드만으로는 절반이다 — 조판·이름창·표기는 빌드가 안 본다. 28초.
⚠ 게이트는 **지금 고칠 수 있는 것**만 실패로 친다(안 옮긴 씬의 후보는 「할 일」이다).

⚠ **판정 규율** — 문안을 쓸 때 **반드시 JP 원문과 뜻이 맞는지 본다**(유저 지시 2026-08-12
"항상 원문과 의미가 맞는지 검토하는 과정도 꼭 지켜줘"). 오역 판정은 우리가 하는 것이라
틀리면 정발보다 나빠진다 — 고친 자리는 `note` 에 원문 근거를 남긴다.
⚠ 이 문서는 **현재 상태 + 남은 일만** 둔다 — 닫은 절은 지우고, 그 안의 함정은 그때
[text-pipeline.md](text-pipeline.md)(도구·절차) 또는
[our-findings.md](../../../docs/reference/our-findings.md)(재사용 기법)로 **옮긴다**.

## 시작하기 — 첫 명령은 빌드다

```bash
cd games/ps1-ed1+2
python3 tools/build.py        # → work/build/<브랜치>/Eiyuu Densetsu (KR).bin/.cue
```

**통과하면 그대로 작업을 시작하면 된다.** 머신이 바뀌었든 파생물이 낡았든 상관없다.

**`work/` 는 통째로 지워도 된다** — `rm -rf work/` 후 23초 재빌드로 **바이트 동일** 확인
(2026-08-19). 원본 덤프(`extract_scn` · `extract_dos_kr`)는 `build.py` 가 매번 새로 뜬다.

⚠ **한동안 깨져 있었다**(ED2 를 재삽입 체인에 올린 2026-08-16 ~ 08-19). 재삽입기가
`work/derived/align/*_SCN*.json` 을 **파일로** 요구했는데 `build.py` 는 화자맵만 만들었다.
게다가 그 파일은 **다시 만들면 내용이 달라지는 판단물**(LaBSE 의미정렬 산출물)이라 빌드
입력으로 두는 것 자체가 제1 원칙 위반이었다. 지금은 화면 문안이 전부 정본(`script/`)에서
오므로 **정렬 파일이 없으면 빈 배정으로 진행**한다(있으나 없으나 sha1 동일 — 실측).
회귀 테스트: `test_align_file_is_optional_so_work_can_be_wiped`.

⚠ `align_jp_kr.py`(전체)·`align_semantic.py` 는 이제 **제안 도구 전용**이다 — 돌리면
그 파일들이 생기지만 빌드는 안 읽는다.

빌드가 **확정 락 위반**으로 멈췄다면 문안이 바뀐 것이다. 절차는 [policy.md](policy.md).

   ⚠ **먼저 배제할 것 하나** — 유저가 DuckStation 빨리감기를 난사하던 중이었다. 에뮬 쪽
   문제일 수 있으므로 **재확인 때는 빨리감기 없이** 그 자리를 지난다. 그러고도 멎으면
   그때 A/B 가 의미를 갖는다.

   근거·한계는 [our-findings.md](../../../docs/reference/our-findings.md) 「구조 계약」 절 —
   구조(`%c`/`%s`/`%d`)는 전량 일치하고 길이만 −4~−24 씩 준다. ⚠ **정적으로는 더 못 좁힌다**
   (세 갈래 검출기 전부 0 · 알려진 사례 다섯을 다 놓친다 — 같은 절에 표로 있다).

### ⚠ 저작권 축 — 닫혔지만 성격을 기억해 둔다

08-18 전환의 동기가 **품질이 아니라 저작권**이었다(유저: "정발 어투로 우리가 일괄

소진**에서 온 정발 유래였고, 그걸 전량 다시 써서 지금 4·3 만 남았다.

⚠ **유사도로는 못 가른다** — 축자 게이트는 공백 무시라 맞춤법 한 글자만 달라도 통과하고

⚠ **정발을 나란히 켜지 않는다**(2026-08-12 전환). 이제 대조할 저본이 없고, 볼 것은

## 유저 손이 필요한 것

- 🔴 **`main` 에 force-push 가 필요하다**(2026-08-13). 히스토리에서 정발 문안을 걷어내려고
  `git filter-branch` 로 29커밋을 재작성했고(오염 143→0), 이어서 작업 커밋들을 유형별로
  접었다. 푸시는 유저 몫이라 손대지 않았다 — `git push --force-with-lease origin main`.
  푸시가 끝나면 옛 히스토리를 붙잡는 참조를 지운다:
  `git update-ref -d refs/original/refs/heads/main` ·
  `git tag -d backup-before-scrub-2026-08-13 backup-before-squash` ·
  `git reflog expire --expire=now --all && git gc --prune=now`.
  ⚠ **force-push 후에도 옛 커밋은 SHA 를 알면 한동안 열린다** — 공개 레포에서 확실히
  지우려면 호스팅 쪽에 GC 를 요청한다.
- **커밋은 순서대로 쌓는다**(유저 확정 2026-08-10) — 장별로 한 커밋씩, QA 반영은 그 장의
  **다음 커밋**으로. 과거 커밋에 끼워 넣지 않는다(같은 JSON 을 뒤 커밋들이 계속 고쳐 충돌하고,
  "무엇을 언제 알았는지"가 무너진다).
- 외부 의존물은 **2026-08-09 기준 전부 최신**이다 — emucap 0.14.1 · create-kr-patch 1.2.1 ·
  patch-template. ⚠ **emucap 을 올린 세션에는 Claude Code 재시작이 필요하다**(MCP 서버가
  메모리에 물려 있어 구 바이너리로 붙어 있다).
- ⚠ **이 머신엔 emucap 어댑터(에뮬레이터 바이너리)가 없다.** 인게임 확인은 맥
  (DuckStation)에서 한다. 여기서 돌리려면
  `sh vendor/emucap/adapters/mednafen/build.sh` + BIOS 배치 —
  [machine-setup.md](../../../docs/machine-setup.md) ③.
- `vendor/emucap` 의 "수정된 파일 3개"(`adapters/desmume-nds/patches/*.patch`)는 **해소됐다**
  — 우리가 고친 게 아니라 CRLF 변환 탓이었고, 그 경로만 변환을 끄면 끝난다(2026-08-09).
  절차는 [machine-setup.md](../../../docs/machine-setup.md) ②.
