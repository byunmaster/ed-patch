## 6. 이번 정적 라운드가 실제로 잡은 것

규약과 우리 게이트를 항목째로 맞대 구멍 넷을 찾았고, 그중 **둘은 이미 화면에 나가는
결함**이었다.

| 무엇 | 어떻게 막았나 |
| --- | --- |
| 🔴 **포인터 표에 한글을 쓰고 있었다**(`ED2SCN2:300`, 327B 표) | `check_pointer_tables` |
| 🔴 **정본에 항목이 없어 원문이 나가던 블록 9개** | `check_jp_leak.untranslated()` |
| 🔴 ISO 물리 배치를 보는 눈이 없었다 | `check_iso_layout` |
| 🔴 바뀐 구간을 되읽지 않았다 | `check_readback` |

넷 다 **게이트가 전부 초록인 채로** 존재하던 자리다 — 그래서 게이트를 늘렸다.
