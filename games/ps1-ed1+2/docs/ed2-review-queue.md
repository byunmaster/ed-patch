### 화자맵(이름창)

- `ボアード` 가 `*_speakers.json` 에서 **「브라도」**로 뜬다 — 본문은 정본대로 「보아드」다.
  **이름창만** 고치면 된다.

### 🔴 정본과 어긋난 원음 하나 (⚠ `shared/glossary` 는 공용이라 `main` 에서)

`ランケア` 를 정본은 **랑케아**로 적는다(우리 문안은 정본에 맞췄다). 다만 원음대로면
**란케아**다 — 정본을 고칠지 판단이 필요하다. 나머지 친서 셋(카논·하르파·마리스카)은 일치한다.

## 3. 번역투 — 축 자체가 거의 비었다

세 판 모두 **도치(후치 성분) 0건**이다. 남은 건 어휘 수준 넷뿐이라 억지로 고칠 자리가 아니다.

- `SCN9:195` 「악신 아그니쟈**에 의해**」 → 「의 손에」 (`~에 의해` 는 ED2 전체에 이 하나)
- `SCN8:75·154` 「…없게 되어 버린 **것이다**」 → 「…돼 버렸지」 (앞 문장은 구어체)
- `SCN8:500·602` 「화초**라고 하는** 거다」 → 「화초란 거다」
- `SCN11:126` 「황제 폐하**로부터** … 와 있을 터다」 → 「황제 폐하**께서** … 내리셨을 터다」
- `SCN2:316` 명령의 `のだ` 를 「~하는 것이다」로 (앞뒤는 명령형)
- `SCN4:30` 「~지 않으면 안 돼」 (원문이 `しないとだめ` 라 대응 자체는 정확하다)
