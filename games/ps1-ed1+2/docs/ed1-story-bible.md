# ED1 인물·말투 기준표 (검수용)

『영웅전설 I』(PS1 SLPS-01323 수록판) 한국어 번역 **검수의 판정 근거**다. 「이 대사가
이 인물다운가 · 이 상대에게 이 등급이 맞는가」를 여기서 판정한다.

- 🔴 **대사는 인용하지 않는다**(저작권). 전부 좌표로 가리킨다 — `ED1SCN3:573` = `script/ED1SCN3.json`
  의 `573`, 원문은 `work/derived/scn_jp/ED1SCN3.json` 의 같은 `entry_id`.
  문안을 나란히 볼 때는 `work/review/speaker_profile_ED1.md` 를 옆에 둔다.
- 근거는 **일본어 원문과 우리 한국어 문안뿐**이다. 정발판(만트라 DOS) 문안은 이 문서의 근거가 아니다.
- 확인 못 한 것은 **⚠ 미확인**으로 남겼다. 추측으로 채우지 않았다 — 틀린 확신이 훨씬 해롭다.

## 0. 먼저 읽을 것 — 화자 라벨은 그대로 믿으면 안 된다

`script/*.json` 의 `s`(화자 라벨)에는 구조적인 함정이 셋 있다. 검수가 라벨로 대사를
묶는 순간 여기서 새므로 먼저 못 박는다.

| 함정                                             | 실측                                                                       | 뜻                                                                                                                                                                   |
| ------------------------------------------------ | -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **이름창 없는 블록은 라벨이 앞 창에서 상속된다** | 현자 153/178 · 도구점 97/193 · 남자 72/236 · 랄프 36/82 블록이 이름창 없음 | 두 사람이 번갈아 말하는 체인에서 **상대 대사에 남의 라벨**이 붙는다. 예: `ED1SCN3:981·982·989~992` 는 라벨이 「제르만」이지만 실제 화자는 류난(원문에서 형을 부른다) |
| **이름창이 `%s` 인 블록이 있다**                 | 병사·게일·도구점·해리·폴스·아토스 국왕 등                                  | 화면에 뜨는 이름은 런타임 인자다. 라벨은 참고값일 뿐                                                                                                                 |
| **한 라벨에 여러 인물이 섞인다**                 | 병사 303 · 남자 236 · 여자 150                                             | 익명 라벨은 개인이 아니라 **역할군**이다(3절)                                                                                                                        |

## 4. 라벨 정리 — 같은 사람인가, 다른 사람인가

### 🔴 「게일」과 「대도 게일」은 **다른 인물이다**

작업 지시에 "한 인물의 두 라벨"로 적혀 있었으나 **원문 확인 결과 조손 관계의 별개 인물**이다.
근거: `ED1SCN5:499` · `ED1SCN5:653`(대도 게일이 게일을 「내 손자」라 부른다) ·
`ED1SCN5:872~875`(게일이 랄프를 게일 2세 = 아버지로 알아본다) · `ED1SCN5:439`(게일이
「3세라 부르지 마라」고 조부에게 대든다).

```
대도 게일 (조부, 판가스의 대도)  →  랄프 (= 게일 2세, 가업을 버리고 고고학자)  →  게일 (= 게일 3세, 일행)
```

**두 라벨을 묶어 말투 일관성을 검사하면 안 된다.** 오히려 갈라 놓고, 서로를 부르는 등급
(`ED1SCN5:437·505` 게일→조부 = 막말 / `ED1SCN5:503` 조부→게일 = 해라체)을 봐야 한다.

### 🔴 남은 하나는 성격이 다르다 — 화면에 틀린 이름이 나간다

`ED1SCN3:981` · `989` 는 원문 이름창이 **`%s`(런타임 이름 치환)** 다. 우리 파이프라인은
이 자리에 **`s` 값을 그대로 박아 넣는다**(`reinsert_kr_pilot._tpl_name` — 화자맵이 `%s` 를
못 푸니 `s` 로 폴백한다). 즉 **`s` 가 곧 화면에 뜨는 이름**이고, 지금 값이 `제르만` 이다.

그런데 이 두 블록은 **에리온(류난)이 제르만에게** 하는 말이다 — 원문에서 `兄上`(형님)라
부르고, `993` 이 「여기서도 류난의 설교가 시작됐습니다」로 못 박는다. 화면엔 **제르만이
제르만에게 형님이라 부르는 꼴**로 나간다.

⚠ 이어지는 `982` · `990` · `991` · `992` 는 이름창이 없어 `s` 가 메타데이터일 뿐이다
(같이 고칠 값이지만 이미지는 안 바뀐다). **고치면 이미지가 바뀌므로 사전 보고 대상이다.**

⚠ 같은 꼴(`%s` 이름창 + `s` 폴백)이 **904 블록**이고 그중 **206 개에 `s` 가 박혀 있다.**
대부분은 의도된 주입(`퍼거슨`·`입구의 병사`·`밀매상`)이지만, **여기와 같은 오배정이 더
있는지는 안 훑었다** — 인게임 QA 에서 이름창을 특히 볼 자리다.

위 자리들은 예시고, **이름창 없는 블록 전체가 같은 상속 위험을 갖는다.**

## 8. ⚠ 미확인 — 채우지 않고 남긴 것

- **`ED1SCN1:1168~1174` 에서 합류하는 인물이 누구인가.** 라벨이 「나이프」(아이템 창)이고
  이름창이 `%s` 라 확정이 안 된다. 정황(`ED1SCN1:1176~1177` 의 탈출로 안내, `ED1SCN1:1297`
  페리시아의 언급)은 소니아를 가리키지만 **원문에 이름이 안 나온다.**
- **`ED1SCN5:1061` 의 실제 화자.** 라벨 「디나공주」가 틀린 것만 확실하다.
- **대도 게일이 "게일 1세"인지.** 원문은 그냥 「大盗賊 ゲイル」다 — 세대 번호를 붙이지 말 것.
- **아그니쟈의 말투.** 대사가 4블록뿐이라 판정 근거가 부족하다.
- **바바라와 라누라 왕가의 관계.** 성역의 노파 현자라는 것만 확인했다.
- **세리오스–디나 공주 혼약이 언제 정해졌는가.** `ED1SCN4:15·482·499` 의 정황뿐이다.
- **지라의 신분.** 판가스의 노인이라는 것만 확인(`ED1SCN5:698`).
- **로우의 최종 처지.** `ED1SCN5:587` 에서 판가스에 눌러앉은 것만 확인. 재합류는 확인 못 했다.
- **홀과 「도둑」 역할군의 경계.** 이름창으로만 갈리므로, 이름창 없는 블록은 어느 쪽인지 모른다.
- **`s`(화자 라벨)의 출처가 원문 이름창인지, 배정 과정의 판단인지**는 이 문서에서 확인하지 않았다.
  4절의 「라벨이 틀린 자리」는 **원문 이름창과 라벨이 불일치하는 것**만 근거로 골랐다.
