# 플레이 매뉴얼 — PS1 영웅전설 1+2 (에뮬 QA 용)

**켜기 전에 읽는다.** 조작 · 어디로 가나 · 막히는 자리 · 전투가 나는 자리.
🔑 **이식판 다섯이 그대로 물려받는다**(같은 게임이다) — 기종별로 다른 건 버튼 이름뿐이다.

⚠ **여기엔 실제로 해 본 것만 적는다.** ED1 완주 지식은 `devlog.md`·`ed1-status.md` 에
흩어져 있고, 필요해질 때 훑어 여기 옮긴다. 지금은 **ED2 부팅~서장**만 실측이다.

## 조작 (PS1)

| 할 것 | 버튼 |
| --- | --- |
| 확인·대화 넘기기 | **`circle`** |
| **필드 메뉴 열기** | 🔴 **`cross`** — `triangle`·`select` 는 안 열린다(2026-09-07 실측, 셋 다 눌러 봤다) |
| 취소·한 단계 뒤로 | `cross` |
| 타이틀 진입 · **오프닝 건너뛰기** | `start` |
| 커서 | 방향키 |

⚠ emucap 에서 **커서 이동은 `press_frames` 3~4** 면 한 칸이다. 대화 넘기기는 `circle` +
`after_frames` 150 이 안정적이고, **화면 전환·로딩은 200~900** 을 준다.

## ED2 부팅 순서 (실측 2026-09-07, 프레임은 `reset` 기준 대략치)

    reset → step 2600            Falcom 로고 → 컬렉션 타이틀
    start                        작품 선택 버튼 둘이 뜬다 (`영웅전설Ⅰ` / `영웅전설Ⅱ`)
    right → circle → step 1200   ED2 오프닝 내레이션 (여러 화면)
    start                        🔴 **오프닝을 건너뛴다** → ED2 타이틀
    left → circle                `처음부터` (오른쪽이 `이어하기`)
    circle × 12~14               서장 대화 (라우엘) — 여기가 길다
    → 조작 자유                   장 카드 `서장 / 평화로운 나날` 이 뜨고 아트라스가 움직인다

🔴 **서장 이벤트가 길다.** 대화 창이 열두어 개 이어지고 그 사이엔 **필드 조작이 안 열린다** —
`cross` 를 눌러도 메뉴가 안 뜬다. **다 넘겨야 열린다.** 첫 회차에 여기서 「메뉴가 안 열린다」로
두 번 헛돌았다.

## 세이브

- 🔴 **ED2 세이브는 시작 하나뿐이다**(카드 슬롯15 `２ Ｌ０１ ０１파렌`). 그 뒤 자리는 **전부
  직접 진행**해야 한다 ⇒ 체크포인트를 만들면 그게 곧 자산이다.
- 카드는 `/root/save/ps1-ed1+2/`. **이미지가 바뀌면 카드 이름(해시)이 달라져 빈 카드로 뜬다** —
  `sh scripts/emu.sh` 가 실행 직전에 맞춘다. MCP 로 직접 띄우면 그 보정이 없다.

## 메뉴 구조 (실측)

    필드 메뉴(cross)   주문 · 사용 · 장비 · 버린다 · 상태 · 그외   ⚠ 일행이 하나면 `리더` 가 없다
    그외               SAVE · LOAD · 시스템 · 전투설정
    상태               고르면 **헤더 상자에 `상태` 가 뜨고 대상 선택 대기** → `circle` 한 번 더

⚠ **명령을 고르면 목록 위에 헤더 상자가 겹쳐 뜬다** — 첫 항목이 가려져 목록이 바뀐 것처럼
보인다. 바뀐 게 아니다.

## 🔴 서장 실내에서 **안 되는 것**

- **도구·주문이 안 걸린다.** 횃불은 밝은 실내라 반응이 없고 회복 주문은 HP 가 가득이라
  안 걸린다 ⇒ **행동 결과 메시지(`…을(를) 사용했다`)를 보려면 던전이나 전투로 가야 한다.**
- **장비를 바꿀 수 없다.** 여벌이 없어 `장비` 는 화면만 보이고 교체 메시지가 안 난다.
- ⚠ 이 셋을 모르고 실내에서 붙들면 **「메시지가 안 뜬다」를 결함으로 오해**하기 쉽다.

## 메뉴 커서

**커서 위치가 기억된다** — 메뉴를 닫았다 열면 마지막 자리에서 시작한다. `그외` 에서 닫았으면
다시 열 때 `그외` 가 열린다. ⇒ 자동화로 항목을 고를 땐 **위치를 가정하지 말고 위로 몰아서**
(`up` ×5) 첫 항목으로 초기화한 뒤 세는 게 안전하다.
