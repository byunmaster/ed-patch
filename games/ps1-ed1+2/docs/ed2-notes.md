# ED2 작업 주의사항

ED1(1편)과 ED2(2편)는 **같은 게임 폴더·같은 이미지·같은 도구**를 쓴다. 트랙이 갈리는 게
아니라 한 패치 안의 두 편이라, 겹치는 자리마다 사고가 난다. 여기 모아 둔다.

진행 현황은 [ed2-status.md](ed2-status.md), 씬 지도는 [ed2-scene-map.md](ed2-scene-map.md).

> **단일 워크트리로 간다**(유저 확정 2026-08-11). 처음엔 `kr/ed2` 브랜치를 따로 두고
> ED1 인게임 QA 와 병행하려 했지만, 겹치는 파일이 생각보다 많아 **한 브랜치에서 순서대로**
> 하기로 했다. 아래 「겹치는 것」은 그래서 **머지 충돌 문제가 아니라 작업 순서 문제**다.

## 🔴 씬을 재삽입 체인에 넣으면 ED1 이미지 배치가 밀린다

**단일 트랙에서 제일 조심할 자리다.** 원본 자리에 안 들어가는 씬은 이미지 뒤쪽 여유 공간으로
**순차 할당**된다:

```python
DUMMY_LBA = 91700  # 재배치 목적지(DUMMY.;1 시작). 순차 할당.
```

지금 ED1 이 `91700 · 91801 · 91908 · 92006 · 92072` 를 차례로 물고 있다
(`work/derived/scn_layout.json`). **`patch_sys_ui._scn_layout()` 에 ED2 를 넣는 순간 같은
공간을 함께 할당하므로 ED1 씬 LBA 가 밀린다.**

문안은 그대로라 **락은 통과하는데 이미지는 달라진다** — QA 중이던 빌드와 다른 물건이 된다.
확정 락도 무변경 구간 검사도 이걸 못 잡는다(둘 다 배치를 안 본다).

> **그래서 체인 등록은 ED1 인게임 QA 가 끝난 뒤에 한다.** 다행히 그 앞 단계(매핑·배정·검토·
> 검출기)는 **이미지를 한 바이트도 안 건드린다** — 실측으로 확인했다(ED2 작업을 하루 종일
> 하고도 이미지 sha1 이 `8d368c90…` 로 동일).

## ⚠ 겹치는 것 — 사고 지점

| 자원                                                            | 무엇이 위험한가                                                          |
| --------------------------------------------------------------- | ------------------------------------------------------------------------ |
| **이미지 배치(LBA)**                                            | 위 절 — ED2 를 체인에 넣으면 ED1 이 밀린다                               |
| `work/build/…(KR).bin`                                          | 빌드가 하나뿐이다. ED2 빌드가 QA 중인 이미지를 덮는다 — 순서대로 할 것   |
| ~~`dos_spelling_fixes.json`~~                                   | **파일을 갈랐다**(아래) — 이제 ED2 규칙이 ED1 을 안 건드린다             |
| `align_map.json` · `align_overrides.json` · `locked_lines.json` | 키가 `ED1SCN*`/`ED2SCN*` 로 갈려 서로 안 밟는다                          |
| `tools/*.py`                                                    | ED2 를 넣을 때 **ED1 동작이 안 변하는지**가 수용 기준 — 이미지 sha1 동일 |

### 🟢 치환 규칙 — 파일을 갈랐다 (2026-08-11)

예전엔 `spell_fix` 가 넘어온 엔트리가 ED1 인지 ED2 인지 몰라서 **ED2 를 겨냥한 규칙이 ED1
문안을 조용히 바꿨다** — `한 가운데에`→`한가운데에`(ED2 `사막 한 가운데에` 겨냥)가 ED1
`위험한 가운데에서` 를 붙여 버리고 있었다.

| 파일                          | 걸리는 곳      |
| ----------------------------- | -------------- |
| `dos_spelling_fixes.json`     | 공용 — ED1·ED2 |
| `dos_spelling_fixes_ED2.json` | **ED2 만**     |

`spell_fix(t, game)` 으로 게임이 흐른다 — `kr_entry` 가 표 이름(`ED2/C_000`)에서 떼어
엔트리에 stamp 하고 `parse_kr` 이 넘긴다.

**규율:**

- **ED2 규칙은 ED2 파일에.** 거기 있으면 ED1 엔 안 닿는다.
  ⚠ 반대 방향은 열려 있다 — **공용 파일 규칙은 ED2 에도 걸린다**(의도한 설계: 정발 두 판이
  같은 표기 관행이고, 되돌릴 수 없는 건 QA 를 끝낸 ED1 쪽뿐이다).
- 넓은 앵커는 그 게임 안에서도 넘친다 — 앞뒤 어절을 물려 좁힌다
  (`오십시오`가 아니라 `오십시오   동굴에`).
- 넣은 뒤 `python3 tools/check_spell_rules.py` (게임별로 사문을 센다).
  ⚠ 이 도구는 **코퍼스만 통과시킨다** — `subs`/`pre_subs` 로 잘라내는 블록엔 못 닿는데도
  「살아 있음」으로 나온다. **그 블록의 렌더를 직접 찍어 확인할 것.**

### 🚨 ED1 락 위반이 뜨면 그건 사고다

빌드가 `ED1SCNx: 확정 락 위반` 을 내면 **ED2 작업이 ED1 문안을 건드린 것**이다.

**절대 `--relock` 하지 말 것.** 그건 ED1 인게임 QA 결과를 무효화한다. 원인(대개 넓은 치환
규칙)을 찾아 좁힌다. `--relock` 은 "내가 의도해서 ED1 을 바꿨다"일 때만 쓴다.

### 📄 ED2 문서는 따로 쓴다

`docs/ed1-status.md` 는 이미 1,200줄이 넘는다. ED2 를 여기 얹으면 아무도 안 읽는다 —
현황은 [ed2-status.md](ed2-status.md), 씬 지도는 [ed2-scene-map.md](ed2-scene-map.md),
주의사항은 이 파일. **주제로 가르는 것**이지 브랜치로 가르는 게 아니다.

## ED2 착수 지점 — 어디까지 돼 있나

| 층               | 상태                                                              |
| ---------------- | ----------------------------------------------------------------- |
| JP 씬 추출       | ✅ `work/derived/scn_jp/ED2SCN1~13.json` (블록 계 7,875)          |
| 정발 ED2 코퍼스  | ✅ `work/derived/dos_kr/ED2/` **357표**                           |
| 씬↔정발 표 매칭  | ✅ `ed2_scene_tables.json` ([ed2-scene-map.md](ed2-scene-map.md)) |
| 번역 정본(SCN)   | ✅ `script/ED2SCN1~13.json` — 13씬 완주(예행 통과 7,025)          |
| 오버레이 주소    | ✅ ED2 = `0x80165000` (`check_overlay_base.py` 가 매번 재도출)     |
| 재삽입           | ⬜ 체인에 안 올림 — **ED1 QA 뒤에**(위 🔴)                        |

**남은 관문:** `patch_sys_ui._scn_layout()` 이 `ED1SCN1~6` 만 돌려준다. 재삽입·검출기가
전부 이걸 물고 돌므로 ED2 를 넣는 순간 **모든 도구가 ED2 를 같이 본다** — 한꺼번에 켜지 말고
씬 하나로 먼저 확인할 것. `OVERLAY_RAM_BASE` 는 이미 게임별 표(`OVERLAY_BASE`)를 타고
`overlay_for(씬)` 이 씬마다 세운다 — 안 세우고 부르면 죽는다(폴백 없음).

⚠ **국가명 플레이트 셋이 아직 어느 표에도 없다** — `ファーレーン`·`ウォンリーク`·`ラヌーラ`
(ED2SCN1 jp531~533). 지금은 ED2 가 체인 밖이라 무해하지만, 올리는 날 `patch_sys_ui.PLACES`
에 넣지 않으면 화면에 일본어로 남는다.

## 세션 시작 체크리스트

1. `games/ps1-ed1+2/CLAUDE.md` · 이 파일 · [ed2-status.md](ed2-status.md)
2. `python3 tools/build.py` — 통과하면 그대로 작업 시작
3. ED1 락 위반이 뜨면 위 🚨 절
4. ED2 를 건드린 뒤엔 **이미지 sha1 이 안 변했는지** 본다(체인에 올리기 전까지는 안 변해야 한다)
