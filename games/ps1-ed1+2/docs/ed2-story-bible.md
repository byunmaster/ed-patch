# ED2 인물·말투 기준표 (검수용)

『영웅전설 II』(PS1 SLPS-01323 수록판) 한국어 번역 **검수의 판정 근거**다.
[ED1 인물표](ed1-story-bible.md)의 속편이고 **형식·판단 기준을 그대로 잇는다** —
ED2 는 ED1 의 20년 뒤라(`ED2SCN7:503`) 인물이 이어지므로, ED1 이 세운 표기와 말투
등급을 **깨지 말고 물려받는다.**

- 🔴 **대사는 인용하지 않는다**(저작권). 전부 좌표로 가리킨다 — `ED2SCN3:1057` =
  `script/ED2SCN3.json` 의 `1057`, 원문은 `work/derived/scn_jp/ED2SCN3.json` 의 같은 `entry_id`.
  문안을 나란히 볼 때는 `work/review/speaker_profile_ED2.md` 를 옆에 둔다.
- 근거는 **일본어 원문뿐**이다. **ED2 는 아직 우리 번역이 거의 없다**(93% 재작성 대기)
  — 그래서 이 문서의 「원문 말투」는 실측이고 「한국어 등급」은 **지침**이다.
- 정발판 문안은 이 문서의 근거가 아니다. 확인 못 한 것은 **⚠ 미확인**으로 남겼다.
- ⚠ **씬 번호는 진행 순서가 아니다**(2절). 시간축이 필요한 자리는 원문으로 선후가
  확실한 것만 적었다.

## 0. 먼저 읽을 것 — 화자 라벨은 그대로 믿으면 안 된다

`script/ED2SCN*.json` 의 `s`(화자 라벨)에 걸린 함정은 여섯이다. 전부 **실측 수치**다.

| 함정                                             | ED2 실측                                                                            | 뜻                                                                                                       |
| ------------------------------------------------ | ----------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **이름창 없는 블록은 라벨을 앞 창에서 상속한다** | `s` 가 붙은 4,634 블록 중 **1,436(31.0%)** 이 이름창 없음                           | 두 사람이 번갈아 말하는 체인에서 **상대 대사에 남의 라벨**이 붙는다. 라벨로 대사를 묶는 순간 여기서 샌다 |
| **한 블록에 이름창이 둘**                        | **7건** (`ED2SCN4:727·785` · `ED2SCN5:484·487` · `ED2SCN8:147·242` · `ED2SCN9:334`) | `s` 는 **첫 화자만** 가리킨다. 뒤쪽 화자는 라벨에 안 잡힌다                                              |

## 4. 라벨 정리

### 4.1 🔴 게일가는 **3대가 전부 나온다**

ED1 인물표 4절의 조손 구분이 ED2 에도 **그대로 유효**하고, 여기서는 **세 사람이 같은 씬에**
등장한다(`ED2SCN11` — 조부는 `159~171`, 손자는 `315~325`. 둘 다 보물상자를 묻고 물건을 준다).

```
대도 게일 (조부, 아직 현역)  →  랄프 (= 게일 2세, 고고학자)  →  게일 3세 (= ED1 의 게일, 지저에서 실종)
```

근거: `ED2SCN7:561`(게일 2세 = 랄프) · `ED2SCN7:578`·`591`(대도 게일은 행방불명) ·
`ED2SCN7:581~582`(게일 3세는 영웅이고 조부의 뒤를 안 잇겠다며 늘 다툰다) ·
`ED2SCN7:503`(게일 3세가 세리오스의 아들을 알아본다).
**세 라벨을 묶어 말투 일관성을 검사하면 안 된다** — 조부는 わし·のじゃ, 손자는 てめえ·ぜ다.

`s` 가 `무기점`·`도구점` 이라 **물건 이름 자리에 가게 이름이 나갈 위험**이 있다
(`ED2SCN1:218·222` · `ED2SCN8:280·282`). ⚠ 실제 렌더는 확인 못 했다.

## 5. 말투 규칙표 — 누가 → 누구에게 → 어떤 등급

`tools/check_speech_level.py` 는 **해요체와 합쇼체를 기계로 못 가른다.** 그 구멍을 여기서 메운다.
"등급"은 우리 한국어 문안이 가야 할 자리고, "근거"는 그렇게 읽히는 **원문** 좌표다.

## 6. ⚠ 미확인 — 채우지 않고 남긴 것

- **씬 1~13 의 진행 순서.** 친서 4통(`ED2SCN2:319~321`)이 온리크·라누라·솔디스·모레스톤을
  가리키고 각각 SCN3·SCN4+5·SCN6·SCN7 에 대응하지만, **씬 파일은 지역 단위라 여러 시점을
  같이 담는다**(1절 ⚠). 장 구분 데모(`V_000`~`V_400`, `docs/ed2-scene-map.md`)와 씬 번호의
  대응은 확인 못 했다.
- **아트라스의 이름이 플레이어 입력인가.** 그의 대사 중 상당수가 이름창 `%s` 다
  (`ED2SCN2:330·339·344`). 고정 `アトラス` 창(180블록)과 공존하는 이유를 못 밝혔다.
- **`ED2SCN2:638~640` 에서 프레이아를 찾겠다는 인물.** 이름창이 `%s` 라 확정이 안 된다.
  말투(私 + です)와 `ED2SCN12:245` 의 정황은 플로라를 가리키지만 원문에 이름이 없다.
- **교육계 라우엘 = ED1 의 라우엘인가.** 원문 이름창이 다르고 신분도 다르다(연락책 → 교육계).
- **피트 = ED1 의 피토 / 훨스 = ED1 의 폴스인가.** 4.4절.
- **프레이아가 무엇인가.** 여신이고(`ED2SCN1:170`), 용의 알에서 대화할 수 있으며
  (`ED2SCN4:309`), 황제가 악용해 몬스터를 만들었다(`ED2SCN12:328`)까지만 확인했다.
- **신디를 용으로 알아보는 순서.** `ED2SCN12:281~285` 에서 밝혀지는 것만 확인했고, 그 전에
  일행이 눈치채는 자리는 못 찾았다.
- **로우·랄프·폼의 최종 처지.** 각각 `ED2SCN1`·`ED2SCN10` 등장까지만 확인했다.
- **화자맵(4.5절)의 오배정 셋이 실제로 화면에 나가는지.** 렌더로 확인하지 않았다.
- **`s`(화자 라벨)의 출처가 원문 이름창인지 배정 과정의 판단인지.** 4절은 **원문 이름창과
  불일치하는 것**만 근거로 골랐다.
