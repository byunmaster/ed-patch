이식판**이라 문안은 대부분 새로 만들지 않는다 — 대사 블록의 95.4% 가 PS1 과 축자 동일하다.

  막는 장치다. **PS1 ED1 이 main 에 머지돼 18,250 원문으로 찼다**(2026-09-06) — `docs/policy.md` 4절.

## 세션 시작 시

- **이 게임은 브랜치 `game/ss-ed1+2` 에서 한다** — 워크트리는 `sh scripts/worktree.sh ss-ed1+2`.
  ⚠ 공용(`shared/` · `scripts/` · `.claude/` · `docs/` · 루트 `CLAUDE.md`)은 여기서 고치지
  않는다 — main 에 넣고 받아 온다.
- **이 트리는 롬분석·기계 작업 전용**이다(유저 확정 2026-08-18) — 사람 판정(QA·대조)이
  필요한 일은 본 트리(ps1-ed1+2)의 흐름을 막지 않게 쌓아만 둔다.
- `docs/status.md` 를 먼저 읽는다(**지금 무엇이 막혀 있나**). 바뀌지 않는 것 — 원본
  지오메트리·파일 구조·폰트·**조판 계약**·재삽입 규약 — 은 `docs/policy.md` 다.
  정적 QA 결과 한 장은 `docs/static-qa-report.md`.
- ⛔ **도구를 늘렸거나 규칙을 새로 세웠으면 「사본이 생겼나」를 센다**(체크리스트 4-D).
  이 게임은 도구가 34개라 저절로 생긴다 — 하루에 다섯을 밟았다(2026-08-29: 열쇠 중립화표 ·
  `owned_elsewhere` · 창 총량 전제 둘 · 이름 규칙 셋 · 인코딩 한 줄 일곱 곳).
  🔴 갈리면 **한쪽 화면만** 깨지므로 인게임 QA 로도 잘 안 잡힌다.

      python3 tools/tests/test_scn.py        # 사본 탐지 회귀가 여기 있다
      grep -c '<의심되는 한 줄>' tools/*.py  # 셋 이상이면 정본을 만든다

  정본은 이미 셋이다 — `names.py`(이름·접미·내부 키) · `font.py`(문안 인코딩) ·
  `shared/text/line_key`(사전 열쇠). ⛔ `done_` 접두는 **끝난 1회성**이다(지우지 않는다).

## 알고 시작하는 것 (2026-08-18 정찰 실측 — ports-survey.md)

- 씬 파일: `/BIN/ED1SCN01~34.BIN` · `ED2SCN01~47.BIN` · `ED2MON01~10.BIN` (+`ED1INIT.BIN`).
  PS1(6·13) 보다 잘게 쪼개져 있다 — **블록은 같고 배치가 다르다.**
- 텍스트: 생 SJIS · `%c` 화자 구분 · `\n` 개행 · 00 패딩 — PS1 과 제어 규약 동일.
- 폰트: 독립 파일 — `11KANJI.FON` 4,375글리프 × 22B(16×11), 색인 `(ku−1)×94+(ten−1)`
  JIS 순차. `hangul_font.pack22()` 출력이 그대로 들어간다. `KANJI.FON`(24B, 16×12)·
  `ASCII.FON`·`KANA.FON`·`11ASCII.FON`(11B, 8×11)도 같은 자리(루트).
- 엔진: SH-2 (MIPS 아님) — 포인터 재배치·훅은 전부 새로 잰다.
- 조판은 **실측으로 닫혔다**(`docs/policy.md` 6절) — **전각 14자 · 창 7행**
  (RAM 눈금자 실측 2026-08-30 으로 정정. ⚠ 그전 값 「15자 × 5행」은 **틀렸다**),
  전각 advance 12px. 🔴 **엔진이 글자 단위로 접는다** — PS1 처럼
  우리가 개행을 다 넣는 게 아니라 **문단 개행만** 넣고 창당 총량(5줄)을 지킨다.
  ⚠ 그러니 PS1 조판기(krwrap 14슬롯·6줄)를 그대로 가져다 쓰지 않는다.
