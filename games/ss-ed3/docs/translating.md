# 대사를 옮기는 법 — 옮기는 사람이 여는 문서 하나

> 이 문서 **하나로** 맵 하나를 끝까지 옮길 수 있어야 한다. 사람이 읽어도 에이전트가 읽어도
> 같다. 말투 정본은 [`voice.md`](voice.md), 표기 정본은 공용 사전 `shared/canon/nouns/ed3.json`·정본 `shared/canon/ed3.json`(새 이름은 **후보로 관리자에게**, 게임 폴더에 새 JP→KR 표를 만들지 않는다),
> 지금 어디까지 왔는지는 [`status.md`](status.md).

## 0. 순서는 맵 번호다

`MAP001`(라그픽 마을)부터 번호가 곧 **스토리 순서**다. 앞 맵을 끝내고 다음으로 간다 —
인물이 이어지고 말투가 이어지기 때문이다. 남은 양은 `tools/progress.py --files`.

## 1. 흐름

```bash
python3 tools/progress.py --todo MAP0XX --by-who   # 검토표 (⚠ work/review — 커밋 금지)
#   → 번역 → games/ss-ed3/script/MAP0XX.json 에 {"블록번호": "문안"} 로 적는다
python3 tools/reinsert.py --check MAP0XX           # 🔴 예산·조판 계약
python3 tools/check_speech.py MAP0XX               # 높임·반말 혼용
python3 tools/check_fidelity.py MAP0XX             # 숫자·고유명사 빠짐
python3 tools/reuse_tr.py                          # 같은 원문을 쓰는 다른 맵에 복사
```

검토표 한 줄이 주는 것 — `who`(화자) · `jp`(원문) · `budget`(바이트) · `fits`(글자로 환산) ·
`narration`(전체화면 서술인가).

## 2. 🔴 계약 — 어기면 재삽입이 거부된다

- **길이 보존**이다. `budget` 은 **바이트**고 한글·전각은 **2**, 반각(공백·`.`·`,`·`?`·`!`·
  숫자)은 **1**(숫자는 1바이트여도 **화면엔 전각 폭으로 그려지고** 조판기도 1칸으로 센다), 제어(`\n`·`\f`)도 **1**. 예산보다 **짧아도 된다**(도구가 채운다).
  넘으면 그 블록만 통째로 안 들어가고 **화면에 일본어가 남는다.**
- **대화창은 전각 17칸 × 3줄.** 엔진이 17칸에서 접으므로 한 줄이 17칸을 넘으면 두 줄을 먹는다.
  ⚠ 원문이 이미 넘는 자리는 그만큼 봐준다(저자가 그렇게 썼다).
- 🔴 **`\f`(원문 덤프의 `0F`)는 페이지 넘김이 아니라 「대기점」이다.** 화면이 한 줄 올라가고
  다음 조각이 **이어 붙는다.** 그러니 **원문의 `\f`·`\n` 위치를 그대로 둔다** — 옮기면
  읽는 순서가 바뀐다. ⚠ 빈 줄로 끝나는 조각 뒤는 잘린다.
- **낱말 사이는 반각 공백**(0.5칸·1바이트). 전각 공백은 예산을 두 배로 먹는다 —
  ⚠ 단 **나레이션의 들여쓰기**(`　`)와 원문이 쓰던 전각 공백은 그대로 둔다.
- 게임이 쓰는 글자만 된다 — `・・・`(`…` 아님) · `〜`(`~` 아님) · `？！`는 반각 `?!`.
  없는 글자는 `hangul_map.encode_kr` 이 곧바로 운다.

## 3. 문안

1. **맞춤법·띄어쓰기는 기본이다.**
2. **화자마다 말투가 있다** — [`voice.md`](voice.md). 검토표의 `who`(블록 머리 `02 XX`)가
   화자를 가른다. `0200` 쥬리오 · `0201` 크리스가 전 대사의 25%다.
3. **한 블록 안에서 화계를 섞지 않는다.** 「~습니다/~요」로 열었으면 끝까지.
   ⚠ 예외는 **한 블록 안에서 말 상대가 실제로 바뀌는 자리**뿐이다.
4. **관계가 화계를 정한다** — 아이가 노인에게는 높임, 동행끼리는 반말. 쥬리오·크리스는
   서로 반말이고 어른에게는 높인다. 인물 관계는 `docs/reference/eiyuu-setting.md` 와
   `.local/keep/guide/` 의 공략(줄거리·정체)에서 확인한다.
5. **고유명사는 공용 사전(`shared/canon/nouns/ed3.json`)이 정본이다.** 없으면 거기 규칙대로 정하고 **후보로 올린다**.
   🔴 **짧은 이름은 빈도만 보고 정하지 않는다** — 그 이름이 **어느 맵에 나오는지**까지
   맞춘다(`work/derived/map_jp/*.json` 에 맵 이름이 있다). `ゴダル`(넬바)에 `ゴーダ`(안데라)의
   표기를 붙였던 적이 있다.
6. **길이는 낱말로 맞춘다** — 예산이 모자라면 어미를 자르지(「~습니다」→「~슴」) 말고
   짧은 낱말로 바꾸거나 문장을 다시 짠다.

## 4. ⚠ 조사를 타는 조각

앞에 **런타임 인자**(금액·아이템 이름)가 붙는 조각이 있다. 원문에 첫 글자가 없는 것처럼
보이는 항목이 그것이다(`でいいよ。`). 받침에 따라 갈리는 조사(**을/를 · 이/가 · 은/는**)를
쓰면 「휴대 식량를」이 나온다. 쉼표로 끊거나 받침과 무관하게 쓴다.

    (대금 지불 공손 꼬리) →  "을 치르겠습니다."   ← 이미 쓰는 문안(금액 뒤라 안전)
    (매입 공손 꼬리) →  "에 사들이겠습니다."
    (서술 꼬리)       →  "입니다."

## 5. 안 하는 것

- **원문을 커밋하지 않는다** — 검토표·페이로드는 `work/review/` 밖으로 안 나간다(루트 「저작권」).
- **`MAP000` 은 손대지 않는다** — 디버그 맵이다.
- **`shared/`·`scripts/` 를 고치지 않는다** — 여기는 게임 브랜치다.
- **밀린 블록**(`mapfile.suspect_head`)은 검토표에 아예 안 나온다. 건드리지 않는다.

## 6. 끝낸 뒤

`reuse_tr.py` 를 돌려 같은 원문을 쓰는 다른 맵에 퍼뜨리고, `sh scripts/check.sh` 로 닫는다.
⚠ **역번역 대조**(`tools/backtrans.py MAP0XX`)는 네트워크가 드니 게이트가 아니라 손으로 돌린다 —
뜻이 미끄러진 자리를 순위로 준다(점수가 낮다고 오역은 아니다, 사투리·조사 회피도 깎인다).

### ⚠ 예산과 줄 수는 **따로** 재야 한다

`hangul_map.encode_kr` 로 바이트만 재면 **줄이 넘치는 걸 못 본다** — 예산이 남아도 한 줄이
17 전각을 넘으면 두 줄을 먹어 페이지가 4 줄이 된다(실측: MAP044 에서 바이트 초과는 0 인데
창 계약 위반이 4 건이었다). `typeset.overflows()` 를 같이 돌리거나, **`reinsert.fit()` 을
그대로 부르면 둘 다 본다** — 그게 가장 확실하다.

## 7. 에이전트로 굴릴 때 (유저 확정 2026-08-27)

맵 하나에 에이전트 하나를 붙여 **대여섯을 동시에** 굴린다. 맵 파일이 갈려 있어 서로 안 겹친다.
에이전트에게 주는 것은 **이 문서 · `voice.md` · 정본 · 그 맵의 배경 몇 줄**이면 된다.

⚠ 에이전트에게 **금지**시킬 것 — `git` · `reuse_tr.py` · `stamp_script.py`(둘 다 전 맵을 건드린다) ·
`shared/`(사전·정본 포함)·`scripts/`·남의 `MAP*.json` 수정.
**새로 지은 이름은 보고만 하게 하고 정본에는 내가 올린다.**

🔴 **`reuse_tr.py`·`stamp_script.py` 는 굴리는 중인 맵을 빼고 돌린다.** 둘 다 **전 맵을 다시
쓰기 때문에**, 에이전트가 그 맵을 옮기는 중이면 「읽고 → 옮기고 → 쓴다」 사이에 끼어들어
서로를 덮는다. 실측 2026-08-27: MAP021 이 작업 도중 **딴 맵 문안으로 바뀌어** 에이전트가
`HEAD` 에서 다시 쌓아야 했다. 둘 다 `--skip` 을 받는다.

    python3 tools/reuse_tr.py --skip MAP026 MAP031     # 지금 누가 굴리는 맵

⚠ 에이전트 임시 파일도 겹친다 — `b1.py` 같은 이름을 스크래치패드에 만들면 **서로 덮어쓴다.**
맵별 하위 폴더를 쓰게 한다.

🔴 **배치가 끝나면 반드시 이 넷을 돈다.** 안 돌리면 굴릴수록 어긋난다.

```bash
# ① 에이전트가 새로 지은 이름을 정본 후보로 올린다(관리자에게 후보로 — 사전은 워커가 못 고친다)  ← 안 하면 다음 맵에서 갈린다
python3 tools/stamp_script.py     # ② 원문 지문 — 「어긋난 것 0」이 블록이 안 밀렸다는 증거다
python3 tools/reuse_tr.py         # ③ 같은 원문을 쓰는 다른 맵에 퍼뜨린다
python3 tools/reinsert.py --check && python3 tools/check_speech.py && python3 tools/check_fidelity.py
sh scripts/check.sh               # ④
```

⚠ **①이 진짜 병목이다.** 실제로 두 번 갈렸다 — `潮騒の道`(파도길 / 물결소리 길) ·
`鷹の爪号`(매발톱호 / 매의발톱호). 둘 다 **맵 이름 칸이 4자로 묶여** 대사 쪽 긴 이름을
못 받는 자리였다. 🔑 **이름은 가장 좁은 칸에 맞춰 하나로 정하고 정본에 올린다** —
화면에서 두 이름이 섞이면 다른 것으로 읽힌다.

⚠ 에이전트가 「알려진 오탐이라 넘겼다」고 보고하면 **검사기를 고쳐라.** 넘기는 경고는 곧
아무도 안 보는 경고가 된다(`check_fidelity` 의 짧은 이름 부분일치를 그래서 고쳤다).
