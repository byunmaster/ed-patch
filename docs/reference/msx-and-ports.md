# MSX · 타기종 이식 사례

**MSX의 천국**(네이버 카페 `msx`, clubid `24860319`)에서 건진 자료. 이름과 달리 이 카페의
「타기종(66·67)」 게시판이 **PC엔진 · PC-8801 · PC-9801 · DOS · SFC · MD** 한글화의
실제 작업기가 모이는 자리라, 우리 로드맵(PCE·SS·PC98)과 정면으로 겹친다.
MSX 본체 게시판(16·24·25·28)은 하드웨어 제작기가 많고, 그중 **폰트 확장·BIOS 디스어셈블**만
우리 쪽에 값이 있다.

> 출처: msx 카페. 요약은 우리 말로 다시 쓴 것이고 발췌가 아니다. 원문은 각 항목 링크.

---

## 1. PC엔진 — 이스 IV (CD-ROM²)

- **한글 폰트를 SYSTEM CARD(CD-ROM BIOS)에 넣는 방식**을 썼다. 게임 이미지가 아니라
  **BIOS 쪽에 글리프를 얹는** 접근이다.
- 🔴 **그 대가로 실기에서 조건이 붙는다** — 게임을 띄우기 전에 BIOS 선택 메뉴에서
  `syscard3_korean` 을 골라야 하고, 기기에 따라 롬과 같은 폴더에 BIOS 파일을 두면 자동으로
  대치되기도 한다. HuCard 계열 기기와 CD-ROM 에뮬 기기(Super HD System 3 pro)에서 모두
  동작은 확인됐다.
- ⚠ 교훈: **BIOS·시스템 자원에 얹는 한글화는 에뮬에서 잘 돌아도 실기 배포 조건이 하나 는다.**
  실기 검증을 남에게 부탁해서 받는 흐름이 카페에서 실제로 돌았다.
  ([작업 공개](https://cafe.naver.com/f-e/cafes/24860319/articles/34973) ·
  [실기 요청](https://cafe.naver.com/f-e/cafes/24860319/articles/34799) ·
  [실기 결과](https://cafe.naver.com/f-e/cafes/24860319/articles/34805))

## 2. PC엔진 — 에메랄드 드래곤 (Super CD-ROM²)

- **음성 컷신 자막을 스프라이트로** 얹었다(영문 패치가 낸 길을 따랐다).
- 🔴 **스프라이트 자막은 배경이 비친다** — 컷신 스프라이트와 겹치는 자리에서 자막 뒤로
  배경이 그대로 통과한다. 영문판은 **검은 레터박스**로 가렸지만 컷신이 가려지는 게 아까워
  통과를 감수하는 쪽을 골랐다. 글자 뒤만 검게 칠하는 안은 가려지는 면적이 너무 커서 되돌렸다.
  ⇒ **자막 배치는 「가림 vs 비침」 둘 중 하나를 고르는 문제**지 양립하지 않는다.
- **배포는 브라우저 웹 패처**다(파일이 서버로 안 간다). 우리 `patcher/` 와 같은 형태.
- 🔴 **「모르는 판입니다」** — 웹 패처가 **원본 지문을 못 알아보는 덤프**가 실사용에서 나온다.
  제작자가 목록에 없는 덤프를 제보받아 추가하는 식으로 대응한다.
  ⇒ 우리 패처도 같은 자리를 지난다. `docs/publishing.md` 의 배포 지문과 짝지어 볼 것.
- **버그 신고에 세이브 파일을 같이 받는다** — 그 지점부터 바로 재현되니 확인이 훨씬 빠르다.
  ([v0.6](https://cafe.naver.com/f-e/cafes/24860319/articles/35036) ·
  [v0.9](https://cafe.naver.com/f-e/cafes/24860319/articles/35091))

## 3. DOS — 젤리아드 (Zeliard)

- 콘솔 롬이 아니라 **DOS 실행파일**을 한글화한 사례. 「폰트 확장도 되고 용량 제약도 없을
  것 같다」는 낙관으로 시작했다가, 대사가 파일로 안 빠져 있어서 **왜 여태 한글화가 없었는지**를
  알게 됐다는 후기가 그대로 남아 있다.
- 완성판에서는 한글화에 더해 **실시간 미니맵(S 키)·전체맵(R 키)** 을 새로 넣었다 — [mod]
  성격의 기능 추가까지 간 사례.
  ([도전기](https://cafe.naver.com/f-e/cafes/24860319/articles/34796) ·
  [공개](https://cafe.naver.com/f-e/cafes/24860319/articles/34937))

## 4. MSX — 룬워스 폰트 확장 (문서화가 잘 된 사례)

가나 문자만 쓰는 디스크 게임에 **한글 글리프를 넣는 전 과정**을 블로그에 정리한 글.
`print_text`·`print_font` 함수를 찾아 디스크 오프셋까지 짚고, **8×10 폰트를 8×12 로 늘리는**
프롤로그 훅을 건다. 소스도 공개.

- 원문 정리: <https://sehwa.github.io/msx/hangul/2023/07/02/msx-runeworth-hangul-patch.html>
- 💡 저자 본인의 결론이 재미있다 — **현실적으로는 커스텀 칸지롬을 쓰는 쪽이 여러모로 낫다.**
  「할 수 있다」와 「그렇게 하는 게 낫다」가 다르다는 것.
- 💡 **문서화가 자기를 구한다** — 몇 달 묵혔다 돌아왔을 때 반쯤 써 둔 글 덕에 두 번 일하지
  않았다고 적었다. 우리 `devlog.md` 규율과 같은 이야기.
  ([카페 글](https://cafe.naver.com/f-e/cafes/24860319/articles/29006))

## 6. MSX 본체 쪽에서 쓸 만한 것

- **한글 롬·폰트팩** — MSX 는 기기 자체에 **한글 롬**이 있는 계보(대우·금성)가 있어서,
  한글화가 「폰트를 넣는 문제」가 아니라 **「어느 한글 롬을 쓰느냐」** 가 되는 경우가 있다.
  폰트팩 인식 실패 문의가 질문 게시판에 반복적으로 올라온다.
- **디스어셈블 자료** — MSX2 Korean BIOS
  ([#1692](https://cafe.naver.com/f-e/cafes/24860319/articles/1692)) ·
  대우 DPQ-280 디스크롬
  ([#4523](https://cafe.naver.com/f-e/cafes/24860319/articles/4523)) ·
  msx.org 의 `rs232.rom`
  ([#34477](https://cafe.naver.com/f-e/cafes/24860319/articles/34477)) ·
  MSX BIOS 분석용 IDA 스크립트
  ([#1634](https://cafe.naver.com/f-e/cafes/24860319/articles/1634)).
- **문서 묶음** — MSX BASIC·DOS·ASM PDF(5부), Z80·TMS9918·V9938 PDF(2부),
  메탈기어 Z80 어셈블리 소스
  ([#28714](https://cafe.naver.com/f-e/cafes/24860319/articles/28714)).
- ⚠ **롬 카트리지를 물리적으로 만드는 글이 많다**(적출·39SF040 이식·핀아웃). 우리 작업과는
  무관하지만, 「한글판을 실기에서 돌리려는」 수요가 이 커뮤니티의 동력이라는 건 알아 둘 만하다.
  ([대항해시대 한글화 팩](https://cafe.naver.com/f-e/cafes/24860319/articles/31804))
