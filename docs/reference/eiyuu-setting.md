## 세계관

- 아주 먼 옛날 고대 문명이 **파괴신 아그니쟈**에게 무너졌고, 그 뒤 인류가 다시 일으킨
  세계가 무대다.
- 나라는 다섯 — **파렌 왕국 · 라누라 왕국 · 온리크 공국 · 솔디스 왕국 · 모레스톤 공화국**.

## ED1 — 인물 관계

| 인물 | 정체·관계 |
| --- | --- |
| **세리오스** | 파렌 왕자. 아버지 **아스엘** 선왕이 **10년 전 대신 아크담에게 암살**됐다 |
| **아크담** | 파렌 대신. 선왕을 죽이고 섭정하다 세리오스까지 노린다 |
| **류난 = 에리온** | 라누라 **셋째 왕자**. 신분을 숨기고 있다. **프라토가 큰형** |
| **소니아** | 레지스탕스 지도자 **아론의 손녀**. 뒷날 류난과 혼인해 라누라 왕비가 된다 |
| **게일** | **대도 게일(1세)의 손자**. 도적 가업을 마다하고 모험가의 길로 간다 |
| **랄프** | 고고학자. 실은 **게일 2세**(게일의 아버지) |
| **디나 공주** | 솔디스 왕녀. **다섯 살 때 양가 아버지들이 정한 약혼자**가 세리오스다 |
| **제스톤** | 온리크 공국의 통치자. **페리시아 왕비의 오라비**(세리오스의 외숙) |

## ED2 — **ED1 에서 약 20년 뒤**

**나락의 입** — 대지진으로 지상과 지저를 잇는 동굴이 생겼다. 지저에는 고대 문명의 후손인
**지저인**의 도시 **파게스타**가 있고, **마스터**라 불리는 기술자들이 그곳을 관리한다.
**고드윈 2세**가 폭정을 편다.

| 인물 | 정체·관계 |
| --- | --- |
| **아트라스** | 주인공. **세리오스와 디나의 아들**, 파렌 왕자 |
| **란도** | **온리크 공국의 마법사**. 삼십 대 중년이다 |
| **플로라** | **라누라 낫슈 마을**의 부잣집 아가씨 |
| **신디** | 기억을 잃은 여전사. 실은 **ED1 에 나온 용을 사람으로 바꾼 존재**다 |
| **세리오스** | **파렌 국왕**. 초반에 나락의 입을 조사하다 사로잡힌다 |
| **에리온**(ED1 의 류난) | **라누라 국왕** |
| **소니아** | **에리온의 왕비** |
| **게일 3세** | ED1 의 게일 |
| **게일 1세** | ED1 의 대도 게일. 지금은 **이즈의 시장**이다 |

**진행 순서** — 각국에 친서 전달 → 플로라 합류 → 지저 세계 발견 → 레지스탕스와 손잡고
고드윈 2세에 맞섬 → 신디의 정체가 드러남 → 최종 결전.
⚠ 우리 씬 번호(`ED2SCN1~13`)와의 대응은 **아직 확정 안 됐다** — 이건 순서의 얼개일 뿐이다.
