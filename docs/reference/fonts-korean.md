## 인코딩·음절표

7비트 완성형에서 실사용되는 한글 음절만 추린 집합 3종. 사용 가능한 글자 수가 적고 폰트 확장이 어려운 환경에서, 번역 전문(全文)에 실제로 등장하는 글자만 뽑아 최소 글자 수로 적용하려는 용도다. 번역을 모두 마쳐두는 부담 없이 무리 없이 적용해볼 수 있는 마지노선급 최소 집합으로 제시됨(실제로는 이보다 넉넉하거나 2350+자를 넣을 수 있는 경우가 더 많다고 저자가 부연).

첨부 파일 3종:
- 청계천한글 1317자
- 대우한글 1566자
- 옴니한글 1359자

정렬은 인코딩 순서가 아닌 가나다순. 출처 자료는 문자 집합 위키(charset.fandom.com, 7비트 완성형 대조표 등)를 활용.

- 원문: https://cafe.naver.com/f-e/cafes/16259867/articles/29189

## Python 폰트 제작 스크립트

### 그라데이션 폰트 만들기 (Python 3 + PIL)

이미지 형태의 폰트(글자 이미지)를 대량으로 찍어내는 스크립트. NDS 이하 구기종에 적합. 팔레트/인덱스 이미지를 다뤄야 하는 상황에서 포토샵보다 PIL의 P모드 조작이 편하다는 점을 활용.

- 입력: 1픽셀 세로줄을 복사해 만든 그라데이션 이미지(grad.png), 그릴 문자열(Text), 폰트, 셀 수(CellCount = 원본 이미지 width).
- 출력: 그라데이션이 입혀지고 테두리·그림자가 붙은 글자 이미지(원본 필요 부분에 붙여 사용).
- 핵심 로직:
  1. `grad.png`를 열어 글자 크기에 맞게 `resize((CellCount*8, 16))`.
  2. `L` 모드 alpha 이미지에 `ImageDraw.text(..., anchor='mm')`로 글자를 흰색으로 그림.
  3. `image.putalpha(alpha)`로 그라데이션을 글자 모양에만 입힘.
  4. 별도 `RGB` solid 이미지에 좌표를 1칸 밀어 그림자용 글자(stroke_width=2)와 본 글자(stroke_width=1)를 stroke로 테두리와 함께 그림.
  5. `solid.paste(image, image)`로 그라데이션 글자를 덮어 최종 합성.
  6. 이후 포토샵 Image > Mode > Index로 원본 팔레트를 옮겨 인덱스에 맞춤(필요한 팔레트 칸만, 예: 16칸 1줄 형태로 넣어야 문제가 덜함). posterize는 PIL보다 포토샵 결과가 나아 포토샵 사용.
- 원문: https://cafe.naver.com/f-e/cafes/16259867/articles/27923
