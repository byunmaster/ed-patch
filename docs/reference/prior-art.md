# 선행 프로젝트 — 남이 먼저 뜯은 것

**「이미 누가 풀었나」를 먼저 본다.** pc98 이 이 문서를 처음 쓴 계기가 그것이다 — 영문 패치
레포를 열자 **막혀 있던 이틀치가 풀렸다**(제어코드 **길이**는 우리가 이미 갖고 있었는데
**뜻**을 몰라 인자 11바이트짜리를 통째로 놓치고 있었다, 61곳).

🔑 **가져올 것은 길이가 아니라 뜻이다.** 표를 갖고도 끝까지 안 쓴 것이 구멍이다.

## 보는 순서

1. **우리가 「모른다」고 적어 둔 것부터** 대조한다(상태 문서의 「아직 모르는 것」).
2. **「안다」고 믿는 것도 대 본다** — 놓치는 건 대개 「모르는 것」이 아니라 **「알지만 안 쓰던 것」**이다.
3. ⚠ **사실만 우리 말로** 적고 **값으로 검산**한다. 「거기 그렇게 적혀 있다」는 **가설**이다.
4. ⚠ **없으면 「찾았는데 없더라」를 적는다** — 안 적으면 다음 사람이 또 찾는다.

🔴 **남의 팬 번역 문안은 안 본다.** 존재만 적는다 — 옮겨 적는 것 자체가 저작권 문제이고,
같은 세션에서 읽으면 **문맥이 오염된다**(스킬 `rpg-translate` §2-2). 공식 발매판(정발·공식
영문판)은 **표기를 재는 자**로만 쓴다(방침 ②: 이름을 물려받지 않는다).

## PS1 영웅전설 III·IV (ps1-ed3+4) — 2026-09-08 조사

### 결론

- **PS1 판을 뜯은 선행 작업은 못 찾았다.** 스크립트 추출기·아카이브(GMF) 도구·제어코드 표
  어느 것도 공개된 게 없다. GitHub 의 팔콤 도구는 전부 **한참 뒤 세대**(궤적 시리즈)이고
  우리 규격(GMF 아카이브 · 자체 16비트 코드표 · 12×12 밀착 폰트)과 무관하다.
  ⇒ **역공학은 우리가 처음 하는 것이 맞다.** 다시 찾지 않는다.
- **문안 쪽에는 선행이 있다** — 아래 셋. 다만 **표기를 재는 데만** 쓴다.

### 값으로 검산한 것 — 공식 영문판 이름 vs 우리 정본

영문판 표기(`Avin` · `Eimelle` · `Rutice` · `Mile`)를 우리 것과 맞대 봤다. **넷 다 안 어긋난다:**

    アヴィン  Avin    ← 우리 「어빈」   정발 36회 (에이빈·아빈 0)
    アイメル  Eimelle ← 우리 「아이멜」 정발 30회 (에이멜 0)
    ルティス  Rutice  ← 우리 「루티스」 정발 18회 (루티세 0)
    マイル    Mile    ← 우리 「마일」   정발 44회

⇒ **정발 한글 표기가 공식 영문판과 같은 원어를 보고 있다**는 확인이다. 우리 정본
(`glossary_ed4.json`)을 그대로 간다. ⚠ 「어긋나면 한쪽이 틀린 것」이라 어느 쪽이든 남는 검산인데,
이번엔 **맞는 쪽**으로 남았다.
💡 곁가지 — `アヴィン` 이 아직 실행파일 낱말 표 밖이라 정본에 못 넣었다(`todo`). 영문판이
**Avin** 인 것이 그 자리를 찾을 때 **검산 재료**가 된다.

### 못 찾은 것 (다시 찾지 않게)

- **ED3 의 챕터·플래그 변수 자리** — 우리가 「모른다」고 적어 둔 1순위인데 **선행에 없다.**
  PS1 판을 뜯은 사람이 없으니 당연하다. ⇒ 우리가 이벤트 VM 쪽에서 찾는다(커서 `0x800DD734`
  까지 와 있다).
- GMF 아카이브·`.TI3/.AM3` 압축·12×12 폰트 규격을 다룬 공개 자료 — 없다.
- Geofront 프로젝트의 기술 문서 — 사이트가 403 이라 못 읽었다. 나중에 다시 볼 값은 있다.
