# 오역이 나는 자리 — 유형 대장

**옛 번역본을 저본으로 삼을 때 어디서 어긋나는가.** 『영웅전설 1』 정발(만트라, 90년대)을
저본으로 두고 원문과 전수 대조하며 모은 것이다. **유형은 게임을 안 가린다** — 다음
프로젝트에서 볼 자리를 먼저 좁히라고 남긴다.

⚠ **저본 문안을 그대로 옮기지 않는다**(저작권 — 루트 [CLAUDE.md](../../CLAUDE.md)).
어긋난 **방향**과 낱말 수준만 적고, 재현이 필요하면 블록 좌표로 찾는다.

## 왜 이게 필요한가

**오역은 화면만 봐선 못 잡는다.** 그 자체로 자연스럽게 읽히기 때문이다. 실제로 이 목록은
전부 「인게임 QA 를 통과한 뒤」 원문 대조에서 나왔다. 사람이 두 게임을 나란히 켜고 봐도
못 잡는 부류가 있고, 그게 아래 ①②⑤다.

## 유형

### ① 어휘 오독 — 사전을 잘못 짚는다

한 낱말을 다른 낱말로 읽고, 문장 전체가 그럴듯하게 재구성된다. **가장 안 잡힌다.**

| 원문 | 바른 뜻 | 어긋난 쪽 |
| ---- | ------- | --------- |
| `決して` | 결코 | **결정할 때** (`決` 만 보고) |
| `こざかしい` | 건방지다 | **깜찍하다** (`小賢しい` 의 `小` 를 귀엽다로) |
| `いろいろな国` | 여러 나라 | **여러 가지로** + 나라 안에서 |
| `どこでしょうか` | 어디입니까 | **어떻습니까** |
| `名をかたる` | 사칭하다 | **이름을 말하다/떠들다** |
| `お戻りになり` | 돌아가시어 | 전혀 다른 구절로 대체 |

⇒ **한자 한 글자만 겹치는 낱말**과 **관용구**(`名をかたる`)를 의심한다.

### ② 방향·시제·주체가 뒤집힌다

문장은 매끄러운데 **누가 무엇을 언제** 하는지가 반대다.

| 원문 | 바른 뜻 | 어긋난 쪽 |
| ---- | ------- | --------- |
| `行ってきました` | 갔다 **왔다** | **가십시오**(명령) |
| `解放したそうですね` | 풀어 주셨다**지요**(완료) | 풀어 줄 **예정** |
| `続きました` | 이어졌**습니다**(과거) | 계속될 **겁니다**(미래) |
| `寝かせてくれ` | (나를) 재워 **줘** | (네가) 자 **두거라** |
| `我々に任せて` | **우리**에게 맡기고 | **나**에게 맡기고 |
| `お待ちしておりました` | 기다리**고 있었습니다** | 기다려 **주십시오** |

⇒ 수수(授受) 동사(`~てくれ`·`~てあげる`)와 시제 어미가 최다 발생지다.

### ③ 숫자·고유명사

| 원문 | 바른 값 | 어긋난 쪽 |
| ---- | ------- | --------- |
| `レベル６` | 6 | **8** |
| `南西` | 남서 | **남** |

⇒ 기계적으로 전수할 수 있는 유일한 부류다. **숫자·방위는 정규식으로 훑는다.**

### ④ 뜻이 정반대

비꼼·부정이 긍정으로 뒤집힌다. 문맥을 모르면 그대로 읽힌다.

- `どうせ たいしたこちゃねぇんだろ`(어차피 별것 아니겠지 — **비꼼**) → **칭찬**으로
- `呪文を教えてしんぜよう`(가르쳐 주지) → **가르쳐 줄 수 없네**
  ⇒ 이건 오역이 아니라 **이식 차이**였다(아래 ⑥).

### ⑤ 조각이 잘리거나 남의 대사가 붙는다

저본이 한 문장을 **여러 엔트리로 갈라** 두면, 앞부분만 가져와 꼬리가 사라진다.
저본과 이식본의 창 구조가 다를 때 필연적으로 생긴다.

- `왕자!?` 에서 끊기고 `자, 잠시만 기다려 주십시오` 가 통째로 사라짐
- `약속이니. 확실히.` 로 끝나 **주문을 준다는 말 자체가 없어짐**
- 이어지는 말(`その建物ってのがねー` = 그 건물이 말이야…)이 **완결된 문장**으로 바뀜

⇒ 저본 엔트리를 **끝까지 따라간다.** 종결부호가 없으면 반드시 뒤가 있다.

### ⑥ 이식 차이 — 오역이 아니다

**저본과 이식본의 게임 로직이 다르면 문안도 달라야 한다.** 이걸 오역으로 보고 고치면
반대로 틀린다.

- 오델로 노인: 저본(DOS)은 재방문 때 게임을 안 하면 안 가르쳐 주는데 **이식본(PS1)은
  게임 없이도 가르쳐 준다.** 저본엔 거절 분기 문안이 있고 이식본엔 그 분기가 없다.
- 저본에만 있는 연출(입장 안내 · 지역 신앙 대사)은 이식본에 대응 블록이 아예 없다.

⇒ **분기 조건이 다른지부터 확인한다.** 문안이 반대면 대개 로직이 다르다.

### ⑦ 캐릭터 개성이 뭉개진다

원문은 **감탄사 한 글자**로 인물을 가른다. 비슷한 대사를 아무거나 가져오면 그게 지워진다.

    ん!? / お!?          같은 상황, 다른 주인공
    うーん / うーむ       같은 감탄, 다른 인물
    あれ、君は…君 / あなたは…さん   격식이 다르다

⇒ 시점별 사본이 있는 게임에서 특히 위험하다. **원문 화자와 어미를 먼저 본다.**

### ⑧ 이름창에 남의 이름

저본 엔트리의 화자를 그대로 물려받으면, 이식본에서 **화자가 다른 자리**가 어긋난다.
알현 장면처럼 여러 인물이 번갈아 말하는 구간이 최다 발생지다(한 장면 전체가 왕비 이름표를
달고 나가던 실측).

⇒ **원문 화자 헤더가 정답이다.** 기계적으로 전수할 수 있다 —
[`check_speakers.py`](../../games/ps1-ed1+2/tools/check_speakers.py).

## 잡는 법 — 비용 순

1. **숫자·방위·고유명사** — 정규식 전수. 싸고 확실하다(③).
2. **화자** — 원문 헤더와 대조. 기계적으로 완결된다(⑧).
3. **길이 비** — 원문 대비 우리 문안이 너무 짧으면 꼬리가 잘린 것이다(⑤).
   [`check_align_fit.py`](../../games/ps1-ed1+2/tools/check_align_fit.py).
4. **호출 그래프** — 코드가 어느 맵에서 그 블록을 부르는지 보면 남의 대사를 잡는다.
   [`scn_callgraph.py`](../../games/ps1-ed1+2/tools/scn_callgraph.py).
5. **전 블록 원문 대조** — ①②④⑥⑦은 **이것 말고 방법이 없다.** 30% 지점에서 16종이
   나왔다. 기계가 후보를 좁혀 주지 못하는 영역이라, 처음부터 이 비용을 예산에 넣는다.

## 저본을 쓸 때의 방침

옛 번역본은 **저본이지 정답이 아니다.** 그래서 이 프로젝트는 방침을 이렇게 잡았다
(2026-08-12, [policy.md](../../games/ps1-ed1+2/docs/policy.md)):

> 저본을 그대로 옮긴다 → **저본의 향수를 살리되 오역·개성 소실·어색함은 고친다**

⚠ **오역 판정은 우리가 한다 — 틀리면 저본보다 나빠진다.** 고친 자리는 원문 근거를
남기고, 검수할 수 있게 둔다.

⚠ **문체는 층마다 다르다.** 옛 번역본은 대개 **시스템 메시지는 평어체 · 해설은 높임말**로
가른다(반복 노출되는 로그 vs 이야기를 들려주는 톤). 한쪽 방침을 다른 층에 적용하면
문안 길이가 바뀌어 **크기 계약을 깨고 블록이 통째로 탈락**할 수 있다 — 그러면 화면에
원문이 그대로 남는다. 실제로 그 사고를 냈다.

⚠ **의역이 문학적으로 나아 보여도 시대의 결에서 벗어나면 향수가 깎인다.** `続きました` 를
`이어졌습니다`(현대적)보다 `계속되었습니다`(직역)로 잡은 것이 그 예다 — 해설·서술문에서는
직역 쪽이 대체로 맞는다.
