# 공통 번역 규칙 — 전 기종·전 게임

마스터 2026-10-08: 「공통 번역 규칙을 정해 두면 좋을 것 같다」. **모든 kr 트랙 게임이 지킨다.** 이 문서는
**규칙 목록의 정본**이고, 근거·경위·세부는 끝의 「자세히」 문서에 있다. 게임마다 다른 것(칸 폭·글꼴 경로·
기종 사정)은 각 게임 `docs/policy.md` 에 두되, **여기와 어긋나면 여기를 따른다**(바꾸려면 마스터 확인).

문안을 쓰거나 검수하기 전에 한 번 훑는다. 검사기로 지킬 수 있는 건 게이트로 만든다(표의 「게이트」 열).

## 1. 부호·폭

| # | 규칙 | 게이트 |
| --- | --- | --- |
| 1-1 | 공백과 ASCII 부호 `. , ! ?` 는 **반각** | 조판 지문 · 게임 게이트 |
| 1-2 | `…` `～` `「」` 는 **전각** | ↑ |
| 1-3 | 🔴 **`…` 는 전각 한 글자, 점 셋은 한국식 바닥(마침표 높이)** — 일본식 가운데 점은 어느 게임에서도 나오면 안 된다(10-08). 마침표 셋 `...` 도 쓰지 않는다. 원문 점 n 개(`･･･`·`・・・`·`…`)는 「…」 round(n/3)개(최소 1), 남는 점은 버린다 | 글리프 테스트 · `...` 잔존 게이트(게임별) |
| 1-4 | **ＥＰ·ＭＰ·ＨＰ 는 전각**(PS1 정본과 같게, 1-1 의 예외 — 10-08) · **장 번호 「제１장」도 전각 숫자**(장 카드·HUD 장 제목·장 띠 — 정본 chapter 꼴, 1-5 의 예외, 마스터 10-11 「장카드 같은건 전각이 어울리지 않나」). 번호↔제목 간격은 반각 2칸(=전각 1칸 폭) | 정본 검사 |
| 1-5 | 숫자는 반각, 숫자+단위는 붙여 쓴다(`3개`·`100G`). 숫자 끝 조사는 읽는 소리대로(`레스1을`·`레스2를`) · 단 전투 보상은 PS1 꼴로 띄운다 — `EP n 포인트 획득`(마침표 없음) · `n Gold를 얻었다.`(마스터 10-09 「ps1 전투 기준」) | 숫자·단위 게이트 |
| 1-6 | 🔴 **전투 문장은 모든 창에서 공백·문장부호가 반각**(마스터 10-09) — 반각 훅이 안 닿는 창(승리·레벨업·커맨드 창 등)도 넓혀서 맞춘다. 예외는 전각 — `…`(1-3)·ＥＰ·ＭＰ·ＨＰ(1-4). 🔴 **ED1·ED2 같은 몬스터 여럿에 붙는 A·B·C·D 는 전 기종·전 몬스터 반각**(마스터 10-10 「일관성 깨지는건 도저히 참을수가 없다」 — 원판은 전각 160·반각 4(캐리온크롤러)로 섞였고, 전각이면 이름 칸이 모자란 예외가 생긴다). 접미 글자와 뒤 조사 사이에 **틈을 두지 않는다** — 「슬라임C를」(PS1 꼴, 마스터 10-10 「붙이자 ps1도 붙이잖아? 규칙은 동일해야지」) | 화면 확인(전투 묶음 ③) |

## 2. 조판(줄·칸)

| # | 규칙 | 게이트 |
| --- | --- | --- |
| 2-1 | **부호 뒤에 공백 없이 글자를 붙이지 않는다** — `,` `.` `!` `?` 다음엔 반각 공백(줄 끝·닫는 」 앞 제외). 전각 부호를 쓰던 자리를 반각으로 바꿀 때 특히 본다(10-08) | 조판 검사 |
| 2-2 | 부호 **앞** 공백은 언제나 뗀다 | 조판 검사 |
| 2-3 | **고아 부호 금지** — 줄 첫머리에 부호만 넘어가지 않게 | 조판 여섯 규칙 |
| 2-4 | **빈 줄 개행 금지** — 꽉 찬 줄 뒤 개행이 빈 줄을 만들지 않게 | ↑ |
| 2-5 | **줄 첫 칸 공백 금지** | ↑ |
| 2-6 | **어절 단위 개행** — 낱말 가운데서 끊지 않는다(로그·자막도) | ↑ |
| 2-7 | 칸·창에서 **글이 사라지면 안 된다**(블록 탈락·잘림) | 화면 바이트 게이트 · 글 소실 불변식 |
| 2-8 | 반각으로 줄이 짧아지면 **원래 정렬(가운데·왼쪽)을 다시 맞춘다** | 화면 확인 |
| 2-9 | 🔴 **전투 보상은 줄을 나눈다**(ED1·ED2 전 기종, 마스터 10-10) — 「…를 해치웠다.」 / 「ＥＰ n 포인트 획득」 / 「n Gold를 얻었다.」 **셋 다** 새 줄에서 시작(PS1 꼴 — 「피해! 슬라임을 해치웠다.」처럼 앞 줄에 붙이지 않는다). 로그를 이어 쓰는 기종도 보상 줄 앞에서 개행한다 | 화면 확인(전투 묶음 ③) |
| 2-10 | 🔴 **한 줄에 나올 수 있는 문장은 한 줄로**(전 기종, 마스터 10-10) — 창 한 줄에 들어가는 문장을 두 줄로 쪼개지 않는다. 앞 줄에 남은 칸이 모자라면 문장을 **새 줄에서 시작**한다(「류난에게 / 19의 피해!!」 → 「류난에게 19의 피해!!」 · 「경험치 40, / 4 Goa를 얻었다!」 → 한 줄 · 「…올랐다. MP가 / 5포인트 올랐다.」 → 「MP가 5포인트 올랐다.」를 새 줄에). 한 줄보다 긴 문장만 2-6 어절 단위로 나눈다. 전투 문안부터 적용(라운드 ③) | 화면 확인 · 조판 검사 |

## 3. 표기·맞춤법

| # | 규칙 | 게이트 |
| --- | --- | --- |
| 3-1 | **맞춤법·띄어쓰기 준수**(표준국어대사전 기준) | 맞춤법 검사(spellcheck) |
| 3-2 | 화자 이름(호칭·관계·직함 합성)은 띄어 쓴다 — `여관 주인`·`크리스 엄마`(ED1~4) | 정본 speaker |
| 3-3 | 🔴 **고유명사·공통 문안(메뉴 라벨·호칭·시스템·전투 문구·장 제목)은 정본(`shared/canon`)을 따른다** — 원문이 같을 때. 게임 폴더에 JP→KR 표 금지(스태프롤만 예외) | 이름 검사 · 정본 검사 · 자기 표 검사 |
| 3-4 | 지명은 **칸에선 붙이고 대사에선 띄운다**(`엘아스타마을` / `엘아스타 마을`) — [`naming.md`](naming.md) | 이름 검사(갈래) |
| 3-5 | 조사는 런타임 조사 훅으로 고른다 — 병기 `을(를)` 을 화면에 남기지 않는다 | 조사 일치 검사 |
| 3-6 | 🔴 **칸이 모자라면 기술(재배치·넓히기) 먼저**, 안 되면 칸 꼴을 제안해 마스터 확인 → 정본 `원문@자리`. 줄인 꼴부터 쓰지 않는다 | — |

## 4. 문체

| # | 규칙 |
| --- | --- |
| 4-1 | 🔴 **원문(JP) 기반 자체 번역.** 정발은 **참고**만 — 고유명사 표기와 애매한 표현을 정할 때. 팔콤 원문·정발 문장을 문서·주석·테스트에 **통째로 옮기지 않는다**(저작권) |
| 4-2 | **원문에 가깝게** — 후보가 갈리면 원문 쪽. 단 **마스터 QA 판정이 원문 우선보다 앞선다** |
| 4-3 | **번역투 금지** — 일본어 어순·피동·「~의」 남발·직역 관용구를 한국어 문장으로 다시 쓴다 |
| 4-4 | **캐릭터 개성을 살리는 말투** — 인물별 말투(존대·반말·어미 버릇)를 그 게임의 인물·관계 정본(story bible)대로, 같은 인물은 전 기종에서 같은 결 |
| 4-5 | 화자 이름은 **오독될 때만** 덧붙인다(원판이 감춘 화자를 까지 않는다) |
| 4-6 | 색·연출 제어 코드는 **원판 그대로** — 바꾸는 건 글자뿐(색을 고르는 건 개조다) |
