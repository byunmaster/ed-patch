# 공통 번역 규칙 — 전 기종·전 게임

마스터 2026-10-08: 「공통 번역 규칙을 정해 두면 좋을 것 같다」. **모든 kr 트랙 게임이 지킨다.** 이 문서는
**규칙 목록의 정본**이고, 근거·경위·세부는 끝의 「자세히」 문서에 있다. 게임마다 다른 것(칸 폭·글꼴 경로·
기종 사정)은 각 게임 `docs/policy.md` 에 두되, **여기와 어긋나면 여기를 따른다**(바꾸려면 마스터 확인).

문안을 쓰거나 검수하기 전에 한 번 훑는다. 검사기로 지킬 수 있는 건 게이트로 만든다(표의 「게이트」 열).

## 1. 부호·폭

| 1-6 | 🔴 **전투 문장은 모든 창에서 공백·문장부호가 반각**(마스터 10-09) — 반각 훅이 안 닿는 창(승리·레벨업·커맨드 창 등)도 넓혀서 맞춘다. 예외는 전각 — `…`(1-3)·ＥＰ·ＭＰ·ＨＰ(1-4). 🔴 **ED1·ED2 같은 몬스터 여럿에 붙는 A·B·C·D 는 전 기종·전 몬스터 반각**(마스터 10-10 「일관성 깨지는건 도저히 참을수가 없다」 — 원판은 전각 160·반각 4(캐리온크롤러)로 섞였고, 전각이면 이름 칸이 모자란 예외가 생긴다). 접미 글자와 뒤 조사 사이에 **틈을 두지 않는다** — 「슬라임C를」(PS1 꼴, 마스터 10-10 「붙이자 ps1도 붙이잖아? 규칙은 동일해야지」) | 화면 확인(전투 묶음 ③) |
| 1-7 | 🔴 **물결표 `～` 뒤에 마침표를 붙이지 않는다** — `불렀어～.` ✗ → `불렀어～` ✓. 물결표가 문장 끝 부호 노릇을 하므로 `～.` 는 문법상 틀린 겹침이다(마스터 10-12, PS1 정본도 `～.` 0건) | 조판 검사(추가 예정) · 게임 게이트 |

| 2-1 | **부호 뒤에 공백 없이 글자를 붙이지 않는다** — `,` `.` `!` `?` 다음엔 반각 공백(줄 끝·닫는 」 앞 제외). 전각 부호를 쓰던 자리를 반각으로 바꿀 때 특히 본다(10-08) | 조판 검사 |

| 2-9 | 🔴 **전투 보상은 줄을 나눈다**(ED1·ED2 전 기종, 마스터 10-10) — 「…를 해치웠다.」 / 「ＥＰ n 포인트 획득」 / 「n Gold를 얻었다.」 **셋 다** 새 줄에서 시작(PS1 꼴 — 「피해! 슬라임을 해치웠다.」처럼 앞 줄에 붙이지 않는다). 로그를 이어 쓰는 기종도 보상 줄 앞에서 개행한다. 「ＥＰ」 뒤 공백은 **화면을 보고 게임마다** 정했다(마스터 10-13, 비교샷) — **있음**: PS1·새턴·md 의 ED1·ED2 · sfc-ed1 · pce-ed1 / **없음**(「ＥＰ1 포인트 획득」): sfc-ed2 · pce-ed2 | 화면 확인(전투 묶음 ③) |
| 2-10 | 🔴 **한 줄에 나올 수 있는 문장은 한 줄로**(전 기종, 마스터 10-10) — 창 한 줄에 들어가는 문장을 두 줄로 쪼개지 않는다. 앞 줄에 남은 칸이 모자라면 문장을 **새 줄에서 시작**한다(「류난에게 / 19의 피해!!」 → 「류난에게 19의 피해!!」 · 「경험치 40, / 4 Goa를 얻었다!」 → 한 줄 · 「…올랐다. | 2-11 | 🔴 **`…` 뒤에 말이 이어지면 반각 공백을 띄운다**(전 기종, 마스터 10-12) — `그대도…잊었다` ✗ → `그대도… 잊었다` ✓. 줄 끝·닫는 부호(`」` `?` `!` 등) 앞은 띄우지 않는다. 🔴 **문장 맨 앞에 오는 `…` 는 붙인다** — `…그랬던 것 같았다.` ✓ · `… 그랬던` ✗(마스터 10-13 「...이 문장 말줄임이 아니라 앞에오는 ...이면 븥이는게 맞을듯」 — 10-12 관리자 해석 「줄 첫머리도 띄운다」를 대체). 띄우는 건 말줄임(앞말 뒤에 오는 `…`) 다음에 말이 이어질 때뿐이다. **예외: 한 낱말을 음절마다 끊어 말할 때는 붙인다**(`세…리…오…스…` · `조…심…해…라…` · `없…다…`, 마스터 10-12) — 끊긴 조각이 모여 한 낱말이면 붙이고, 낱말이 바뀌면 띄운다. **같은 소리를 되풀이하는 의성어도 붙인다**(`흑…흑…흑…`), **`…` 뒤 여는 괄호도 붙인다**(`…(화끈!)`)(마스터 10-13) | 조판 검사(추가 예정) · 게임 게이트 |
| 2-12 | 🔴 **물음표·느낌표와 `…` 가 겹치면 `…` 를 앞에** — `…?` · `…!` · `…!?`(`소, 소니아…!? 어째서…` ✓ · `소니아!?…` ✗). 원문의 `？…`·`！…` 순서를 그대로 옮기지 않는다(전 기종, 마스터 10-13 「?… 은 좀 어색한것 같은데?」 → 「오케 그렇게하자」) | 게임 게이트(`[?!]…` 검출) |
| 2-13 | 🔴 **쉼표는 한국식으로 — 원문의 `、`를 기계적으로 옮기지 않는다**(전 기종, 마스터 10-14 「쉼표는 한국식으로 넣자」) — 일본어는 주어 뒤·짧은 연결 뒤에도 `、`를 찍지만 한국어는 아니다. **남긴다**: 부르는 말 뒤(`아트라스,`) · 감탄·응답 뒤(`그래,` `어머,`) · 나열(`란도, 플로라,`) · 앞 절이 길어 쉼이 꼭 필요한 곳(드물게). **뺀다**: 주어·주제 뒤(`파렌 왕국은,` ✗) · 부사어 뒤(`처음에는,` ✗) · 짧은 연결 어미 뒤(`~하고,` `~받으며,` ✗) · 줄 끝이라 줄바꿈이 이미 쉼을 주는 곳. 문장 끝 부호(`.` `…` `!` `?`)는 원문을 따른다. **경계 사례**(마스터 10-14 「추천대로」): ① 「아니」로 말을 고칠 때는 **앞 쉼표 남김·뒤 쉼표 뺌**, 줄 끝이어도(`앞으로의 우리, / 아니 모든 사람의`) — 단 ED1 오프닝 첫 줄 `아주 먼 옛날… 아니, 어쩌면`은 09-17 판정 그대로 · ② 줄 끝에 걸린 **나열은 남김**(`파렌, 온리크, / 라누라…`) · ③ 접속부사 뒤는 뺌(`다만 언제까지나`) · ④ 시처럼 되풀이되는 `~할 때,`는 남김(앞의 `담아,` `않고,` `이와,`는 뺌) · ⑤ 짝을 이룬 두 구(`갈라지는 대지,`)·⑥ 동격(`가장 큰 재앙, 라우알의 파도`)·⑦ 말머리 군말·맞장구(`하지만 말이야,` `아하하,`)·⑧ 부르는 말 **앞**(`왜 그래, 왕자님?`)은 남김. 오프닝·엔딩부터, 메뉴·전투·씬도 같은 규칙 | 기종 대조표(관리자) |
| 2-14 | 🔴 **음성 자막은 줄마다 가운데 정렬**(애니메이션 자막 느낌 — pce-ed1 · pce-ed2 · ss-ed3, 마스터 10-15 「아무래도 음성자막은 가운데정렬로 하는게 맞는것 같아. 애니메이션 자막같은 느낌으로. sfc,md는 책읽는 느낌으로 왼쪽정렬로 하고.」) — 폭은 2-8대로 재서 줄 끝 `.` `,` `…`는 뺀다(길이가 같고 한 줄에만 마침표가 붙으면 시작이 맞는다 — 대관식 「위아래 같은 위치에서 시작」이 이 경우였다). **세로**: 화면 **위쪽**에 놓이는 자막은 한 줄이면 **첫째 줄 높이**(위 맞춤 — 마스터 10-15 「자막이 위쪽에 있을떈 한줄은 위쪽에 align 되게 해줘. 아래에 있을때만 바닥에 align이야.」) · 그림 위 **아래쪽**에 얹히면 한 줄 자막은 두 줄 자막의 **둘째 줄 높이**(바닥, 「자막은 한줄일떈 바닥에 붙어나오게 하자」) · 그림 아래 **검은 띠** 안이면 한 줄 자막은 **첫째 줄 높이**(위 — 띠 바닥에 붙이면 그림과 떨어져 어색하다, 10-15 비교샷). **줄 수**: 줄 폭을 최대한 넓혀 **두 줄**에 담고, 어쩔 수 없을 때만 세 줄(마스터 10-15 「자막줄은 최대한 칸 늘려서 두줄에 나오게 하고 어쩔수 없을때만 3줄로 하자」). **줄마다 정확히 가운데** — 두 줄 시작을 억지로 맞추지 않는다. 폭은 줄 끝 `.` `,` `…`를 뺀 실제 글자(잉크) 폭, 가운데가 반 px 로 떨어지면 왼쪽으로 내린다(마스터 10-15 미리보기 A·B′·C 비교 뒤 「C로 하자」 — 앞서 「0.5칸은 왼쪽으로」 시작 맞춤을 대체). SFC·MD 엔딩처럼 글로 읽히는 자막은 왼쪽 정렬 | 화면 확인 |
| 2-15 | 🔴 **음성 자막은 말이 끝나고 0.5초 뒤에 닫는다**(모든 음성 자막 — 대사창 포함, 마스터 10-15 「말끝날떄 바로 자막이 닫히지 않고 0.5초정도 여유를 두었으면 해. 물론 다음에 대사가 있어서 자막이 바로 나와야 하면 그 자막을 띄우고.」) — 다음 대사가 0.5초 안에 시작하면 다음 자막이 앞선다. **예외**: pce-ed2 인게임 자막(이미 구현된 대사창 방식). pce-ed1 인게임 자막은 pce-ed2 와 같은 방식으로 구현할 수 있으면 그렇게, 안 되면 이 규칙 | 화면 확인 |

| 3-5 | 조사는 런타임 조사 훅으로 고른다 — 병기 `을(를)` 을 화면에 남기지 않는다 | 조사 일치 검사 |
| 3-6 | 🔴 **칸이 모자라면 기술(재배치·넓히기) 먼저**, 안 되면 칸 꼴을 제안해 마스터 확인 → 정본 `원문@자리`. 줄인 꼴부터 쓰지 않는다 | — |
| 3-7 | 🔴 **스태프롤·성우 크레딧은 일본어를 하나도 남기지 않는다** — 분야(직함) 라벨·배역명·**사람 이름·회사·스튜디오 이름까지 전부 한글**로 옮긴다. **영어로 된 것(「CD-AUDIO」·「PSG」·영문 회사명 등)은 그대로** 둔다(마스터 10-16 「사람 및 회사 스튜디오 까지 포함해서 번역하자. 아예 일본어가 안남게. 영어로 된건 그대로 두고」 — 10-13 「사람 이름만 원문」을 대체). 같은 사람·회사는 기종이 달라도 같은 표기 — 먼저 나온 한글판(PS1·새턴·SFC) 표기를 따르고, 새로 읽는 한자 이름은 읽기 근거를 붙여 마스터 확인 뒤 쓴다. 스태프롤은 정본 대상이 아니라 게임마다 든다(CLAUDE.md 예외). 🔴 **일본 사람·회사 이름의 한글 표기는 국립국어원 외래어 표기법(일본어)** — 어두 예사소리(가쓰유키·도시히코), つ→쓰, 장음 표기 안 함(마스터 10-16 「크레딧이니까 외래어표기법에 따르는게 맞을듯」). 원판 스태프롤이 **로마자·영문인 게임(md-ed1·md-ed2·ss-ed3)은 이름까지 그대로** 둔다(마스터 10-16 「md, ss-ed3은 스태프롤이 영어라서 신경안써도돼」) | 화면 일본어 게이트(이름 포함) |
| 3-8 | 🔴 **오프닝·엔딩은 기종이 달라도 뜻이 같으면 같은 문안** — 원문 표현이 조금 달라도 의미가 같으면 **PS1 문안**을 그대로 쓴다(ED1·ED2 = ps1-ed1+2, ED3 = ps1-ed3). PS1 에 없는 문장은 기종 간 대조표로 하나를 골라 정본에 올리고 나머지가 따른다(마스터 확인). 뜻이 다른 문장만 각자 원문대로(마스터 10-13 「원문이 차이가 있더라도 의미가 같으면 동일하게」 · 「오프닝 엔딩 둘다 ps1 기준으로 진행하자」). ⚠ **원문에 없는 말을 더하거나 원문에 있는 말을 빼야 PS1 문안이 되는 줄은 「같은 뜻」이 아니다** — 원문대로 둔다(예: PS1 의 호칭 「왕자님,」·빠진 「멸망시키는」, 마스터 10-13 「1,2 원문대로」). PS1 문안 자체가 PS1 원문과 어긋난 곳(ED2 오프닝 끝 4칸 — 초기 「정발 느낌」 문안)은 PS1 을 원문대로 고친 뒤 그것을 기준으로 한다 | 기종 대조표(관리자) |

## 4. 문체

| # | 규칙 |
| --- | --- |
| 4-1 | 🔴 **원문(JP) 기반 자체 번역.** 정발은 **참고**만 — 고유명사 표기와 애매한 표현을 정할 때. 팔콤 원문·정발 문장을 문서·주석·테스트에 **통째로 옮기지 않는다**(저작권) |
| 4-2 | **원문에 가깝게** — 후보가 갈리면 원문 쪽. 단 **마스터 QA 판정이 원문 우선보다 앞선다** |
| 4-3 | **번역투 금지** — 일본어 어순·피동·「~의」 남발·직역 관용구를 한국어 문장으로 다시 쓴다 |
| 4-4 | **캐릭터 개성을 살리는 말투** — 인물별 말투(존대·반말·어미 버릇)를 그 게임의 인물·관계 정본(story bible)대로, 같은 인물은 전 기종에서 같은 결 |
| 4-5 | 화자 이름은 **오독될 때만** 덧붙인다(원판이 감춘 화자를 까지 않는다) |
| 4-6 | 색·연출 제어 코드는 **원판 그대로** — 바꾸는 건 글자뿐(색을 고르는 건 개조다) |
