# 고유명사 표기 규약 — 타이틀 공용

**정본 데이터는 [`shared/glossary/`](../shared/glossary/), 판정 규칙은 여기다.** 사전은 편마다
갈린다 — [`eiyuu.json`](../shared/glossary/eiyuu.json) = ED1·ED2, ED3·ED4 는 `eiyuu3`·`eiyuu4` 로 낼
예정이다(마스터 2026-10-07). 같은 세계관을 여러 플랫폼이 나눠 쓰므로(PS1 · 새턴 · PCE · MD · SFC ·
PC-98) **규칙이 한 곳에 없으면 트랙마다 다르게 판정하고, 그게 정본을 조용히 갈라 놓는다.**

⚠ 실제로 그랬다 — `オークホーン` 이 **08-12 붙임 → 08-27 띄움 → 08-29 붙임**으로 두 번
뒤집혔다. 까닭은 규칙 없이 자리마다 개별 판정을 했기 때문이다(2026-08-29).

## 어디에 무엇이 있나

| 무엇 | 어디 | 누가 고치나 |
| --- | --- | --- |
| **판정 규칙** | **이 문서** | 문서라 어느 브랜치든 |
| **표기 데이터**(원문→우리 표기) | `shared/glossary/` | **main 에서, 마스터 확인 뒤에만** |
| 공략집이 적은 사실(이형·수치·출처) | `shared/lore/` — 정본을 고치는 **근거**지 정본이 아니다 | main 에서, 마스터 확인 뒤에만 |
| ~~플랫폼 제약으로 줄인 꼴~~ | **없다** — 칸이 모자라면 줄이지 않고 칸을 넓힌다(마스터 2026-10-07) | — |

🔴 **고유명사는 사전 한 곳에만 있다**(마스터 2026-10-07 — 08-29 「정본은 데이터니 게임 브랜치에서
고친다」를 대체). 게임 브랜치가 사전을 고치면 `check_shared_scope` 가 **실패**시키고, 세션은 새
이름·바꿀 이름을 **후보로 관리자에게** 올린다. **게임 폴더에 JP→KR 이름 표를 새로 만들지 않는다** —
이미 있는 자기 표는 라운드마다 사전에서 읽게 옮기고, 그 전까지는 **사전과 전량 대조하는 게이트**로
묶는다(루트 `CLAUDE.md` 「공용 코드는 `main` 에서만」 절).
⚠ 까닭 — 08-29 에 브랜치에서 고치게 열었더니 ① 세션 판단이 마스터 확인 없이 정본이 됐고 ② 게임마다
자기 표를 들고 있어 한쪽만 고쳐졌다. PS1 도구 표는 사본이라도 테스트가 묶는다고 여겼는데
(`test_tool_tables_match_shared_glossary`), **PS1 v1.0.0 배포판에 옛 몬스터 이름 15종이 나갔다**(10-07 발견).

⚠ **표기를 바꾸면 문안이 따라와야 한다.** 이미 써 놓은 문안에 글자로 박힌 자리는 표 대조가 안 본다 —
2026-08-29 실측: 20가지를 바꾸자 338곳이 걸렸고 그중 **310곳이 문안**이었다(`script/` · `textmap/` ·
`line_dict.json`). ⇒ 사전을 고치면 **각 게임이 자기 문안을 따라 고친다**(머지되면 받는다).

| 규칙                                                                                                                   | 사유                                                                                                                                                             |
| ---------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **⭐ 고유명사는 정발 표기를 따른다** — 원음과 달라도(`アグニージャ`→**아그니쟈** · `ウォンリーク`→**온리크** · `ヘベタル`→**헤베달**, 원음이면 「탈」이다 — 유저 확정 2026-09-06) | 유저 확정 2026-08-12. 향수를 살리는 것이 방침이고, **원음 환원은 오역 교정이 아니다**. ⚠ 단 정발이 갈리면 아래 규칙으로 넘어간다 ✅                              |
| 정발 **내부가 갈릴 때는 일본어 원음으로 판정한다** — ED1↔ED2 충돌도, 한 작품 안의 갈림도 같다(영문판은 어원 확인 보조) | 유저 확정 2026-08-12. **ED2 우선을 잠깐 뒀다가 원음 우선으로 되돌렸다** — ED2 도 대사와 아이템 테이블이 갈리는 자리가 많아 「ED2」 가 한 값을 가리키지 못한다 ✅ |
| **⭐ 같은 고유명사는 ED1·ED2 가 한 표기다** — 정발이 갈라 썼어도 우리는 하나로 간다(`제르만` · `리셸` · `길모아`)      | 유저 확정 2026-08-12. 두 작품이 한 디스크에 담기고 플레이어는 이어서 한다 — 같은 인물·물건이 편마다 다른 이름으로 나오면 그게 결함이다 ✅                        |
| **정발과 정본이 갈리면 정본이 이긴다 — 오역·규칙 위반이라 우리가 고친 이름은**(`온리크` · `프라토` 등) 정발로 되돌리지 않는다. 정발은 사전·`lore` 에 이형으로 단다 | 마스터 2026-10-06. 정발 우선을 문자 그대로 적용해 되돌리면 이미 배포한 PS1 표기와 갈린다. 정본에 **아예 없는** 이름만 정발을 출발점으로 삼아 마스터께 올린다 |
| 🔴 **칸에 맞추려 줄인 꼴을 쓰지 않는다** — 칸이 모자라면 표기를 줄이지 말고 **칸을 넓힌다**(아래 `늑대의입`) | 마스터 2026-10-07 |
| 지명 접미(마을/항구)는 **작품별 원판 스타일**: ED1=접미 있음, ED2=무접미                                               | JP 원판 자체가 2편에서 접미를 뗌 ✅ ⚠ 이건 **접미**지 고유명이 아니다 — `크루즈`(고유명)는 한 표기, `크루즈 마을`/`크루즈`(접미)는 작품별                        |

### 외래어 이름은 **공백을 뗀다** (유저 확정 2026-08-29)

가타카나 원문이 두 낱말이어도 붙여 쓴다 — `오크 혼`→**오크혼** · `버스트 하운드`→
**버스트하운드**. ⚠ **한국어 문법 공백은 그대로 둔다**(`아크담의 부하` · `암흑의 전사` ·
`강철 거인`) — 붙이면 한국어가 안 된다.

🔴 **가르는 기준은 「원문이 가타카나인가」가 아니라 「우리가 음차했는가」다**(2026-09-06 보강).
원래 문구가 앞엣것이었는데 그러면 **음차+음차**와 **음차+번역**을 못 가른다:

| 꼴 | 예 | 처리 |
| --- | --- | --- |
| **음차 + 음차** | `バトルスーツ` → 배틀+슈트 | **붙인다** → `배틀슈트` |
| **음차 + 번역한 보통명사** | `レストナキノコ` → 레스토나 + **버섯**(`キノコ` 를 번역) | **띄운다** → `레스토나 버섯` |
| 한국어 문법 공백 | `암흑의 전사` · `강철 거인` | **띄운다** |

⚠ 이 구멍에 넷이 빠져 있었다(2026-09-06 실측 — `배틀 슈트`·`배틀 슈트`(사본)·`피코 해머`·
`타이슨 펀치`). 셋 다 **음차+음차**라 붙이는 게 맞았고, `레스토나 버섯` 하나만 정당했다.
⛔ **테스트가 지킨다** — `shared/glossary/tests/test_glossary.py` 가 「가타카나 한 덩어리인데
우리 표기에 공백」을 전부 잡고, 정당한 예외는 **목록에 근거와 함께** 올려야 통과한다.

부수 효과가 둘 있다 — **홀수 바이트가 준다**(반각 공백이 홀수를 만들고, 홀수 주소는 두
바이트를 고정으로 읽는 화면을 깨뜨린다), 그리고 **이름 칸이 빠듯한 자리에서 1바이트를 번다.**

### 기타 — 정본 파일 자신이 들고 있는 규칙

`eiyuu.json` 의 `_doc` 에 적혀 있다(범주별로 둔다 · 정본은 도구 표의 상위집합이다 ·
한 원문에 한 표기다 · 확정 판단이 정본을 이긴다 · 항구는 `항` 으로 붙인다). **정본을 열면
보이는 자리**라 거기 둔다 — 이 문서는 그보다 긴 판정 규칙을 맡는다.

## 접미는 층마다 다르다 — 정본은 **붙임 꼴**이다 (2026-08-30)

`shared/glossary` 의 지명은 **HUD·표 꼴(붙임)** 로 적는다 — `네리아항구`·`크루즈마을`.
**대사는 띄운다** — `네리아 항구`·`늑대의 입`. 층이 다른 것이지 갈린 게 아니다
(HUD 는 슬롯이 좁고 2바이트 단위로 종단해 공백이 위험하다 — 그 게임 `policy.md`).

⚠ **편마다 접미 규약이 다를 수 있다.** 실측(영웅전설): ED1 표는 접미가 73%(`크루즈마을`·
`베르가광산`·`네리아항구`)인데 ED2 표는 7%(`크루즈`·`베르가`·`네리아`)다. **원작이 그렇게
갈라 뒀고** 우리는 그대로 따른다. ⇒ 「두 편이 갈렸다」로 보고 통일하지 말 것.
🔴 단 **대사는 두 편이 한 표기**다 — 플레이어가 이어서 하기 때문이다.

### `狼の口` — 정본은 **늑대의입**이다 (마스터 확정 2026-09-14 · 재확인 2026-10-05)

🔴 HUD·워프·입장 배너는 **`늑대의입`**(붙임), 대사 속은 **`늑대의 입`**. **축약형은 쓰지 않는다.**
칸이 모자란 기종(새턴 HUD 씬머리 8B 등)은 표기를 줄이지 말고 **기술로 푼다** — PS1 이 반각 글리프와
좌표 덮어쓰기로 HUD·워프를 `늑대의입` 으로 맞춘 길이 선례다(`games/ps1-ed1+2/tools/patch_sys_ui.py`).
🔴 **반각 공백은 HUD 에서 쓰지 않는다** — 두 바이트를 한 글자로 읽는 화면이라 1B 를 끼우면 뒤가 반 칸씩
밀린다(실측 2026-08-25 「곶의동굴 근틀」).
⚠ **표만 바꾸면 더 나빠진다** — 지명 표만 고치고 HUD 를 못 고치면 워프 목록과 HUD 가 어긋나 보인다
(아래 `리셸` 과 같은 증상). 한 기종 안의 모든 층을 같이 맞춘다.

⚠ 접미가 빠진 자리를 보면 **판단인지 자리 부족인지 먼저 재라.** 실측: 워프 슬롯의 `리셸` 은
판단이 아니라 원문 `リシェールの港` 가 15B 라 14B 슬롯에 안 들어가서였다. 우리 `리셸항구` 는
9B 라 들어가므로 **원문보다 일관되게 갈 수 있었다**(유저 QA 로 발견 — 워프 목록과 HUD 가
어긋나 보였다).
